# the autonomous run — the method

This is what the agent does when the owner sets full autonomy and says go
ahead. It runs without further instruction until the stop condition.

It is a LOOP OVER MACHINES THAT ALREADY EXIST. It invents no new lane and
skips no guard. Every state on the way still weighs the dial, proves its
reads and runs its scripts.

## The trigger

The owner raises the autonomy, opens the door, and says to work as much as
the agent wants. Nothing else starts it. An agent never begins one because
the inbox looks full.

## Phase 1 — clear what stands

Fix everything currently fixable, in whatever order the machinery offers.

- Open iterations get worked.
- Open expeditions get worked, and closed when their goal is met.
- Pending notes mean a retro is due, so run one.

Continue until the backlog is zero and there is genuinely nothing left.

## Phase 2 — overhaul

Everything standing is now fine and tidy, so sweep it. The overhaul is the
machine for exactly this: everything catches up, deep, over what already
stands. Its method card is the sibling of this one.

## Phase 3 — ideate in batches

Nothing left to do means the work must be INVENTED. Ideation is the machine
for that, and its shelf of method cards is the input.

- Take the FIVE most fitting cards first. Implement what they produce.
- Then the next five. Implement what those produce.
- Then the next five. Keep going.

STOP ON EITHER CONDITION.

- Every card has been drained.
- The cards stop yielding anything worth building.

Never pad a batch to reach five. A card that does not fit the frame is not
run, and saying so is the honest outcome.

## Phase 4 — overhaul again

Phase 3 is the phase that MAKES MESS, because it builds things nobody
planned. So the tidy-up runs a second time over what it added.

## Phase 5 — done

Back at idle with nothing left, follow the shutdown policy. Say plainly what
was done and what was left.

## The shape worth noticing

The overhaul BRACKETS the ideation round. Clear and tidy, then invent and
build, then tidy again. The second pass is not duplication. It exists
because inventing is messier than fixing.

## What it never does

- It never runs without the owner's word, however full the inbox looks.
- It never skips a guard because it is unattended. An unwatched agent needs
  the guards MORE, not less.
- It never invents work while phase 1 still has work in it. Inventing is
  the last resort, not the first move.
