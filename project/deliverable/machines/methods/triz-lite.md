# TRIZ-lite — break the contradiction instead of trading it

**What.** TRIZ's core in one pass: state the contradiction (improving A
degrades B), then refuse the compromise — separate, or apply an
inventive principle. Somebody already solved a problem shaped like
yours.

**When.** Every option seems to trade one good thing for another. The
card for "faster but less safe", "flexible but complex".

**Steps.**
1. Write the contradiction in one line: improving X degrades Y.
2. Try the four SEPARATIONS: in time (both, at different moments), in
   space (both, in different places), in relation (both, for different
   observers), in level (part vs whole).
3. Scan a handful of the 40 inventive principles for fits — segmentation,
   asymmetry, nesting, prior action, inversion, mediator, self-service,
   cheap short-lived object, feedback.
4. Reformulate the idea so BOTH sides of the contradiction win.

**Output.** Ideas that dissolve the trade-off, each naming the
separation or principle that produced it.
