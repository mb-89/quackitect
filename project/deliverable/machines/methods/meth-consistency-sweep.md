## Situation

M8, before the validation gate.

The describing surfaces are wherever the changed behaviour is taught:

- method notes
- task notes
- guides
- templates
- the book chapters
- the README

## Procedure

- List what the iteration changed. The evidence trail has it.
- For each change, find every surface that describes the old behaviour.
  - Update it, or mark it.
- The machine's own notes are surfaces too. A changed practice means the
  method note changes in the same sweep.
