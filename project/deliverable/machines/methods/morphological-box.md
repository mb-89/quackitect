# Morphological box — enumerate the space before picking from it

**What.** A grid: rows are the FUNCTIONS the solution must fulfill,
columns are OPTIONS per function. One solution = one path through the
grid, one option per row.

**When.** The problem decomposes into parts and each part has
alternatives — architecture, tooling, process shapes. The strongest card
when "did we even consider X" matters.

**Steps.**
1. Partition the problem into 3–7 functions (rows).
2. Per row, list every option you can — including the silly ones.
3. Combine deliberately: walk 3–5 promising paths through the grid.
4. Name combinations nobody would draw by instinct; keep one as a probe.

**Output.** The grid itself (it IS the coverage claim) plus the walked
paths as candidate ideas.
