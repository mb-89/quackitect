# Pugh matrix — converge on a defensible pick

**What.** Score options against few criteria relative to a DATUM (the
baseline option). Better +1, same 0, worse −1. Sum, then argue with the
sums, not from them.

**When.** Several candidates, a pick needed, and "best" must survive a
why. The converge state's standard card; any decision state may pull it.

**Steps.**
1. Name the datum — the current way, or the least surprising option.
2. Pick 3–7 criteria from the frame or the requirements. Independent ones.
3. Score every option per criterion against the datum: +1 / 0 / −1.
4. Sum. Then probe the winner: which single criterion flips the pick?
5. Record the matrix and the sensitivity in the decision graph.

**Output.** A ranked set with reasons, and the named criterion the pick
hinges on.
