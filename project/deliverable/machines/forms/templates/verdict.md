# verdict

The first line is the ruling. Below it, the reasoning.

- pass — the claims held.
- pass with overrides — findings stand; each is named with its dissent.
- fail — the reasoning names what must change.

A fail is MECHANICAL: the form never counts as met while it stands, so
the walk cannot leave the gate past it. Submitting a fail is legal — it
records the ruling — but the gate stays shut until the fix lands and the
verdict changes.
