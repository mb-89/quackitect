# free-form — the default template

Any field without a template of its own uses this one. It asks for prose,
and it asks that the prose be readable.

## How to write the field

- Lead with the answer. The first sentence carries the finding.
- One thought per sentence. Short sentences.
- Numbers over adjectives. "3 of 22 failed" beats "some tests failed".
- Three or more items are a list, one per line.
- Name things by what they do, not by their internal identifier.
- State uncertainty plainly. "Unverified — needs a scoped run" is a
  complete sentence.
- An empty answer is a claim too: write an explicit "nothing", never a
  blank.
