# End

Mechanical. The machine is done when everything before end has transitioned
into it. Nothing machine-specific belongs in this note; every machine
shares it.

## NO BAR HERE, AND THAT IS DELIBERATE

It carried `busbar: true` for an hour, so a fan could fold on it. Wrong
place: a bar belongs over the WORK that joins the legs, not over the pill
that closes the machine.

Every machine's end has exactly one arrow into it once the bar sits where the
join really is, and a bar over one input synchronises nothing.
