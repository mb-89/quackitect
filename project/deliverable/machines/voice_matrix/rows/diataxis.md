# Diátaxis

Four modes, kept apart (diataxis.fr).

## This row decides where STE binds hardest

The split we settled: how-to and reference take STE hard, because they are
instructions read under load. Explanation keeps the figurative register,
which the project built on purpose and which a controlled vocabulary would
flatten. These are the terms it protects:

- the walk
- the lane
- a stray
- the blue line

So this row is not only a rule. It is the SELECTOR that tells the
dictionary row how strict to be on a given text.

## brief, refusal, note

Struck. A single-mode fragment cannot blend modes.

## Why tier two

Classifying a passage's mode is judgement. A lint can notice that a
reference page contains a narrative section, which is a weak signal and a
review-time report at best.
