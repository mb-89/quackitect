# Size

A budget is per content KIND, which is exactly what this matrix's columns
are. That is why size is a row here rather than a rule in `voice.md`.

Counting is arithmetic, so this is tier one and can run at the write.

## guidance

ABOUT 100 WORDS per field. State guidance, a tool description and a form's
help are read on every visit, by an agent that has already spent its context
on the work. A field that runs long is paid for on every single walk.

Refused at the write, because the cost is countable and immediate.

## document

TWO NUMBERS, not one.

- SOFT, 1,200 tokens. Reported at a sweep. Past this a document is asking to
  be split, and the author decides.
- HARD, 2,000 tokens. Refused. Past this nobody reads it whole, and a
  document nobody reads whole is a document whose second half is not binding
  anything.

THE REMEDY IS A FOLDER CLUSTER, never section routing. `walking.md` becomes
`guidance/walking/*.md`, one file per idea. Small files ARE section routing,
and both mechanisms that carry documents keep working unchanged: the pull
addresses a file, and the reading proof hashes a file.

FOUR DOCUMENTS EXCEED THE HARD CAP TODAY: walking, voice, authoring/machines
and software. None of them is split yet, so this cell reports rather than
refuses until they are. Turning it on before then would refuse edits to the
very files that need editing.

## record

A record earns its length. It carries a goal, its reasoning and its report,
and an archive reader wants all of it. Reported at a sweep so an outlier is
visible, never refused.

## comment

The document numbers are the owner's to set. They came from the ICM reading
of 2026-08-02 as a starting point, not from measurement of this repo.
