## Why this one

IT IS THE ONLY LINE THAT ASKS WHAT THIS DELTA'S FAILURES HAVE IN COMMON. Every
one of them is silent, and a silent failure is not made safer by a check that
somebody has to remember to keep right.

IT EXISTS TO PRICE LOUDNESS. Whoever decides should see what buying it actually
costs, rather than agreeing it would be nice.

## How it works

THE SAME DECLARATION SITS AT THE CENTRE as on the reference line, and everything
downstream of it is inverted from a check into a shape.

WHAT HAPPENS ON AN OPEN, END TO END.

- The host tests its declared pattern. No match, and nothing of ours runs.
- On a match the tree is settled before anything else happens. SUPERSEDED BY
  THE HOST SPIKE, 2026-08-19: the editor cannot state which tree it opened.
  Read "After the host spike" below for what this step is now.
- One bring-up path runs, the same one that serves a machine with nobody at it.
  Whether a person is present is an input to it rather than a second path.
- The corpus is read through the only reader that exists. The second one is
  deleted, so a malformed node has one answer by construction.

WHAT HAPPENS WHEN A COPY IS PRODUCED. The package is assembled from a list of
what belongs in it. A file nobody named is not in the package, whatever it is
and wherever it sits.

### Before any of that, the first install — SUPERSEDED BY THE GRAFT

EVERYTHING IN THIS SUBSECTION DESCRIBES THE LINE AS COMPARED, NOT AS IT NOW
STANDS. The install cell was replaced on 2026-08-19. Read "After the graft"
below for what this line is. This is kept because the picks are the record of
what was compared and deleting it would make the comparison unreadable.

THE PRODUCT NEVER INSTALLS ITSELF. A declared image arrives with the runtime and
the product already in it, so there is no install to get half-right.

THAT IS THIS LINE'S OWN LOGIC APPLIED ONE STEP EARLIER. Every other cell here
replaces a check with something unrepresentable. An image either built or it did
not, so the half-installed machine stops being a state that can exist rather
than a state something has to detect.

IT IS THE MOST EXPENSIVE CELL ON THE CHART FOR THIS LINE, and the option node
says so in its own words: it moves the problem rather than removing it, because
building and publishing the image is work somebody does and keeping it current
with the product is a second thing that can drift.

### The seams

IT CLOSES THE SEAM THE REFERENCE LINE LEAVES OPEN, and that is its strongest
argument. There, two host mechanisms decide whether we start and what we hold,
and nothing forces them to agree. Here the handover is stated and acknowledged,
so a disagreement is a refusal rather than a lane rooted somewhere nobody chose.

ITS OWN SHARPEST SEAM IS THE MERGED ARRIVAL AGAINST THE OPEN ROW. This line
takes the host's pattern test as the way in, and it also merges the unattended
arrival into the same path. On a machine with no editor there is no host to run
that test, so the merged function needs a second way in that the open row does
not describe.

THAT IS NOT FATAL AND IT IS NOT FREE. The merged function's own option already
warns that folding the unattended path into one built for a present person risks
losing the guarantee that exists because nobody is watching. This seam is where
that would happen.

DELETING THE SECOND READER MEETS THE FORM PATH. Every form's node lists come
from the reader that is being removed, so they come from the whole corpus
afterwards. Inside one pass that is a stamped read; the first read in a pass is
not.

THE INCLUDE LIST AND THE DECLARATION ARE COMPLEMENTS, NOT ONE LIST. The
declaration says what the machine-state folder is. The include list says what
ships. A file in neither simply stays home, which is the safe direction.

## What it costs

THE FOUR PARAGRAPHS BELOW ARE SUPERSEDED BY THE GRAFT and describe the install
cell this line no longer takes. They stand as the record of what was compared.

THE INSTALL CELL FAILS THE SETUP FLOOR OUTRIGHT, and this was the sharpest price
on the line before the graft removed it. The floor is a computer holding only an editor and a shell. An
image needs a container runtime, which is more than that, so this cell CHANGES
the precondition rather than meeting it. The option node states it plainly.

IT ALSO SERVES THE WRONG PERSON. The same node says telling an engineer to run
a container to get an editor extension is worse than the script they have. This
line takes the cell anyway, because loudness is what it buys everywhere else,
and that trade should be judged rather than assumed.

THE OPTION ITSELF OFFERS A WAY OUT THIS LINE DOES NOT TAKE. It records that an
image and a script are not exclusive, and could serve the unattended host and
the laptop respectively. Taking both would soften this cost and would also give
this line two install paths that can drift, which is what it exists to prevent.

THE INCLUDE LIST IS CHEAPER HERE THAN ITS OPTION NODE ARGUES, and probe P3 is
why. Both producing paths run through `travels`, which is our own filter
function rather than a vendor's ignore file. Inverting a filter is a change in
one function, not a build step bolted onto a packaging tool.

WHAT THAT DOES NOT COVER. Any future producing act that does not use `travels`
inherits nothing, and the loudness argument only holds where the list is
actually consulted.

MAKE, REUSE OR BUY.

- BUY: the activation pattern, and the host's own statement of which folder it
  opened.
- REUSE: the corpus loader, which already exists and is already stamped.
- MAKE: the declaration and its generators, the acknowledgement step, the
  include list, and the merged bring-up path.

THE MERGED PATH IS THE LARGEST PIECE ON THIS LINE. Seven functions and a cluster
boundary disappear, and the two paths stop being able to drift. It is also the
only piece here whose failure is worse than what it replaces.

PERFORMANCE, MEASURED. Deleting the second reader makes a form that wanted
eleven nodes depend on all 1097. A full read is 359 ms and a stamped repeat is
11 to 13 ms, against a five-second open bound. The number is comfortable and the
dependency is real.

FAILURE MODES, ORDERED BY HOW BADLY THEY FAIL.

- The merged arrival loses its second guarantee. SILENT, and an agent believing
  it is caged when it is not is the worst failure this chart contains.
- A future producing act does not consult the include list. Silent, and the
  same shape as the deny list it replaced.
- The include list omits a file that should ship. LOUD, on install, for the
  first person who tries it. This is the trade being bought.
- The carrier count is not one. Loud, and nothing starts. This read "the
  acknowledgement rejects the handed-over tree" until the host spike.
- The system's content test drifts from the host's. SILENT, and it is the one
  failure this line had not written down. Both tests come from the same
  declaration, so a stale generated consumer breaks the root check without
  breaking anything visible. Found by the second hand rescoring the fatal axis
  after the rewrite, not by this line's own author.

TESTABLE. The acknowledgement is a unit test. The include list is the same
packaging test the M2 gate already asked for, read the other way round. The
merged path's second guarantee is the one thing here that wants a real spike,
and M6 is where that belongs.

## What it leans on

THE PACKAGING TOOL CAN TAKE AN INCLUDE LIST. Measured for the two acts that
exist, because both run our own filter. Assumed for any act added later.

WHOEVER STARTS THE SYSTEM CAN STATE WHICH TREE IT IS HANDING OVER. A host that
simply launches a process with a working directory cannot, and then the
acknowledgement has nothing to acknowledge.

THE ARRIVAL'S SECOND GUARANTEE SURVIVES THE MERGE. That is the assumption this
line is least sure of, and the merge option carries the argument against it.

THERE IS A WAY IN ON A MACHINE WITH NO EDITOR. The open row does not describe
one, and the merged path needs it.

A CONTAINER RUNTIME EXISTS ON THE MACHINE — NO LONGER ASSUMED. The graft removed
this lean along with the image cell. Kept struck rather than deleted, because it
is half the reason the graft was taken.

SOMEBODY KEEPS THE IMAGE CURRENT WITH THE PRODUCT — NO LONGER ASSUMED, same
reason. It was a stale-image failure of exactly the kind this line exists to
abolish, and the graft is what removed it.

WHAT THE GRAFT ASSUMES INSTEAD. One command can run on the target machine, and
the runtime it installs is one the engine runs on. The second is already in the
register as an assumption rather than a fact.

A COMPLETE PREFLIGHT IS BUILDABLE TO THE NAMED STANDARD. `mason.nvim` shows the
five properties in about two hundred lines. This line now owes that build, and
the second hand scoring the graft would not award prior-art par until it exists.

THE WHOLE CORPUS STAYS AFFORDABLE TO LOAD. Deleting the second reader makes
every form depend on that, and the corpus has grown from 328 nodes to 1097.

THE SYSTEM'S CONTENT TEST AND THE HOST'S STAY THE SAME TEST. New on 2026-08-19,
and it arrived with the rewritten root cell. The self-check that replaces the
handover is only as good as its agreement with the test the host ran, and both
are generated from the declaration. This lean did not exist before the spike.

## After the graft, 2026-08-19

ONE CELL WAS TAKEN FROM THE RUNNER-UP and the picks above are left as composed,
because they are the record of what was compared. This section is what the line
IS now.

THE INSTALL CELL CHANGES. The declared image is replaced by one command and no
wizard, taken from [[opt-one-command-install]].

### Why this is coherent rather than merely better-scoring

THE LINE'S CLAIM IS THAT SILENT FAILURES ARE MADE UNREPRESENTABLE, and the
image delivered that for install by construction: it either built or it did not.
Swapping to a command looks like giving that up.

IT IS NOT, AND THE PRIOR-ART SCAN IS WHY. A complete preflight is loud by
construction too, and `mason.nvim` shows what complete means: every check run
rather than stopping at the first, each tool named with its version, required
split from optional, the remediation command carried in the source, and nothing
on disk changed. That is roughly two hundred lines.

THE IMAGE ACHIEVED LOUDNESS BY MOVING THE PROBLEM SOMEWHERE ELSE. Somebody
builds the image, somebody keeps it current, and a stale image is a silent
failure of exactly the kind this line exists to abolish. The preflight achieves
it inside the product, where this line can hold it.

SO THE GRAFT EXPRESSES THE LINE'S OWN ARGUMENT BETTER than the cell it replaces,
which is the only reason to take it.

### What it costs, declared rather than netted away

IT SPENDS A STRENGTH THIS LINE WON ON. Stopping before a partial install was one
of three axes where this line stood alone, and it stood there because an image
cannot half-install. A preflight can be incomplete in a way an image cannot.

WHAT IT BUYS IS TWO AXES AND A PRECONDITION. The setup floor becomes reachable,
because one command needs no container runtime, and a fresh machine no longer
has to obtain one first.

THE TRADE IS NAMED HERE BECAUSE A NET FIGURE HIDES IT. Whoever builds this now
owes a preflight that is complete, and the standard for complete is a named
implementation rather than a wish.

### What the graft does NOT change

EVERY OTHER CELL STANDS. Ownership stated and acknowledged, an unnamed file
unable to ship, one corpus reader, the merged bring-up path, the way in marked
at every arrival point. The graft is one row.

## After the host spike, 2026-08-19

THE ROOT CELL WAS HALF IMPOSSIBLE AND IS REWRITTEN. A spike read the editor's
own source and its whole published type surface. The editor computes which
folder matched its activation test, discards that identity, and hands the
extension the entire workspace with no activation reason at all.

SO NOTHING STATES A TREE ON THIS HOST. A launcher, a hook or a command line
still can, and where one does the two-sided act stands unchanged.

### What the step becomes

THE SYSTEM RUNS THE SAME TEST THE HOST RAN, once per open folder, and counts
what carries the marker.

- Nought. Refuse. Something claimed a carrier exists.
- One. Bind to it, and echo it where a person reads it.
- Two or more. Refuse, and ask the person which.

IT NEVER LEARNS WHICH FOLDER FIRED THE EVENT, and it does not need to. The only
case where the trigger's identity would matter is the ambiguous one, and that
case refuses.

USE THE HOST'S FILE-EXISTS CALL RATHER THAN ITS SEARCH. The search applies the
person's own exclusion settings unless told otherwise, which makes it a
different test that can disagree with the host's.

### What it cost, declared rather than netted away

THE SHAPE IS WEAKER AND THE GUARANTEE IS NOT. A receiver checking its own input
is not a transfer, so the analogy this cell was borrowed from no longer
describes it.

THE SCORE DID NOT MOVE, and that was measured rather than hoped. A second hand
held both designs on the fatal axis after the rewrite. The requirement grades by
failure mode rather than by mechanism, and both shapes sit at the same rank.

ONE CLAUSE MOVED THE OTHER WAY. The requirement's environment is any host, bound
or unbound, and the two-sided act had a declared gap for a host that only
launches a process with a working directory. The self-check covers that host.

WHAT IS GENUINELY LOST is a route this line could once have taken in principle.
Its original statement contrasted itself with inference, and a content test IS
inference. Today's rank is unchanged; the ceiling is lower.

### Two host behaviours worth knowing before building

A SEVEN-SECOND TIMEOUT KILLS WILDCARD ACTIVATION and leaves only a log line. A
pattern with no wildcard avoids the search path entirely, so it is the safer
form. It reverts to searching under a remote authority.

ADDING THE FIRST FOLDER TO A WORKSPACE RESTARTS EVERY EXTENSION rather than
firing the folders-changed event.
