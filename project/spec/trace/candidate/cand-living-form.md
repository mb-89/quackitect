## Why this one

This is the no-drift candidate. Its single rule is that one fact is written in
one place, and every surface that shows it is a view.

Filling an evidence field writes the standing node directly. The record splits
into the part that outlives it and the part that dies with it, so nothing
durable is trapped in something disposable. Every gate demands a verdict, and
the session autonomy decides whose verdict counts.

What it trades away is form weight. An editor that owns the artifact has to
carry the whole artifact, and the cost is already visible: this state's own
form is 171 KB because its grid derives 27 option nodes. It also needs a real
editor built for every field shape, which is a large surface to keep correct.

It is drawn because drift is the failure this project has paid for most often,
and this is the only combination that makes drift structurally impossible.

## How it works

The baseline stays. The lane, the walk and the trace corpus are untouched.
What changes is the direction of the write.

THE FIRST SEAM IS BETWEEN THE FORM AND THE NODE, and it reverses. Today a
form holds an answer and a separate step binds it onto a node. Here the field
IS the node's editor: typing in it writes the node, and the form's stored copy
is a rendering rebuilt on every look. The node table and the morphological box
already work this way, so the change is to finish the pattern rather than to
invent it.

THE SECOND SEAM IS THE RECORD'S SPLIT. What outlives the record — requirements,
options, candidates, decisions — lives in the corpus. What dies with it — the
evidence forms, the checklists — lives in the record's own folder. The
boundary is not a filing convention: it is what decides whether closing a
record loses anything.

THE THIRD SEAM IS THE GATE. Every gate demands a verdict, always, and the
slider decides whose verdict it accepts. That removes the case where a gate
quietly passes because nobody was asked, which is the same class of silence as
a form that saved without stamping.

WHAT THE COMBINATION MAKES POSSIBLE. One fact has one home, and every surface
showing it is a view. A rendering can be wrong for exactly as long as it takes
somebody to look again, and never longer.

WHAT IT COSTS TO GET THERE is an editor per field shape, which is the
substance of the candidate.

## What it costs

RESOURCE, ROUGH. Ten field shapes already exist: free-form, refs, table,
per-item, dsm, morph-box, rank-cut, node-table, pareto-plot, compare-card.
Several are already editors. The remainder is the build.

THE WORST CASE THAT DECIDES VIABILITY is form weight, and it is MEASURED
rather than feared. This state's own form came back at 171 KB, and later at
177 KB, because its grid derives 27 option nodes and hands every one to the
browser. A form that carries its artifact carries all of it.

That number is from 2026-08-09 and it is already at the edge: the host moved
the result to disk and handed back a two-kilobyte preview. A corpus three
times this size makes the form unservable as one payload.

MAKE, REUSE OR BUY. Almost all make. An editor that writes a typed node is
specific to this trace schema and nothing off the shelf fits it.

THE FAILURE MODE THAT DECIDES. A partially converted set. While some fields
are editors and some are not, a reader cannot tell which surface is the truth,
which is worse than the drift the candidate exists to remove.

## What it leans on

- A RENDERING IS ALWAYS CHEAPER TO REBUILD THAN TO RECONCILE. This holds at
  the measured corpus size and is untested well above it.
- EVERY FIELD SHAPE CAN BE AN EDITOR. Ten shapes exist and several already
  are, so this is plausible; it is not demonstrated for all ten.
- THE DURABLE AND DISPOSABLE HALVES CAN BE TOLD APART CLEANLY. Where a thing
  is genuinely both, the split has no answer and the rule leaks.
- A FORM CAN CARRY ITS ARTIFACT WITHOUT OUTGROWING ITS TRANSPORT. Already
  false at 177 KB for one form on one host, so this candidate owes a paging
  answer before it can be believed.
