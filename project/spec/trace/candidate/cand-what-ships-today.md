## Why this one

A CHART WITHOUT THE INCUMBENT MEASURES EVERY CANDIDATE AGAINST NOTHING. This is
what the product does now, and it is the zero the other three are priced
against.

IT FAILS A STATED DEMAND AND THAT IS THE POINT.
[[req-overlay-drift-reported]] asks the system to say what a copy changed, and
here nothing does. The owner has also ruled that a copy can pull engine updates,
which this line cannot.

THREE OF ITS NINE CELLS GO INERT UNDER THE SECOND, and the inertness is the
finding rather than a flaw in the drawing. With no update channel there is no
stale override to catch, nothing for upstream's work to reach, and nothing for
an overlay to be resolved against. Those rows are picked to complete the line,
and a reader should see that four of this iteration's nine questions only exist
BECAUSE the channel does.

## How it works

NOTHING IS BUILT. This is the system as it stands on 2026-08-18, described so
the other three have a zero to be priced against.

A PERSON RUNS THE EXPORT SCRIPT with a destination, a name and an abbreviation.
It refuses a destination that is not empty and refuses if any of the three
arguments is missing. It copies the working tree, excluding the history, the
session state and this project's own expedition records, writes the new name
into the single file that holds it, and commits once into a fresh repository.

THE COPY IS THEN INDEPENDENT AND TERMINAL. It shares no commit with its source,
so no merge is possible in either direction. Its owner edits any file they like,
in place, because nothing is sealed and there is no separate layer to edit
instead.

THE SEAM THAT MATTERS IS THE ONE THAT IS NOT THERE. Four of this iteration's
nine questions — how changes are represented, how a stale override is caught,
how upstream's work arrives, and what an overlay resolves against — have no
mechanism here, because each presupposes a channel that does not exist. That is
not four gaps. It is one absence seen four times.

RESOLUTION STILL HAPPENS, and it is the predecessor's: join the artifact's
relative path onto each layer in turn and take the first that exists. With no
overlay the list has one entry, so the mechanism is present and degenerate.

THE PROGRAM FINDS ITS OWN METHOD by walking up from its executable, which is
why a copy works at all on a machine that never had the source.

WHAT STAYS is everything: the lane, the walk, the trace corpus, the record
lifecycle, the path jail. This candidate changes nothing, which is its entire
claim.

## What it costs

BUILD COST IS ZERO. No element is made, reused or bought. That is the only
number in this section that is certain, and it is the reason the candidate
exists.

THE RUNNING COST IS PAID BY THE RECEIVER, once per improvement they want. A
copy wanting an upstream fix reads it and re-implements it by hand. That cost is
unmeasured here and rises with how far the copy has diverged, which nothing
records.

THE WORST CASE THAT DECIDES VIABILITY is a security or correctness fix in the
engine. Under every other candidate it reaches copies. Under this one it reaches
none, and the source cannot even enumerate who is affected, because a copy is
not registered anywhere by design.

THE FAILURE MODE THAT DECIDES is silent and total: nobody learns that a copy is
running a broken engine, including the copy's owner. There is no signal, because
there is no relationship.

AND ONE COST IS ALREADY MEASURED RATHER THAN ESTIMATED. The prior-art survey
found the same outcome shipped: an AI methodology framework forked twice, each
fork renamed by hand, and each fork's update command fetching the latest fork
rather than anything upstream. That is this candidate, arrived at by somebody
else, and it is where they ended up.

## What it leans on

THAT NOBODY EVER WANTS AN UPSTREAM IMPROVEMENT. Stated plainly, this is the
assumption the whole candidate rests on, and the owner has already ruled against
it.

THAT DIVERGENCE NEVER NEEDS EXPLAINING. With no record of what a copy changed,
a colleague inheriting one cannot tell a deliberate decision from an accident,
and neither can its author a year later.

AND THAT THE CREATE VEHICLE BUTTON IS NOT WANTED. Production happens outside
the lane here, as a script a person invokes, so nothing inside the running
system can call it. The owner has asked for that button by name.

ALL THREE ARE ASSUMPTIONS WITH NO TRIGGER, because each is already contradicted
by something the owner has said. They are written down so that scoring this line
is about its cost rather than about whether anybody remembered the objections.
