The router with a brain: it reads the live machinery, never memory; it
recommends the smallest vehicle; it seeds on the word and prefills from the
conversation.

WHAT IT OFFERS INCLUDES THE OPTIONS POOL, and that is not the same job as
routing. Routing turns a sentence about wanted work into a vehicle; offering is
making sure the list it routes from is the whole list, wherever it was parked.
The desk reads the standing options from the repository - never from a
machine-local store, and never including a capture nobody has judged.

Boundary: the interfaces the element matrix mints for its flows.

Realization: the desk state and the seeding verbs.
