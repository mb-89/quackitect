## Rationale

THE METHOD MOVES FASTER THAN THE SYSTEM FOLLOWS. Something has to close that
gap deliberately, or it closes by a hundred small unrecorded edits.

It owes no deliverable, which is what makes it a different function from
holding the work. A vehicle exists to produce something. This exists to
remove a difference.

The dated clean verdict matters as much as a finding. A sweep that reports
nothing and records nothing is indistinguishable from a sweep that never ran.
