## Rationale

THE EXPLANATION IS DERIVED FROM THE SYSTEM, never stored beside it. That is
the one property that makes this a function rather than a document, and it is
why it cannot be folded into showing: showing draws what is; this decides
what a stranger needs and in what order.

Admitting absence is the honest half. A tour that invents an example to fill
a stop teaches something false about a system the reader cannot yet check.

Its measures are about PEOPLE, not the machine, and that is deliberate. This
is the one function whose pass line can only be read off a reader.
