## Success criteria

- An unattended walk stops AT gates and nowhere else, with its evidence forms filled.
  Metric: unattended stops that are not gates. Target: zero.
- Every artifact is readable and every command runs with no AI, no network and no agent.
  Metric: commands and artifacts that require an agent to produce or to read. Target: zero.

## Unlike

A coding harness and willpower at one end, and a fully autonomous agent at the other. Both pick a point on the range and build for it. The difference is that the range itself is the product: the same machine serves a person working alone and an agent working unattended.

## Notes (not load-bearing)

This absorbed an earlier candidate, "works without the AI". Autonomy zero IS working without the AI, so the two were one proposition seen from its two ends.

The control that sets it is being redesigned from a slider into a ladder of work types. The proposition is named after the property rather than the control, so it survives that change.
