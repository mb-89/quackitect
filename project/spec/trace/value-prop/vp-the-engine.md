## Success criteria

- A drawn canvas compiles into a governed walk with zero engine code.
  Metric: engine code changed to onboard a new drawn machine. Target: none.
- Machines that are not systematic engineering run in production daily.
  Metric: distinct non-SE machines walked per week (boot, the desk, the retro, the expeditions today). Target: three or more.
- Two machines ship two iterations concurrently without collisions.
  Metric: double-claimed iterations. Target: zero.
- A new machine joins with one install and one claim.
  Metric: acts from clone to first claimed iteration. Target: two.

## Unlike

Workflow engines - BPMN suites, Temporal, n8n - run flows but carry no
evidence discipline: no refusable claims, no gates a person blesses, no
cage on the agent. And what the AI crowd ships as an "ontology" is a
schema with no teeth - ours refuses. The difference is that this engine
attaches CONSEQUENCES to the drawing: a state refuses tools, a gate
refuses passage, a claim refuses collision.
