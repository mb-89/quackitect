## Mechanism

THE FOLDER IS TREATED AS ONE THING TODAY and it holds parts with different
owners. Dividing it means each part resolves by its own rule.

- WHAT BELONGS TO THE MACHINE. The declared roots, saying which trees this
  machine may drive. Strays, captured anywhere and belonging to no record.
- WHAT BELONGS TO A RECORD. The calls made while walking it. The position the
  walk stands at.

## Why this delta raises it

THE STANDING RULING PINS THE WHOLE FOLDER TO THE MACHINE, on the reasoning that
session state belongs to the machine rather than to a branch. That reasoning is
about DEPTH being irrelevant, and the iteration's own vision says so.

THE COLLAPSE MAKES DEPTH RELEVANT AGAIN. Once the folder sits inside the opened
folder, a worktree per branch gives a folder per branch. The vision already
names the risk and asks for a test pinning resolution to one place.

SO THERE ARE TWO ANSWERS AND ONLY ONE IS WRITTEN DOWN. Pin everything to the
machine, which is the incumbent and what the test would fix. Or divide, and pin
only the parts that are actually machine-scoped.

## What it buys

THE TEST GETS SOMETHING TRUE TO ASSERT. A test that pins the whole folder to one
place is asserting a rule some of the contents do not want. Two calls made
against two different records land in one log today, and telling them apart
afterwards is work.

IT ALSO ANSWERS A QUESTION THE INCUMBENT DODGES. Which record does a call
belong to. Under this option the answer is where the file is.

## What it costs

TWO RESOLUTION RULES INSTEAD OF ONE, inside a function whose whole job is saying
which tree a path names. [[opt-one-resolution-seam-not-a-rule-per-tool]] argues
the opposite direction and is on the same chart.

IT IS NOT THE SAME AS [[opt-resolution-varies-with-the-path-kind]]. That option
varies by the KIND of path a caller passes. This one varies by what the file
is FOR, which the caller never states.

THE DIVISION LINE IS NOT OBVIOUS. Strays are machine-scoped and calls are
record-scoped, and the walk's own position sits between them. It is bound to a
record and read by a machine, and this option does not settle which side it
falls on.
