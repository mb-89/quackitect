## Mechanism

THE SUBJECT is the pull, and the operator is REVERSE. Today the agent asks
and the machine answers. Inverted, the machine decides a step is ready and
pushes it to a listener.

WHAT CHANGES. The walk stops depending on somebody remembering to ask. A
session that dies mid-step leaves work the machine can hand to the next
listener, rather than work nobody knows is owed. The mirror already pushes —
it holds an event stream and wakes the page — so half the machinery exists on
the wrong side of the boundary.

WHAT BREAKS. The pull's whole value is that it is ONE verb with nothing to
learn. A push needs a listener, a registration, and an answer for what
happens when nobody is there. That is three concepts where there was none.

It also removes the agent's ability to pace itself. Reading, thinking and
tool use happen between pulls today, and a pushed step arrives whether or not
the last one finished.

WHY IT IS STILL A CELL. Unattended running is a named capability, and the
push shape is how every other unattended system works. A candidate that wants
the walk to survive an absent agent has to answer this, and answering it with
"the agent asks more often" is the answer that has already been tried.
