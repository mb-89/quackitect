## The contradiction it breaks

An agent that knows its output is discarded does not behave as it does on real
work, so the number does not transfer. Blinding it would fix the transfer and
would require the machine to lie to the agent it governs.

## Why system level dissolves it

The conflict is only irreducible at the level of the RUN. One level up, at the
level of what the result CLAIMS, it disappears: a number that says it measures
process overhead rather than production behaviour is true either way.

## What it costs, stated rather than hidden

The number understates. It is a floor rather than an estimate. The paired delta
survives because the same bias sits on both sides of a pair.

## Mechanism

A standing sentence on the report template, and an open assumption on the
register carrying the bias direction.
