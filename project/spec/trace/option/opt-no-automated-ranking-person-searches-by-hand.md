## Mechanism

The trim question: does rank-candidate-couplings need to exist? Today,
finding "what in the corpus resembles this change" is a person's or agent's
own se_file_search/se_file_glob sweep, read by eye.

IT STAYS, on the evidence this very walk generated. Locating this
iteration's own related nodes (existing clusters, flows, the ADR) took
several manual searches and direct reads earlier in this session precisely
because nothing ranks candidates automatically. That is the gap
rank-candidate-couplings exists to close — the ENVIRONMENT (a person
reading search hits) already does the job, but at a recall cost nobody has
measured, which raid-asm-i15-query-plus-rows-earns-trust already flags as
unresolved.

The null option is not free, though: it costs zero build effort and keeps
disposal entirely manual, so record-a-coupling-disposition's own
forced-disposition guarantee would have nothing automatic feeding it.
