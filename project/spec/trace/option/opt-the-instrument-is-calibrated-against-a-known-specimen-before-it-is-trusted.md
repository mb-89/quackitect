## The abstract problem it answers

Tell a real zero from a broken instrument.

## Why it transfers hard here

This walk needed it twice in one session. A rigor-matrix search returned
nothing and was read as no-rows-match; it was an unpaid-toll refusal. A probe
of 60 files returned all-present and was read as a falsification; it was the
same refusal counted the other way.

The probe that stands only stands because a control search for a DIFFERENT
iteration returned 123 matches at the same ref.

## Mechanism

Every absence-shaped measurement runs a paired positive control, and the
result records both. An absence without a control is not recorded as a
finding.
