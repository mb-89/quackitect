## Mechanism

Seeding already creates it/<id> with the record stub; pushing that
branch in the same act makes existence visible to every peer's fetch.
No second artifact, no index to drift - the branch list IS the pool.

WHAT IT COSTS HERE: nothing new - the branch exists today, unpushed.
The alternative (a seeds index file) is one more thing to keep true
against the branch list it summarizes.
