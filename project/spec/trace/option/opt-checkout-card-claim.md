## Mechanism

Circulation systems solved shared-pool checkout a century ago: the mark
travels with the item, shows who and since when, and anyone can see a
book is long overdue - but only the desk recalls it. Transferred: the
claim file carries machine id and time where every surface shows it,
staleness is visible to anyone, and the recall stays a person's act.
What deliberately did not transfer: due dates - work has no return date,
so overdue is a judgment, not a threshold.
