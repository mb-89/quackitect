## The contradiction it breaks

A full re-walk is the honest measurement and costs a day. A short run is
affordable and is not comparable with a full one. Trading them gives up either
the budget or the comparability.

## Why condition dissolves it

Comparability is not a property of length; it is a property of comparing like
with like. A run that records where it stopped can be paired with another run
that stopped in the same place, and refused a pairing with one that did not.

## And it makes a failure into data

Where the machine stops an agent is exactly what this iteration exists to
measure, so a run that could not continue is a measurement rather than a waste.

## Mechanism

Two fields on the report — the stop point requested and the state actually
reached — and a pairing rule that reads both.
