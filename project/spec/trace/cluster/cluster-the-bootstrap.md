## Rationale

ONE FUNCTION, AND IT COUPLES TO NOTHING. That is the finding rather than an
embarrassment.

Standing a product up runs before the system it stands up exists. It consumes
a bare computer and a template, and every other function in the tree consumes
something the running system produced. There is nothing for it to be coupled
to.

A SINGLETON CLUSTER IS ALLOWED TO SAY SO. Folding it into a neighbour to
avoid a cluster of one would assert a coupling the matrix does not show, and
every candidate would inherit that assertion.

TWO OF ITS OUTPUTS ARE CONSUMED BY NOBODY. The toolchain and the scaffolded
product appear in no other function's inputs. The scaffolded product is very
likely the repository under a second name, which is a gap in the flow set
rather than a missing function, and it is carried as a follow-up.
