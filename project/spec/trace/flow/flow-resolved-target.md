## What it carries

The call arrives naming a path. It may name a path more than one tree can
answer - the bound record's, the trunk's, another record's, the machine's
own session folder.

THIS FLOW IS THE ANSWER TO WHICH ONE, made explicit so nothing downstream
has to infer it.

## Why it is a flow and not a detail

Because two functions have to agree about it. One decides; the others act
on the decision. A flow node is how two functions are connected by
construction rather than by both happening to be right.

Before this existed, the decision was implicit and the disagreement was
silent: on 2026-08-13 two paths outside the project folder resolved two
different ways within five minutes, and neither rule was written anywhere.
