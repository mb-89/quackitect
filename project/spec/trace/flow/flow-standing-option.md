## Why it is material rather than a signal

IT IS A THING THAT PERSISTS AND IS READ AGAIN. A signal is consumed by whoever
it reached; this crosses the boundary of the machine that produced it and is
still there when that machine is gone. That property is the whole proposition
it serves.
