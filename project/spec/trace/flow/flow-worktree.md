## The name outlived the thing it was named for

THIS FLOW WAS A RECORD'S OWN WORKTREE, and i34 deleted worktrees. It is kept
rather than removed because the FLOW is still real: unfinished work still has a
place, and `resolve-a-path` still consumes it. What changed is that the place
is now the one tree, so the flow carries a constant.

A CONSTANT IS NOT INFORMATION, and that is the honest reading. Renaming it is a
structural act belonging to decompose-structure rather than to a build chunk,
and it is named here so the next pass over the structure faces it.
