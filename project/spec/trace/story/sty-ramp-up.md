## Deck

An engineer has heard about quackitect and has nothing installed. A laptop, a browser, and no idea where to start.
|||

---

They clone the repository into a folder and open a terminal there. One script sits in the root, and its name is the loudest thing in the folder.
|||

---

The script installs the editor extension, starts the engine, and opens the workspace. It asks for nothing else. There is no configuration step, no key to paste, no service to sign into.
|||

---

The editor opens on the project folder. THAT FOLDER IS THE PRODUCT. The choice was made by which folder they opened, and no screen asked them to pick one.
|||

---

The panel appears beside the editor. A state machine is drawn on it, one node lit, and a slider sits above the drawing.
|||

---

The agent boots on its own. It reads the contract, then the method it owes, and then it stops — because nothing has been asked of it yet.
|||

---

The front desk greets them by name of role, not by backlog: "Tell me what you need — in your own words." Under it, a short list of what is actually walkable this minute, generated from the live machine rather than written down anywhere.
|||

---

From an empty machine to a system waiting for one sentence. One script, one folder, no configuration. Every other story in this set begins here.
|||
