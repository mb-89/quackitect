## Deck

Mid-build, the agent sees that the neighbouring module carries the same bug. Chasing it abandons the state in hand. Ignoring it loses the finding for good.
|||

---

The agent writes one note and keeps walking. No permission asked, no state left, no plan rewritten.
|||

---

The note joins the inbox. The desk sees it, the survey counts it, and the count is on the person's screen — so it cannot quietly rot.
|||

---

At the retro the note is CHECKED before it is judged. Most of what pends turns out to be already built, and the code answers in seconds. Then it drains into exactly one home: done, obsolete, carried or backlog.
|||

---

Nothing was chased and nothing was lost. The inbox is a working set with a floor, not a graveyard.
|||
