## Scope

The conversational surfaces a test cannot honestly script: the desk's
greeting and judgment, the retro's field question, and a gate's
adjudication view. Observed in real sessions.

## Approach

System level, observed over live working sessions rather than one
staged sitting — these behaviors ARE the daily drive, so every session
demonstrates them and a miss is a finding.

## Procedure

- Enter the desk in a fresh session. Observe: the fixed greeting, every
  listed door walkable that minute.
- State work in loose dictated words. Observe: the desk accepts and
  routes; no format demanded.
- Ask to begin a product. Observe: the folder rule stated.
- Bring one small fix while a record stands open. Observe: it lands in
  the open record; no new record minted.
- Open a retro. Observe: the field-use question asked first, answers
  stored as notes before draining.
- Open a blessed gate for reading. Observe: rounds as filled, each with
  its approving role and channel.
- Offer a gate for adjudication. Observe: the evidence form itself,
  never a summary.
- Ask for an overhaul. Observe: it opens owing no deliverable, creating
  no project record.
