## Why likely

THE OWNER RULED ON 2026-08-18 that cloud iterations run completely by
themselves, and raised the dial to make it so. Every such run captures strays -
this one captured three in its first ten minutes - and each is a candidate for
the pool.

SO THE VOLUME IS NOT SPECULATIVE. It scales with how much unattended work
happens, and the direction of travel is more.

## What is NOT the mitigation

A REVIEW QUEUE FOR AGENT-FILED OPTIONS. That rebuilds the inbox this iteration
exists to drain, one level up.

## What is

THE REWRITE IS THE JUDGMENT, AND THE AGENT PERFORMS IT. Ruled at M1, conflict
three: the agent does the same act a person does, not a lighter one. An agent
that cannot state its finding cleanly files it as an open question rather than
as a guess.

WHAT IS DELIBERATELY LEFT OPEN, and it is a requirements question rather than a
vision one: whether an agent-filed option carries a different status from a
person-filed one. Inventing that field at the vision is how a mechanism grows
one nobody needs.
