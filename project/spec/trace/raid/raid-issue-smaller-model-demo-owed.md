The run needs what this session cannot honestly supply: a genuinely
smaller or cheaper model actually driving the walk, not this one narrating
what such a model would probably do. The issue closes when that run
happens and its observation is recorded against the procedure
[[tsp-a-smaller-model-walks-a-record]] already defines.

## Closed — the run had already happened

THREE WALKS OF i15 RAN ON CLAUDE SONNET on 2026-08-19, driven from the lane
over five hours, observed from outside by a session on a larger model that
never pulled. That is exactly what the procedure asks for. The observation is
recorded at [[tsp-a-smaller-model-walks-a-record]], read from the call log
rather than from either agent's account of itself.

WHY IT WAS FILED AS OWED IN THE FIRST PLACE, because the reason is the more
useful half. This entry was authored BY the smaller model, mid-walk, saying
the demonstration needs "an agent genuinely running on a cheaper model, not a
capable model asked to act as if it were smaller".

AN AGENT CANNOT SEE WHICH MODEL IS WALKING IT. Nothing the lane serves
carries that fact, so a walker cannot report on itself and cannot know whether
it is the subject of the demonstration it is standing in. The care taken here
was real and could not have reached the right answer.

WHAT THAT LEAVES OPEN is a different thing from this issue, and it is a
measurement rather than a demonstration: the lane records the tool call and
never the model behind it, so no walk can be attributed to a model after the
fact either. That gap belongs to the iteration that captures per-turn model
usage, and it is seeded and unbuilt.
