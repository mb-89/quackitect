## Detail

THIS ROW ANSWERS THE QUESTION M1 LEFT OPEN. draft-vision ruled that the filing
is cheap and the judgment IS the rewrite, and deliberately did not decide
whether an agent-filed option carries a different status. It does not. There is
one act, one set of demands, and no field marking who made it beyond the
authorship the record already keeps.

WHY inspection AND NOT test. What is being checked is that no second path
EXISTS. A test proves a path behaves; only reading the doors proves there is
one door. The mint's lifecycle row says the same thing from the other side.

## Pass line

Metric: code paths that write an option node without going through the mint's
demands. Target: zero, established by reading every writer of the option kind.
