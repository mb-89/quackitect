## Scenario

THE SIX PARTS, and the response measure IS this row's pass line.

| part | value |
| --- | --- |
| source | anything asking what work stands open |
| stimulus | the pool holds more options than the answer's bound admits |
| artifact | the answer that carries the pool |
| environment | normal operation, any clone |
| response | a window is served AND the answer says it is a window, with how many stand |
| response measure | answers that omit options without saying so: zero |

WHY should AND NOT must. Nothing breaks while the pool is small, and the pool
starts empty on every clone. It becomes a must the day the migration runs, and
the migration is a non-goal of this record — so this row is written now and
graded honestly rather than being discovered then.

## Pass line

THE RESPONSE MEASURE ABOVE IS THE PASS LINE, repeated here so it is not read
twice as two demands. Metric: answers that omitted at least one standing option
without saying so. Target: zero.
