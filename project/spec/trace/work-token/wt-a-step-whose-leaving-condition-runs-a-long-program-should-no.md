## Why it stands

A step whose leaving condition runs a long program should not freeze the agent's only verb. Measured once at sixty-eight seconds, with two calls timing out at the tool boundary. One of those had partly landed, so the caller was told it failed while it had in fact moved. Wanted is to start the program, reply at once saying it is still going, and hand back its verdict on a later call. The shape already exists one lane over, where a shell command takes a background flag and returns a handle.
