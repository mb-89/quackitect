The panel's answer to several processes. It is the question
cand-os-rooted left open in its own text.

## What crosses

For each live satellite, the record it serves, the machine it
is running including which files came from that record's own folder, and its
walk position.

## Why the machine travels too

Satellites can legitimately run different
machines at once, so a panel that showed positions without versions would
show a system that does not exist. The overrides list is what makes the
difference visible.

## A dead satellite is shown as absent

Never as stale. Content that is
genuinely gone may clear and must say so; a position left on screen for a
process that is gone is the surface lying.
