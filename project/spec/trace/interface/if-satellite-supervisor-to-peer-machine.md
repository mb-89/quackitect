## What crosses

The same as `if-satellite-supervisor-to-cloud-host`: a record handed out to be
walked, and the tree that comes back.

## Why it is a separate node from the cloud host

THE TRAFFIC IS IDENTICAL AND THE TRUST IS NOT. A peer machine is the owner's
own; a cloud host is somebody else's computer holding the whole corpus. Any
demand about what may leave the product differs between them, and one node
carrying both would have to state the weaker demand or state neither.

## Honest status

NO TRAFFIC HAS CROSSED THIS EDGE YET. It is modelled because the boundary set
is meant to be complete, and an edge left out because it is currently idle is
how a boundary set silently stops being the denominator it was built to be.

THAT IS RECORDED HERE RATHER THAN INFERRED from an empty measurement. A
measured zero on this edge means nobody used it, never that it is fast.
