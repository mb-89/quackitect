The crossing the one-declaration decision creates. The walk dispatches a call;
what the machine-state folder IS is no longer knowledge the walk carries.

## What crosses

THE FOLDER'S NAME AND WHICH OF ITS FILES HAVE A STRUCTURED DOOR. Two facts, not
one, because the second is what lets three files stay hidden while the rest
become readable.

## Why it is a call rather than a read

THE ANSWER IS GENERATED, and a generated answer has a staleness question. A call
lets the declaration refuse when its consumers have drifted, where a file read
would silently return whatever was written last.

## What comes back

ONE ANSWER, THE SAME ONE EVERY CONSUMER GETS. That identity is the whole point of
the decision this interface serves.
