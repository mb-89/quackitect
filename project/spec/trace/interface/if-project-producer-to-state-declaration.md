The crossing that makes the produced tree's exclusion derive rather than repeat.

## What crosses

WHAT MUST NOT TRAVEL, and it is a smaller answer than it used to be. The winner
builds the copy from an include list, so this crossing tells the producer what is
never on that list rather than handing it a deny list to apply.

## Why it exists at all under an include list

BECAUSE THE TWO MECHANISMS ANSWER DIFFERENT QUESTIONS. The include list says what
belongs in the copy. The declaration says what the machine-state folder is. A
file can be absent from the first for ordinary reasons and must be absent because
of the second, and only the second is a rule somebody could get wrong silently.

## What the probe already settled about it

BOTH PRODUCING ACTS ALREADY RUN ONE SHARED FILTER, measured, which withholds the
folder by name at any depth. This crossing replaces that filter's hardcoded name
with a generated one. It is a small change on a mechanism that already works.
