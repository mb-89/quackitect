## Interface

The handoff at the far end of the walk: a signed architecture and a design
input register, in plain markdown, that an output tool reads as its brief.

There is no integration to build and none is wanted. THE OUTPUT END IS OPEN
BY DESIGN — the signed non-goals say this product never competes on
producing code or CAD, so the interface is deliberately a document rather
than an API.
