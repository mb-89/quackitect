An LLM pipeline that runs the TRIZ reasoning loop end to end.

Its related-work section names three knowledge-based ideation methods worth
automating. Those three are SCAMPER, Design Heuristics and Design-by-Analogy.

Cited by [[meth-scamper]], [[meth-heuristics-catalog]] and
[[meth-analogy-transfer]] as evidence that each method is a current automation
target, never as evidence that it works.
