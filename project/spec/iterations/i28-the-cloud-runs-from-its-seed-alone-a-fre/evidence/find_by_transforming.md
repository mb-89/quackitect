## anything_else

### Why the incumbent was the only subject

THE OPERATORS COULD HAVE RUN AGAINST FIVE CLUSTERS AND A DOZEN OPTIONS, which is sixty or more cells. That is not thoroughness, it is a table nobody reads.

THE METHOD SAYS "EVERY SUBJECT WORTH TRANSFORMING", and this iteration has exactly one incumbent: a worktree created at seeding and never removed, with the disk answering what is open. Every option on the chart is a transformation of that one thing.

RUNNING THE CATALOGUE AGAINST the-holding-pen OR the-account would have produced twelve rows of `nothing` and looked like diligence.

### The overlap with trimming, which the guidance predicted

ELIMINATE AND SUBTRACTION BOTH REACHED THE NULL OPTION that find_without had already reached. The state's own guidance says that is fine and that the null option is worth arriving at twice.

IT IS WORTH MORE THAN FINE HERE. Two independent finders reaching the same option is the closest this method gets to a second opinion, and the null option is the one the method says has the highest value and the lowest proposal rate.

### What a yield of one means

THIS FINDER RAN SIXTH OF SEVEN. Prior art, heuristics, trimming, contradiction and analogy had already swept the same cone, so most of what twelve forced operators can reach was already a node.

THAT IS AN ARGUMENT FOR THE FAN, not against this finder. Had it run first it would have found more and the others would have found less, and the set would be the same.
