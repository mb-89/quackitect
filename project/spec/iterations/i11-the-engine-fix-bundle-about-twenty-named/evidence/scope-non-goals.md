## scope

THE BUNDLE TAKES ON ONE SURFACE: what a lane call costs. Every item below is a call that produces no information, or a payload nobody reads.

### The payload

- The pull TRIMS as well as pages. Field names, grammars and hints ride; the ten null argument slots per field and the static template metadata do not.
- The form stops being sent twice in one response.
- Anything larger serves BY REFERENCE with offset and limit, the way se_file_read already does.

### The verbs

- se_test blocks or pushes instead of handing back a job id, and the full battery is refused outside verification. THESE TWO SHIP TOGETHER — raid-dec-blocking-and-the-battery-refusal-ship-together.
- The battery answers in the same parsed shape a scoped run already answers in.
- se_amend patches with old text and new text instead of taking a field whole.
- se_why names the ROOT of a ripple in one answer.
- The file tools agree on their argument names.

### The walk

- `reentry: "restart"` leaves the containers, so a re-entry stops discarding which edges have fired.
- The router stops aiming at a state that is not a legal door — the map-lies defect, confirmed twice today, once at this iteration's own kickoff.
- A state that owes work is reachable BACKWARD, so recovery stops costing an escape and a re-entry.
- A finding routes into the bucket: an owed item names an OPEN raid entry with an owner, and the close blocks while one stands. Both halves, or rule 4 wins instead.

### The acts

- Before a node is deleted, the engine names what points at it. One slice pulled forward from i18.
- The mirror gets two buttons: a FREEZE that stops the agent moving any state, and a BLESS separate from it.
- The narration toll gets its grace, and a chained `fork` brief is corrected the way a chained `update` brief already is.
