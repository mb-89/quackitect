## goal_system

Measured the same day — 2,850 calls, of which building was 7%.

### The conflict this delta creates, named openly

PACE PULLS AGAINST THOROUGHNESS, and pretending otherwise is how a speed iteration ships a hole. Four items in this bundle each buy time by giving something up.

- Refusing the full battery outside verification gives up the agent's freedom to check whenever it feels uneasy.
- Trimming the pull payload gives up shipping everything the agent might want.
- Blocking instead of polling gives up the ability to work while a long run finishes — unless the piggyback half lands with it.
- THE BUCKET GIVES UP THE MOST: a known defect rides while the work continues.

### The ruling: thoroughness wins on correctness, pace wins on ceremony

THE TEST IS WHETHER THE THING REMOVED PRODUCED INFORMATION. 428 polls asking "are you done yet" produced none. Null field-args in every pull payload produce none. Resending 207 register rows to change three produces none. Those are ceremony and pace wins outright.

A CHECK IS NEVER CEREMONY. Nothing in this bundle removes a check, weakens a coverage law, or lets a gate pass on less evidence. Refusing an agent-initiated battery does not run fewer batteries — the engine still runs it at verification, which is where the row already says it belongs.

### The bucket is the exception, and it is ruled rather than waved through

IT GENUINELY CONFLICTS WITH A STANDING RULE. Contract rule 4 says a defect in the work you are building is not a stray — a hole in the thing under your hands IS the work. The bucket says: name it, and if it breaks nothing, carry on.

THE RULING: the bucket wins ONLY where the disposition is agreed and guarded. NASA NPR 7123.1 is the precedent and it is precise — a review completes when every finding has an agreed DISPOSITION, not when every finding is fixed. Agreed, not asserted.

SO THE GUARD IS PART OF THE FEATURE, not a follow-up. An owed item points at an OPEN raid entry carrying an owner, and req-close-refuses-loose-ends blocks the close while any stands. Both ends already exist in this system and neither was used once in i34. Without both halves, the bucket is a way to ship broken work quietly, and rule 4 should win instead.

### No new goal, so no escalation

A DELTA NEEDING A NEW GOAL WOULD BE ARGUING FOR A NEW VISION, and this one does not. It makes an existing promise true rather than making a new promise. That is the same test that put the change size at minor.
