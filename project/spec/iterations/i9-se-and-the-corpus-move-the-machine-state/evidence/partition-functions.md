## follow_up

THE BOOTSTRAP AND THE ARRIVAL CLUSTERS NOW SHARE A FLOW, and design should look at it rather than inherit it silently.

Both clusters end at the same place: a lane that answers. The bootstrap cluster reaches it by opening a folder on somebody's own machine. The arrival cluster reaches it by preparing a checkout nobody is watching. They were separate because one had a person present and the other did not.

THE NEW FUNCTION MAKES THAT SEAM VISIBLE. bring-the-product-up produces the live lane, and the arrival's hand-over-the-means-to-call consumes it. Two paths now converge on one flow.

WHETHER THAT IS ONE FUNCTION OR TWO IS THE DESIGN MILESTONE'S CALL, and this state deliberately does not make it. Folding them would mean a person opening a folder and a hook preparing a container run the same code, which is attractive and is not obviously right — the consent question differs, and so does what may be assumed present.

NOTHING ELSE MOVED. Seven clusters are untouched by this delta, and the eighth gained one member.
