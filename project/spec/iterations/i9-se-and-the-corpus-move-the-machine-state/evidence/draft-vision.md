## goal_system

INHERITED, NOT REDRAWN. This is a minor, so the big idea, the to-be world and the pitch stand untouched by pointer. What follows is the delta only.

TWO CONFLICTS BETWEEN STANDING GOALS, BOTH RULED HERE.

### One: the marker must be committed, and machine-local state never is

THE STANDING RULE IS EXPLICIT AND IN TWO PLACES. `.gitignore` line 1 reads "machine-local — never committed", and the README tells every newcomer the same thing at line 31.

THIS ITERATION'S MARKER GOAL NEEDS THE OPPOSITE. A clone finds the folder only if something inside it is committed. Git tracks files, never directories.

SO THE TWO GOALS PULL AGAINST EACH OTHER DIRECTLY, and the pull is not cosmetic. One says nothing in that folder reaches version control. The other says something must.

THE RULING, and it keeps both true rather than dropping one. COMMIT EXACTLY ONE FILE, and let its entire content be the instruction to ignore everything beside it.

WHY THAT IS NOT A BREACH. The committed file carries NO MACHINE STATE. It holds a catch-all and a negation of itself, and it is the same on every machine that ever runs this. Nothing local, nothing private, nothing that differs between two clones.

SO THE RULE SHARPENS RATHER THAN BENDS. Machine-local CONTENT never enters version control. The folder's EXISTENCE is not content.

AND THE WORDING FOLLOWS. `.gitignore` line 1 says "never committed" of a folder where one file now is. That sentence gets rewritten in this iteration, or it becomes the next reader's contradiction.

### Two: legibility pulls against the structured door

THE STANDING GOAL IS THAT SOME THINGS ARE READ THROUGH A DOOR. The call log, the notes and the reading each have a verb that serves them with structure, ordering and paging. Reading the raw file instead loses all three.

THIS ITERATION'S GOAL IS THAT THE FOLDER STOPS BEING INVISIBLE. Today the lane hides it wholesale, and that costs three concrete things the record names.

THE RULING: HIDE WHAT HAS A DOOR, SERVE WHAT DOES NOT.

WHY THE CONFLICT WAS NEVER REAL, once stated properly. The door rule is about THREE FILES. Hiding the whole directory was a proxy for it, and the proxy over-reached onto every other file in the folder. A proxy that catches more than its rule is not the rule.

THE EVIDENCE THAT IT OVER-REACHED. The retro method instructs a read of a timings file the lane forbade until today. The agent could not read back a declaration its own header says it maintains. Neither file has a door, and neither was ever meant to be hidden.

### No new goal is needed, so no escalation

THE MARKER MECHANISM IS AN OPEN CHOICE rather than a new goal. Two mechanisms serve the marker goal that already stands, and picking between them is design work at the next milestone.

ONE OWNER ASK ARRIVED TODAY AND IS NOT A GOAL HERE. The installer should run once, with the editor as the only entry point afterwards. It is captured as a note and belongs to another record. Naming it here so it is visibly out rather than quietly absent.
