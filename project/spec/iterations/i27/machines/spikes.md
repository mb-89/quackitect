# The spike drawing

One timeboxed probe per unknown picked at rank-unknowns. Four were picked out
of seventy-six live register entries.

They are independent and all hang off start. The join waits for every one.

## What each probe settles

- ONE SEAM asks whether the seam every candidate leaned on can actually exist.
  Every lane verb must reach storage through one place, and the shell is the
  case that broke the last guard. The i8 field report of 2026-08-12 records
  that bypass, and this session found a second instance: se_lint resolved a
  path against the record's worktree while the file tools served it from the
  machine root, with nothing on either answer saying which.
- CHANNEL COST asks whether the core can own what the architecture says it
  owns. The mirror already serves over HTTP, so a read-mostly surface is
  proven. The call log is written on every single call and is not.
- SATELLITE START asks the one number every figure on the board excludes. It
  also decides what a satellite is, and record-adrs says four scored axes move
  with that choice.
- INFLIGHT DEATH asks the architecture's own open question. el-satellite-
  supervisor names it and does not solve it, and no single-process line ever
  had to answer it.

## What a probe owes

The measurement, and the register entry's status moved by it. A probe that
settles nothing says so, and the entry stays open with what was learned.

TIMEBOXED, per [[meth-spike-tracer]]. A probe that overruns reports what it
has and hands the rest back as a finding.

## What none of them is

None of these is the build. A probe answers one question with the smallest
thing that can answer it, and it is thrown away afterwards.
