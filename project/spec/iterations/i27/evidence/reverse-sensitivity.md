WHY THIS STATE KEEPS FINDING THE FLIP OUTSIDE ITS OWN COLUMNS.

THIS TIME it is an assumption about the hardware, which no axis measures because it is not a property of any candidate. cand-core-satellite is better than its rivals if work can be spread across cores, and no better if it cannot.
