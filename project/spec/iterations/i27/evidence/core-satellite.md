# Evidence form / core-satellite

## current_situation

cand-core-satellite is composed. Three sections written into the candidate
note, nothing minted from here.

THE SEAM THAT DECIDED THE SHAPE is the split. What must be one thing, and what
belongs to one agent. Everything else follows from where that line falls.

- THE CORE holds the mirror, the claim ledger, the note inbox, the call log,
  the routing, and trunk.
- A SATELLITE holds one agent's walk, their bound record, and the engine code
  they are running.

THE QUESTION THE OWNER RULED FREE IS ANSWERED HERE EXPLICITLY. A satellite
loads its engine code from the record's own tree. The owner ruled on
2026-08-14 that a record carrying the machine it may change is not forbidden,
and this line takes that door rather than leaving it open.

WHAT IT SOLVES THAT ITS NEAREST RIVAL DOES NOT. cand-os-rooted puts one
process per record and then records, in its own text, that the machine-wide
shared state has no owner and that neither way of giving it one is designed.
That undesigned wall cost it five of its twelve cells. Here the wall is the
design.

## follow_up

THE START-UP NUMBER THIS LINE NEEDS IS STILL MISSING. 67 ms cold per process
and about 36 ms warm were measured on 2026-08-14 with the engine module load
NAMED AS EXCLUDED. The excluded part is the part this line pays per record.
That is a probe M6 can run cheaply and it should be named rather than
discovered.

THE THROUGHPUT ARGUMENT IS UNPROFILED AND IT IS THIS LINE'S STRONGEST CLAIM.
raid-asm-the-target-machine-is-many-throttled-cores says the target is about
twenty cores at 2 GHz, and this is the only shape besides cand-os-rooted that
can use more than one of them. Nobody has profiled where the time goes. If the
slow calls are IO-bound the argument is worth nothing.

PARTIAL FAILURE IS UNDESIGNED. One process either runs or does not; a core
with N satellites has states in between, and no other line has to answer for
them.
