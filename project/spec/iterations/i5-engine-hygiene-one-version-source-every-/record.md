# i5-engine-hygiene-one-version-source-every-

## Goal

Engine hygiene: one version source, every refusal anchored to its guidance, the sync sweeps duplicates, the slow test file splits, and the paint rules get their pin.

## Rough vision

The small standing debts, bundled to a day - each mechanical, none blocking the others.

- The version reads from package.json once; the four 3.0.0-bootstrap stamps go (note-4c4a3f8bb8a5).
- Every refusal clause carries a guidance anchor, a test refuses an unanchored clause, and the Rejection payload links its rule (note-bacff107e302, owner ruling 2026-08-06).
- se_git_sync runs the duplicate-key sweep over the merged tree and reports every hit at once (note-6491ca1887b0).
- refs.test.ts splits by theme - 153 seconds summed, the battery's heaviest file (note-e0dcdfe20aee).
- The paint rules (green is submitted, thumb is blessed, law-proven greens) get their test pin (note-b4544437d0c9).
- The whole-battery guard design: gates-only enforcement stands, the se_run hole and the poll cadence want their ruling (note-c545177dff77, note-7a5a9beb2fc3).

Independent of every sibling iteration.

FROM THE POOL, 2026-08-13. Seven more, each already diagnosed.

- A PACKAGE PROVES ITSELF WITH A VERSION FLAG (owner ruling, note-1023a7f62f6d). A package is a zip carrying a README and a RUNME. Run the installer, then ask the entrypoint for its version. That proves the installer ran, the entrypoint resolves, the code loads, and the version is the one intended. It does NOT start a server, so a startup-only defect passes - accepted knowingly, because running what the package built destroys the lane it runs in. No such flag exists today. Three pieces: the flag, the version source above, and the release step running it after the install.
- A CHECK REPORTS IN THE WORDS OF THE QUESTION IT ASKED (owner ruling, note-acd0547758a2). A leave condition may ask something additional, and may reference what the submit accepted. It may not ask the same thing differently. The observed defect was worse than repetition: the leave check ran a ripple and reported it in the SUBMIT's words, so a form with nothing wrong with it was resubmitted, rewritten and reformatted, while the engine knew all along which INPUT had fallen. Mislabelling is worse than repeating.
- A SILENT FALLBACK HID A MOVED FILE (note-13b3b5ae5a93). The palette reader catches a failed read and returns a default, so a moved file rendered as an almost-empty palette and surfaced two layers away as a missing variable. The comment above it claims preflight guards it, and preflight checks its OWN copy of the path, so both go stale together. Let preflight ask the READER where it looked.
- A WIRED-UP OFFER THAT RESOLVES TO NOTHING IS INVISIBLE (note-306a7034f873), the same silence one class wider. A per-item field over an empty source falls through to a plain textarea. A dependency matrix over no functions draws an empty grid. A comparison card over an empty pool reports every pair settled, which the code's own comments call the worst way to be wrong. THE RULE: a field whose live source is empty says so, in the field, naming the source.
- THE FEED GUESSES THE ACTOR FROM A TOOL NAME (note-a2ed1eb79e9d) where the handler already knows it. The guess was wrong for fifty-two records, and a new server-side tool reads as a person until somebody remembers to add it. Stamp the actor where the call is made.
- THE WRITE RATCHET STANDS AT 36 direct write sites (note-8ec15d39c18b): 18 in the session module, 4 in iterations, 3 in bases. It may fall and cannot rise. A site whose file the door can never hold may stay direct, with the ceiling lowered around it.
- THE WALK SIGNS STATES WITHOUT COMMITTING THEM (note-7112f62ea40c). Seven signed states and 36 minted nodes stood disk-only until a manual checkpoint. A signature that lives only on disk is weaker than the word suggests. The engine takes a checkpoint commit on the record's branch at every signing.
- THE LOG GARBAGE COLLECTOR, last survivor of the 2026-07-27 backlog (note-792c32b5425e).
