## current_situation

Eight new requirement rows want functions. Two functions carry all eight, both inside existing clusters, and the flows between them close.

THE ESCALATE TEST WAS APPLIED FIRST, because it is the one that would change this iteration's column. A new function that fits no existing cluster is the architecture moving. Neither of these is: the mint sits in `the-holding-pen` beside hold-a-stray, which is where a stray already lives from capture to disposition, and the offer sits in `the-record-life` beside route-the-work, which is where what-to-do-next already lives. Putting either in a new cluster would have been the tell that this is a major, and neither wanted one.

Neither extends to cover what these do.

## neutrality

THE TEST IS ONE QUESTION AND BOTH WERE PUT TO IT: could two honestly different designs do this?

mint-an-option — "turn a held stray into a durable option that can leave the machine that captured it". YES, AND THE RIVAL IS NAMED: a hosted store with an API, which is what every tracker in the prior-art scan does. Nothing in the statement says file, repository, format or commit.

WHAT WAS ALMOST WRITTEN AND WAS NOT: "write an option node onto trunk". That names a technology twice. It would have collapsed M4's candidate space to the one point that raid-asm-the-pool-is-a-node-kind-under-project-spec exists to keep falsifiable — and an assumption nobody can falsify is not an assumption.

offer-what-may-be-taken-up — "put every standing option in front of whoever is deciding what to do next, wherever it was parked". YES. No surface, no query language, no store. It holds for a rendered panel, a lane answer and a printed list alike.

THE THIRD TELL WAS THE ONE TO WATCH, because no word list catches it: a function that only makes sense given one design. Asked of both by naming a design we rejected — the hosted tracker — and both survive it. "Leave the machine that captured it" is a demand a hosted store satisfies trivially; "wherever it was parked" is a demand it satisfies by having one store. Neither statement needs our answer to be readable.

WHERE A SOLUTION IS GENUINELY FORCED it is a constraint, not a function, and this delta has two of them in the register rather than in the tree: the raw note never entering version control, and there being no lighter path for an agent.
