## sweep

- environment: ONE — raid-asm-a-node-file-per-option-holds-at-the-sizes-this-pool-reaches. The shape of the data is what this source asks about, and the delta takes as given that a pool is a few hundred items rather than a few hundred thousand. The number that exists, 205, comes from the seed rather than from a count made here, and this clone cannot verify it because it holds three notes.
- toolchain: NONE, and the reason is that this delta installs nothing and versions nothing. It writes markdown through a writer that already exists and reads it through a reader that already exists. The runtime pin is the arrival's business and is already an entry elsewhere.
- host: ONE — raid-asm-the-corpus-sweep-already-covers-a-minted-option. What the host does that we rely on and did not verify is that prose-inspect's identity sweep walks wherever the pool lands. Half of it IS verified — the code walks project/spec recursively — and the unverified half is that the pool lands there, which is the standing assumption from M0. Recorded rather than folded, because the consequence is a success criterion that would keep reading as met while measuring nothing.
- platform: NONE, and this one was checked rather than waved. The delta's whole surface is file reads and file writes through the lane, which already runs on both platform families, and nothing in the eight rows touches a path separator, a line ending, a process or a port. The nearest platform risk in the system — the POSIX branch of the lane spawn — is exercised by this very session and belongs to its own standing entry.
- neighbours: ONE — raid-asm-the-drain-is-the-only-door-into-the-pool. The neighbour here is the rest of the engine, and what is taken from a reading rather than from a run is that no other writer of the option kind will appear. Five of the eight rows are demands on the mint, and every one of them is bypassed by a second writer, silently.
- people: ONE — raid-asm-a-verbatim-overlap-check-catches-the-paste-that-matters. This is the only source that is genuinely about behaviour, and it is the one carrying a fatal consequence: the check assumes the copy that happens is a paste rather than a paraphrase. An author under time pressure who knows a paste will be refused will reword the paste, and a reworded private sentence is still private. Written as the claim, not as the subject, so it can turn out false.
