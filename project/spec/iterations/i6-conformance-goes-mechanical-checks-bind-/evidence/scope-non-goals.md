## scope

THE DELTA THIS EFFORT TAKES ON, in the order it takes it. The order is part of the scope, not a preference about it.

### First — the floor, and the measurement

ONE CHECK THAT NEEDS NO BINDING: frontmatter that does not parse refuses at the write. It reads the incoming bytes and nothing else.

IT IS FIRST BECAUSE IT SETTLES THE ASSUMPTION EVERYTHING RESTS ON. raid-asm-a-bound-check-runs-inside-the-write-budget asks whether a check fits inside a write's one-second budget. A check that parses only the string being written is the cheapest check there can be. If that one does not fit, nothing does, and the architecture moves before any code is committed to it.

### Second — the conformance system

CHECKS BIND TO NAMED THINGS: an el- element or a dsp- design spec, ArchUnit's shape, per the parked design.

THEY FIRE AT THE WRITE, per the owner's direction.

EVERY CHECK DECLARES REFUSE OR REPORT, per raid-dec-a-check-refuses-a-wrong-write-and-reports-a-wrong-corpus. A check declaring neither does not ship.

EVERY CHECK NAMES ITS WAY FORWARD, per raid-risk-a-bound-check-refuses-the-write-that-fixes-it. Three shapes are known to work: report instead of refuse, accept a signed answer, carry.
