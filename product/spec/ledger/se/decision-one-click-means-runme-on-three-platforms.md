statement: "OWNER RULING, 2026-07-25, clarifying what one-click installability MEANS. It was being weighed as a criterion without a definition, and it decided an architecture.\n\nTHE DEFINITION: someone clones the repository and runs RUNME. That one act installs everything that needs installing and then starts the system. The owner's words: 'the way RUNME currently works is exactly what I want, but I want all the installations in there too.'\n\nTHE PLATFORMS THAT MUST WORK, named by the owner and closed:\n  - Windows. The primary working platform.\n  - Whatever platform Claude Code uses when run in the cloud.\n  - Whatever platform GitHub Enterprise with GitHub Copilot uses.\nAND EXPLICITLY NOT: 'I don't need support for very exotic Linux distributions.'\n\nWHAT THIS DECIDES, immediately and concretely: it settles the open question at gate_architecture, which asked whether one-click installability is a heavy weight or a VETO that would disqualify the chosen search architecture. It is a weight, AND the risk it was carrying is scoped away rather than merely accepted. The packaged searcher declares twelve platform binaries as optional dependencies with os and cpu constraints, all twelve are recorded in the lockfile, and the install already runs from the lockfile inside RUNME. Windows and glibc Linux - which covers all three named targets - resolve a working binary. The cases that worried the analysis were musl-based Linux and exotic architectures, and both are now out of scope by ruling.\n  CONSEQUENCE FOR THE RECORD: the criterion scores 5 rather than 4 for the chosen design, so it stops discriminating between the two candidates at all, and tripwire T3 (installability turns out to be absolute) is CLOSED. The M5 convergence stands and is better supported than when it was made.\n\nWHAT THIS EXPOSES, and it is a real gap that has nothing to do with the dependency: RUNME is a PowerShell script. On the two Linux targets the owner named there is nothing to click. Its Node bootstrap uses a Windows-only package manager, and its agent configuration writes to a Windows user path. So the one-click promise currently holds on ONE of the three platforms it is required to hold on.\n\nTHE BAR THIS SETS for anything added to the system from now on: a dependency is acceptable if RUNME can install it unattended on Windows and glibc Linux. That is a checkable statement, which the previous unstated version was not."
