## Situation
M8, before the validation gate. The describing surfaces: method notes, task notes, guides, templates, the book chapters, the README - wherever the changed behavior is taught.

## Procedure
- List what the iteration changed (the evidence trail has it).
- For each change, find every surface that describes the old behavior; update or mark it.
- The machine's own notes are surfaces too: a changed practice means the method note changes in the same sweep.
