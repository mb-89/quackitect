# connections — every semantic relation, one home

One subfolder per kind. Two lanes per kind (adr-connection-lanes): `edges.jsonl`
for trivial edges (one JSON line per edge), `con-` notes for prose-bearing ones
(shape: `items/connection.md`). An edge lives in exactly ONE lane. Housekeeping
is determinizer-owned: `quack mint connection`, `quack promote connection`,
`quack connections <id>` (the merged adjacency answer).
