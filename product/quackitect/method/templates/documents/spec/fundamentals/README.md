# fundamentals — the concepts this document stands on

One note per fundamental, shaped by the `item-fundamental` template
(`../../items/fundamental.md`): a one-line `statement:` for the ch2 list, the
full body for ch8, Obsidian-native `aliases:` for the auto-link pass.

The pull law renders them: a fundamental appears in the book only when a
chapter links it. The ch2/ch8 views come from `queries/fundamentals.base` —
the list in ch2, the full bodies in ch8.
