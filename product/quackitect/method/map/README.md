# map: the methodology catalog

One note per named method: its essence, when to use it, and a pointer-level source.
The map is a quiver, not a gate: the agent MAY pull a method opportunistically
(discussions, M3 candidates, reviews); rigor still decides what is mandatory.
The rigor checklists' method lines will reference these entries over time (DRY).
The book renders this folder as a chapter. (req-method-catalog.1)
