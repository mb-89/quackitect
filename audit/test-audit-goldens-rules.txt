## B1. Draft note for a writer of tests

File: `spec/guidance/code/tests.md` (mint it with `mint_note`, per `spec/guidance/guidance.md` rule 11).

```markdown
---
kind: [[guidance]]
tags: [testing]
scope: ["every test a change adds, moves or deletes"]
rationale: [[spec/rationales/testing]]
---

# Actionables

1. Test a behavior once, at the outermost interface that reaches it within rule 15 of [[spec/guidance/code/testing]]. A second test of one behavior fails on the same edit, and every fix pays twice. *
2. Hold a behavior in one layer and one language. The module runs its table, and the wiring runs one case of it. The contract suite of rule 13 in [[spec/guidance/code/testing]] alone runs twice. Where two languages hold one behavior, write the second copy as a finding. [[spec/guidance/working]] *
3. Delete a test in the change that deletes the code it tests. A test over a removed path fails for nothing or passes over nothing. *
4. Delete what compares old and new code in the change that switches its migration phase. That is each twin, parity case, shadow row, old golden section, and guard keeping a removed file gone. A comparison past its switch holds the live code to code nobody runs. *
5. Pin a behavior in a golden file, and keep incidental output out of it. That output is a line count, a size, an unread order, a wording, a hash or the tree's own content. A golden file holding it fails on an unrelated edit, and a hand counts it again. *
6. Keep the test lines of a module at or under its code lines, its fixtures counted. A module past that holds copies of one behavior, and every change pays for each copy. *

# Examples

| the rule | do | do not |
|---|---|---|
| 1 | the draft table run by the module test, and one case of it through the wired quack | the whole draft table run by the module test and again by the quack test |
| 3 | the test deleted in the commit deleting its function | a test of a removed script, standing for its fixture |

| 6 | a module of two hundred lines with two hundred lines of tests | a window module of two hundred lines with two thousand lines of tests |
```
