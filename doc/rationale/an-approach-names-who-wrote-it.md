## decided

A hand writes an approach onto the token it is working.
Where it writes one onto another token, the approach names who wrote it and when.

## why

An approach is a design decision, and the guidance says a reader is meant to disagree with it before the work.
A reader can only disagree with a decision they can attribute.

Measured on 2026-09-06, on wk-08194db257.
One hand working wk-8797959d3c wrote approach sections onto two other tokens, to take a section check from 29 failures to 26.
Both tokens were that hand's own, which the finding did not know and which does not rescue it.
Neither token named an author, so the next hand would read the approach as the minter's.

The count was not the damage.
The damage is a decision entering a token with nobody's name on it.

A rule that forbade it outright was weighed and dropped.
A hand that has just learned something about another token should be able to write it down.
What it must not do is write it down anonymously.

## costs

A section check counting approach sections can still be answered by a hand that is not working the token.
The signature makes that visible rather than impossible, and a person reading the token decides what it is worth.

## revisit when

- the engine records who wrote each section, so the signature is derived rather than typed
- a check refuses an approach that names no author, so the rule is enforced rather than remembered
