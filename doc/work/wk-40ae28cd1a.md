## lesson 1 · round 1 · by reviewer10

**the class:** AN ANTI-VACUITY GUARD PLACED ON THE MEMBER RATHER THAN ON THE SET, WHICH READS AS THE SCOPE BEING GUARDED AND IS NOT. A criterion says every, and the drafter knows that a check which finds nothing to check has to refuse, so a clause is added: it refuses when it finds none. The clause is real, it fires, and it guards the wrong noun. The check drives ONE producer and asserts over the things that producer emitted, and the guard refuses when THAT producer emits nothing. Nothing at all guards the number of producers, which is the only quantity the word every was ever about. It is more dangerous than having no guard, because a reviewer reading the criterion sees the failure mode named and moves on, and because the sentence now carries both the word every and a refusal, which together read exactly like a measured claim. It is worst where the claim happens to be true on the day it is written, since the check is green, the guard is armed, and the boundary is invisible until somebody adds the second producer. Measured on wk-40ae28cd1a: the claim is every command a notice names, the engine builds a notice in 18 places through seven builders, the check reads one of them, and the guard refuses when that one notice names no command.

**instead:** Two halves, and the first is what stops it being made. Before writing the guard, name the set the word every is about, out loud and in the criterion, and check that the guard's noun is that same noun. A guard on the members is a guard on the wrong thing whenever the members come out of one producer, so ask what produces them and count the producers first, because that count is what fixes the check's entry point and the entry point is chosen before anybody thinks about scope. Write the count into the criterion, so the guard and the number sit beside each other and disagree visibly if they ever do. The second half is the check that catches it, and it is one experiment: add a second producer that violates the claim, in a copy of the tree, and run the check. If it stays green the guard is on the member. Do that before agreeing the criterion, because a claim that is true on the day it is written cannot be tested any other way, and running the check against the tree as it stands proves only that today is fine.
