## detail

An agent should name no tool to check its work. Rule 15 of writing-go names four programs and tells the agent to run them. Rule 4 of driving-the-engine says to use the tool the engine gives you. The two rules disagree.

The lint verb reads work tokens and the guidance prose. gofmt, go vet, go fix and golangci-lint sit in util/checks and run when the battery runs. There is no format verb among the engine's verbs.

So nothing formats the tree on demand. A battery run by hand is refused, and the agent is handed the test door instead. Nothing gives an agent the formatter that would settle a red gofmt lane.

A machine without golangci-lint answers differently from one that has it, and the agent cannot tell them apart.

## approach

Two verbs. Format reaches everything it can, which is Go, TypeScript, shell and prose. Lint names everything that breaks a rule, across tokens, guidance, Go, TypeScript and shell. Format runs first, because a formatter settles what a linter would otherwise report.

What each verb reaches is the engine's business and never the agent's. The agent calls two verbs and names no program. A missing program becomes the engine's answer to give, so the agent reads one refusal rather than a tool error.

Rule 15 of writing-go loses its list of programs and names the two verbs instead.

## note

The engine gained a format verb and the lint verb gained the Go. Format runs gofmt over every folder carrying a go.mod, writes what it changes, and names each file. Lint runs go vet and golangci-lint over the same folders, and their findings join the ones about tokens, guidance and processes. The folders are read off the disk rather than listed, so this file and the battery cannot go out of step.

A program the box has not got is a line in refused, not a tool error. The refusal names the program and where to get it. golangci-lint on this box will not start at all. It was built against an older toolchain than the module targets. That reads as a refusal too, rather than as a defect in the tree.

Rule 15 of writing-go now names the two verbs. Format reaches Go only, and the rest is wk-bb6d003644.
