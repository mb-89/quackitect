## approach

What replaces the engine's own reader is the module the viewer already calls, quackitect/filter at src/filter. src/engine/go.mod requires it and replaces it with ../filter. src/engine/internal/expr is deleted rather than left beside it, because two readers of one syntax is what this work exists to end.

It is a rewrite of the callers, not a rename. Expr and Row run through view.go, in its field types and in filterOf, joined, fold, keep, truthy, group, sortRows, columnsOf and Render. query.go builds a Row per token. Each moves onto the row of named values the module reads, and the seven test files that name expr move with them.

The syntax a person types does not change, and the Level 0 ruling is what says so. An invalid expression keeps the last good filter and says it is invalid, rather than emptying the view. That is judged in the heading box, with the extension running.
