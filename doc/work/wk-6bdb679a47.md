## detail

sh util/setup/install.sh --profile headless --no-open dies on Linux with set: Illegal option - because the file carries CRLF. RUNME.sh, util/setup/install.sh, util/cage/session-start.sh and its projection .claude/hooks/session-start.sh are CRLF, and there is no .gitattributes. Add a .gitattributes that pins every executable script to LF, then normalise what is already there. Add a check that fails on a CR in any file the system executes. Nothing else blocks headless: with the files converted the install ran clean end to end.

## done when

- A .gitattributes pins scripts to LF. git ls-files --eol shows no CRLF on the four named files.
- A check fails on a CR in any executed file, seen red first.
