## detail

THE LAST BUT ONE GROUP OF wk-40abb881a7. The call graph there named eleven groups reaching nothing outside themselves. Nine are packages under src/engine/internal. log.go is not: one file of 248 lines holding Log, Record, Current, OpenLog, ContinueLog, OpenExistingLog, RetireCurrent, Yes, No, sessionOf and sessionVar.

It is the widest seam in the tree. se find --regex over Yes(), No(), *Log, Record, Current and the Open calls answers 334 lines in 68 files, most of them tests, and Yes() and No() alone are about 160 of those. Every name in it shares the flat namespace the parent token was written about.

TWO HAZARDS THE MOVE HAS TO CLEAR. A package named log collides with the standard library's, and some fifteen functions take a parameter named log, which would shadow the package inside them. And the test files it touches are the ones other hands edit most, so the move wants a quiet tree.

## proposed action

Move log.go and log_test.go whole to src/engine/internal/sessionlog, named for what it holds. Export Log, Record, Current, Open, Continue, OpenExisting, RetireCurrent, Yes, No, SessionOf and SessionVar. Leave every parameter named log as it is: it is a variable of type *sessionlog.Log and shadows nothing. Rewrite the 334 sites, adding the import per file, then go build and go vet -C src/engine ./... and se test --on this token.

## approach

The package is sessionlog, because log is the standard library's name and record is a function in hook.go. The file moves whole, with its test. The exported surface is the one the callers already use: Log, Record, Current, Open, Continue, OpenExisting, RetireCurrent, Yes, No, SessionOf and SessionVar.

A parameter named log stays a parameter. It is a *sessionlog.Log and shadows nothing, so the fifteen functions taking one change only their type.

The sites are found by the compiler rather than by search. Remove log.go, run go build -gcflags=-e -C src/engine ./..., and every undefined name is a line to rewrite. The untracked test files other hands have open are rewritten last, or the move waits for them to land.
