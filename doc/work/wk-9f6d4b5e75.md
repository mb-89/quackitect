## lesson 1 · round 1 · by reviewer2

**the class:** Moving a declaration to a new home and teaching only the reader its new address. The loader was taught to read groups and pinned at the top of the file; declaresGroup, AddPin and DropPinNamed were left addressing the view, so the screen looked right and every write went into a drawer nobody reads. The evidence checked the screen, which is the half of the round trip that still worked.

**instead:** When a key moves in a file format, grep for that key and move every site that READS it and every site that WRITES it in the same change, then drive the whole round trip through the door a person actually uses - the CLI flag, or the message the client sends - and read the file and the query back afterwards. A loader test proves half a round trip. And put the check where the defect is: a control that writes a file is guarded in the program that writes it, not in the HTML that draws its button.
