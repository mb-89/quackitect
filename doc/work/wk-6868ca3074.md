## detail

A table-driven check built one row at a time leaves the rows nobody has named typed as literals. src/engine/shapes_test.go walks theShapes through helpers named after rows, blockRows, mapRows and headingRows, and src/engine/red_test.go holds a fourth, oneLineRows. Replace all four with one selector that takes the shape as an argument, in every file that reads theShapes. The set of files comes from searching src/engine for the table's name, not from a hand-typed list. When a finding says one row of a table types its members, fix the table and not the row. Related: wk-24be1c06ae, wk-5697d58b1b.
