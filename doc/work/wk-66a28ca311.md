## detail

The editor is not finished. What v3 had and this does not, from reading tables.ts, baseui.ts and basesclient.ts:

TOOLBAR, above the table and outside the scrolling pane: the view name, the row count, Filter (an and-of-ors builder), Sort (group by and sort by level lists), Properties (a column tick list with a find box), and a toggle to the raw .base text. Below the table, a pager. Help is a detail and never a button: clicking a control's label puts its help in the details pane.

COLUMNS: drag an edge to set a width, which writes columnSize back into the .base file. Drag a heading to reorder, which writes order. Click a heading to sort, which replaces every sort level rather than adding one.

WHAT IS DONE: two panes, pinned groups, counts, folding that survives new data, cell editing, drag onto a group, the last column filling the pane.

WHAT IS NOT WORTH COPYING: v3 lost every hand-fold on refresh, and several of its handlers query the document rather than their own pane, so they hit the left one whichever pane the control was in.
