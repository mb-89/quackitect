## detail

Spec rejections name criteria that cannot judge anything, and the reviewer has already written the fix. Owner's decision: a reviewer applies a fix that does not alter what done means, records the repair and opens no round. A change that alters what done means is a rewrite and goes back as a round. The reviewer must declare which it is, and the engine treats the declaration as binding. Criterion 1 must check the boundary words inside the repair section, not anywhere in the file. The detail must price a declared rewrite as criterion 5 does. Related: wk-cae83b6e63, wk-925ca24643.
