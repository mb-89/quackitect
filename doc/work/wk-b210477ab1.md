## detail

Two mechanisms enforce one rule set. The apply door refuses a write that breaks a voice rule and names the line. A standing check counts breaches after the fact and refuses nothing.

Two mechanisms for one rule is a smell whichever way it resolves. Either the refusal covers every door and the counting is dead, or it does not, and the counting catches what slips.

There is a second question. Code has a formatter, and a formatter decides nothing, because it moves whitespace and whitespace carries no meaning.

Some voice rules are that kind. A missing blank line between paragraphs and trailing whitespace could be applied in silence, and nobody would miss the refusal.

The rest are not. A sentence of twenty-eight words cannot be split without choosing where the idea breaks, and that is a decision about meaning. A refusal naming the sentence is the honest shape there.

## approach

Every voice rule is labelled one of two things: a formatter can apply it, or only a refusal can. The label lives beside the rule in the rules file, which is already data meant to be swapped.

The format verb applies every rule labelled for the formatter. The apply door refuses only what is labelled for refusal, so the two mechanisms stop overlapping.

The standing check then counts nothing a door already refuses. What it still counts is the list of rules no door reaches, which is the honest measure of the gap.

## done when

- every rule in the rules file carries its label, decided by: read the file
- a rule labelled for the formatter is applied rather than refused, decided by: write a breach of one and run the format verb
- the apply door refuses only rules labelled for refusal, decided by: a test planting one breach of each kind
- the standing check reports only rules no door reaches, decided by: run it over a clean tree
