## detail

A finding from [[wk-2f51c2156a]], which gave a session its name back.

AgentSeen in src/engine/evidence.go now reads `|| s.Name != "main"` in its guard. Every hook event but an end event reaches it, from hook.go line 474, so a tool call reaches it. A second live session holds a name apart from main for as long as the first session stays. Its every call now enters NoteSession, takes the evidence lock, and writes the whole store again.

SaveEvidence marshals and writes on every call and guards no no-op. lockFile sleeps whoever else wants that lock. So the two-session run this token was written for pays a locked whole-store write per tool call, and the store it writes says what it already said.

NoteSession asks aSessionName for the name and takes it only when it is main. The guard can ask the same question, and then a session named apart re-registers only when main is free.

## proposed action

Re-register only when main is free, by asking aSessionName inside the guard.
