## detail

An agent can answer a page of ten reds with one edit and run the suite again. That is guessing, and the suite pays for it.

THE OWNER'S WORDS, September 2026: we need the engine to reject tests if the number of changes is not as big as the number of errors.

MEASURED that month on this box. A run came back with six reds. The agent read one, changed one thing, and ran the whole set again. Two of four runs in that sequence taught it nothing. Each run rebuilds the engine and costs about fourteen seconds plus the reading.

WHAT THE ENGINE ALREADY KNOWS. se test writes the delta since the last run and the result of every test it chose. So it holds both halves already: how many tests were red last time, and how many places the tree changed since. Nothing new has to be recorded.

THE SHAPE OF THE RULE. Where the last run was red in many tests and the delta since is one small edit, the run is refused and the refusal says how many reds are unanswered. It is not a bound on effort. It is a bound on running the suite as a way of thinking.

WHERE IT MUST NOT FIRE. A build failure is one error and hides every other, so a package that did not compile is not a page of reds. And a red another hand caused is not the agent's to answer.

## proposed action

se test compares the reds of the last run against the delta since that run. Too few changed places against too many reds is refused, and the refusal names the count of each.

A build failure counts as one, whatever it lists, because the compiler stops at the first wall and every other test in the package is unrun.

The threshold is one number in the parameter tree, so a person can move it, and zero turns it off.

The refusal names a legal move, which is to read the rest of the page. It never blocks a run that follows a change touching as many places as there were reds.

## done when

- a Go test drives se test twice: the first run leaves several reds recorded, a one-place delta follows, and the second run is refused and names both numbers
- the same second run goes through where the delta touches as many places as there were reds
- a first run with nothing recorded before it is never refused
- a run whose previous answer was a build failure is never refused, however many tests that failure listed
