## detail

The editor draws with rules of its own instead of the ones panel.ts already
has, and it shows.

WHAT THE OWNER SEES: the text on a toolbar button sits off centre and the button
does not look like a sidebar button. Every input and select in the popovers has
a white background, because the editor's rules set font: inherit and say nothing
about colour, so the browser default wins. The sidebar's inputs set
--vscode-input-foreground and --vscode-input-background and look right.

ONE STYLESHEET, WHICH IS WHAT V3 HAD. The markup was ported and the styling was
not. Every control in the editor takes the same rules as the same control in the
sidebar: a button, a select, a text input.

THIS IS THE THIRD TIME THE OWNER HAS ASKED FOR IT.
