## detail

The editor draws with rules of its own instead of the ones panel.ts already has. Toolbar button text sits off centre, and every input and select in the popovers is white because the editor rules say nothing about colour. One stylesheet, as v3 had. Every control in the editor takes the same rules as the same control in the sidebar: a button, a select, a text input. Owner has asked for this three times.

## evidence: outcome

src/extension/controls.ts exports controlCss, embedded by both editor.ts and panel.ts. It holds the control height, button, text box, number box, select and checkbox, with every colour a theme variable. Only width stays local, with a comment. One check pulls the shared block out of each rendered page and asserts they are identical and the control height resolves the same. It goes red when the sidebar stops sharing. The two one-sided checks were deleted, and render-check.mjs, drive-editor.mjs, panel-icons.mjs and npx tsc --noEmit pass.
