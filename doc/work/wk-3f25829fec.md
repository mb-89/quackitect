## detail

Whether a rule in the standing layer changes what an agent does is unmeasured. The cost half is answered by a counting script that is still there. The effect half has never been run.

The method: take one standing rule whose effect a check can see. Run the same piece of work with the rule and without it, in a separate tree, several runs each way. Count how often the check goes red under each.

One run either way is not evidence, and this refuses it. Two samples of a thing this noisy say nothing, and a number with no spread behind it will be quoted later as though it did.

Run it in a separate tree and mind the mint. A mint against a scratch folder has been reported landing in the real backlog. Check where a token lands before running anything that mints in bulk.

## proposed action

Name one standing rule and a check that can see its effect. Run the work with and without it, several runs each way, in a separate tree.

Write up the rule taken away, the piece of work, the check counted, and the counts each way.

## done when

- one standing rule is named, with a check that can see its effect
- the same work runs with and without that rule in a separate tree, several runs each way
- the write-up names the rule, the work, the check and the counts each way
- where a minted token lands is checked before the runs, so the real backlog is not polluted
