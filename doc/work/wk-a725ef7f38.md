## detail

writing-go rule 14 asks a test to be a table under t.Run. src/viewer holds 7 test files and none of them calls t.Run.

Counted at HEAD by `find src/viewer -name '*_test.go' -exec grep -L 't\.Run(' {} + | wc -l`, which answers 7. The whole file count comes from `find src/viewer -name '*_test.go' | wc -l`, which answers 7.

What is gained is that a new case becomes a row rather than a new function carrying a copy of the setup. This module has no converted file to copy from, so it takes its shape from src/mcp and util/setup.

What breaks if nobody does it is that the module drifts further from rule 14 with every case added. The standing check that would hold the rule stays impossible to turn on.

The package is the compilation unit. A file converted, built and tested before the next one starts leaves the package building for every other hand.

A table earns its place where cases share setup. A single case stays a single function, and this token names each file it leaves alone and why.

## proposed action

Convert each _test.go file under src/viewer to a table under t.Run, one file at a time, building and testing the module after each file.

## approach

Seven files, so this needs no batching and no sub-tokens. One file at a time, built and tested before the next one starts.

The shape is taken rather than invented. src/mcp and util/setup are converted already, so their table reads as the pattern here.

Inside a file the shape is one table under one t.Run. The setup each old function copied becomes a row's fields. The assertion stays where it is, and a row is named for its case rather than numbered.

A table earns its place where cases share setup. A file holding one case stays one function, and the note names it and says why. So the criterion counting files with no t.Run has to allow those, and the note is what a reader checks it against.

## done when

- no _test.go file under src/viewer lacks t.Run. Decided by `find src/viewer -name '*_test.go' -exec grep -L 't\.Run(' {} + | wc -l`, which answers 7 at HEAD and must answer 0
- src/viewer compiles its tests, decided by: `go vet -C src/viewer ./...` exits zero, which it does at HEAD
- se test answers ok with nothing unreached. Decided by `./RUNME.sh test --on <this id> --propose <its src/viewer test ids> | jq -e '.ok and ((.unreached // []) | length == 0)'`
- the note names every file left as a single function, and why. The reviewer reads it against `find src/viewer -name '*_test.go'`
