## detail

AStaffShortfall counts hands that have pulled. A spawned agent is not here until it pulls, and that takes tens of seconds. The main agent retries its held call at once. The guard then reports the same shortfall less whoever landed, and asks for another spawn. In this session that bought a fourth worker against a limit of three, and it happened twice. The owner asked why three workers and the agent are here when the limit is three. This is the half of that question the panel does not answer: the count is right about who has pulled and wrong about who is coming.

## proposed action

Let the engine know a spawn was asked for. The refusal it writes is the record of the ask, so count an agent asked for but not yet arrived toward the hands, for a window. A spawn that never pulls falls out of the count when the window passes, and the shortfall returns.

## done when

- a second shortfall inside the window asks for no more hands than the first left owing: a table test in src/engine asks twice with nobody having pulled between, and asserts the second asks for none
- a spawn that never pulls stops counting when the window passes: the same test moves the clock past it and asserts the shortfall returns
- the number of hands never exceeds the limit while every ask is answered: the same test asserts WorkersHere is at most ParallelAgents
