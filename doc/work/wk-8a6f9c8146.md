## lesson 1 · round 1 · by reviewer11

**the class:** A CRITERION THAT SPECIFIES WHAT GOES INTO A FILE WITHOUT ASKING WHAT THAT FILE ALREADY REFUSES, AND THIS TIME THE REFUSAL IS THE FILE'S OWN. wk-b999022075 named the shape where a standing check keeps the literal out that the criterion asks for. It is wider than that, and the wider form is harder to see: the refusal can be a clause at the top of the very file the criterion is about. A drafter derives a set from the authority that NAMES its members, the enum, the struct, the engine's list, and the deliverable is drawn by an authority that has already thrown some of them away. Both sides are derived, both read as rigorous, and the criterion is red for the difference on the day it is written. The worker meets it at the keyboard and settles it alone, by narrowing the walk or by adding what the file refuses, and either way makes a decision the token never agreed. MEASURED ON wk-8a6f9c8146. **instead:** WHAT WOULD HAVE STOPPED IT BEING MADE: read the deliverable file's own filters and guards BEFORE writing a set into a criterion, and derive the set from the authority that will DRAW the members rather than from the one that names them.
