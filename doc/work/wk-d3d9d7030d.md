## detail

Rule 15 of writing-go said to run gofmt, go vet, go fix and golangci-lint before every commit. wk-8ec7483730 put the programs behind two verbs and reached three of the four. FormatGo in src/engine/format.go runs gofmt alone, LintGo runs go vet and golangci-lint, and nothing runs go fix. Searched at caafd04^ over util/ and src/: go fix was in no check then either, so the token's detail is wrong where it says all four sit in util/checks and run when the battery runs.

The old chapter said what it was for: go fix since Go 1.26 rewrites old idioms to slices, maps, strings.CutPrefix and the atomic types, so the tree stays on one idiom without a person remembering each. That chapter is deleted, and TestWritingGoNamesNoProgram at src/engine/formatlint_test.go line 149 now fails the guidance if it names go fix at all.

What is gained by doing it is that the rule the project wrote down is either kept by a program or struck on purpose, rather than lost between two edits.
