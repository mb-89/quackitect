## detail

A command through se run inherits the parent's PATH, so about twenty-five recorded calls carry cd and export PATH by hand. Two failures reported as engine defects were only a missing rg. The engine already probes the tools (the pull answer lists each name, path and version), so the run verb can hand the child that environment instead of every command carrying it.

## proposed action

Where se run builds the child process, prepend the directory of every probed tool to the child's PATH. Then rg, node, go and git resolve without a command exporting anything.

## done when

- a test drives the run verb's environment builder with a probe fixture and sees each tool's directory on the child PATH
- a command naming rg with no export runs through se run and resolves, tried once on this machine by the taker
- the test was seen red for the reason expected before the change
