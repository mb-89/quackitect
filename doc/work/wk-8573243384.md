CLASS: WORK ADOPTED ON THE STRENGTH OF ITS TESTS, WITH NONE OF THEM RUN AGAINST
THE DEFECT IT NAMES.

Somebody else's branch is read, the commit messages are good, each commit
carries a test, and the verdict is taken. "Each carries its own test" is a claim
about those tests, and it is made by reading them. A test that is read is a test
that is green. Green is what a test that cannot fail looks like too, and the
whole reason for adopting the work was that it guards something.

THE SAME RULE THIS PROJECT ALREADY APPLIES TO ITS OWN WORK. A check nobody has
watched fail is a check nobody has tested, and the engine now refuses a
submission that rests on one. Inherited work is where the rule is easiest to
forget, because the check arrives already green and there is no moment at which
somebody had to make it go red.

FOUND ON wk-c6247665a3, the judgment on thirteen upstream commits. The verdict's
reason is that every one of them is a hole a Linux clone actually fell into and
each carries its own test. The central one is 6522bcbb's
TestNoCommittedProjectionNamesTheMachine, src/engine/cage_test.go, whose whole
subject is that a committed cage file must not name the machine it was written
on -- the exact fault the upstream work exists to fix, a Windows path reaching a
Linux box.

IT CANNOT FAIL ON WINDOWS. It asks strings.Contains(committed, root), where root
is filepath.Abs(...) and therefore
"C:\\Users\\ichbi\\Desktop\\ai\\quackitect-v4", and the projector writes
paths through filepath.ToSlash, so the file says
"C:/Users/ichbi/Desktop/ai/quackitect-v4". Two spellings of one path, and the
check looks for the one nothing writes.

MEASURED AT ecb7857b, THE MERGE COMMIT, and pinned there rather than to the word
today. Three committed projections named this machine in the spelling the
projector uses -- .claude/settings.json, .mcp.json and .copilot/mcp-config.json
-- and go test was green over all three. .claude/settings.json named it on
fourteen lines, so the check arrived green over a live violation in the same
commit that introduced it. At HEAD it names it on none.

WHAT TO DO INSTEAD. When you adopt work because it is guarded, break what each
guard guards and watch it go red before counting it as a reason. One pass, one
defect per check, and the reason for taking the work then rests on something
somebody saw. If a check cannot be made to fail in a few minutes, that IS the
finding.

AND THE NARROWER LESSON UNDER IT: a check that compares two spellings of the
same thing -- a path with either separator, a name in either case, a URL with or
without its trailing slash -- must be written in the spelling the producer
writes, or normalise both sides. Ask what the artefact actually contains, by
opening it, rather than what your own language hands you.

THE FIX HERE LANDED IN 2dd4c19d AND NOTHING OF IT IS OWED. That commit put both
spellings into namesTheMachine in src/engine/cage_test.go, both tests call it,
the three cage files were re-projected, and no {{mcp}} placeholder survives. An
earlier draft of this paragraph told a worker to watch that check go red today,
and it is green on nothing, which reads either as a check that cannot fail or as
a worker looking in the wrong place. This token owes the rule and owes no code.


THE REMEDY IS A RULE AN AGENT READS, NOT A CHANGE TO A PROGRAM. Nothing in the
engine can tell an inherited check from one written here, and a rule that asked
it to would be a word list fitted to the branch we happened to merge. What can
be written down is what to do before leaning on somebody else's test.

WHERE IT GOES. doc/guidance/behaviour.md, under the section that already says
the check comes first, because this is the same rule at the moment the check
arrives already green rather than at the moment it is written.

WHAT IT SAYS. Before a verdict rests on the reason that each commit carries its
own test, run the ones the reason leans on against the defect they name: break
what the check guards, watch it go red, put it back, watch it go green, and
write the two lines into the report under the commit that brought it. Not all of
them and not for long. The ones the verdict's reason turns on.

AND WHY IT IS WORTH THE TIME, WITH THE MEASUREMENT THIS CAME FROM. Thirteen
