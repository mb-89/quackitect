## detail

The cage declares fourteen hook events and nothing has established which of them each harness fires. Today's record shows that SubagentStart and SubagentStop never arrived for any helper although the door records them when posted, and that an interrupt sends nothing. Every rule that rides on an event nobody fires is a rule enforced against nobody. This is a spike, and it closes on its numbered questions. Consumes wk-7de54dfcc4.

## approach

For each harness at hand, the desktop app's Code tab, the terminal CLI and the IDE extension: 1. which of the fourteen declared events write a line in the record when driven, proved by the record and not by the settings file. 2. for SubagentStart and SubagentStop, whether they fire for a helper spawned by the Agent tool, and under which harness version. 3. what arrives on an interrupt, if anything. The answer is a table in the token's note, and the ruling lands in the engine's cage comment and in driving-the-engine's discussion. Events proven silent are struck from the cage or kept with the reason written beside them.

## done when

- every declared event has a row per harness saying fires or silent, proven by a record line or its absence: the note's table
- the cage's settings file carries no event the table says is silent everywhere. Or it carries the reason beside it: se find --words SubagentStart --path util/cage/**
- the register's turn rule is kept or replaced according to what the table says about the two helper events: the note says which
