## detail

Fifteen ids written into fourteen live notes reach no token, no archive row, and no note this branch can read. They are not ids nobody minted. Each names work another box did, and the sentence naming it is true: "Found while working wk-32c0df8d1c", "Three tokens closed by worker-kest tonight", "Found reviewing wk-e51c579664".

Ten of the fifteen have a note in an object this box fetched, reachable from no commit on HEAD. Five reach nothing at all here. wk-b5c68d2bbf (another box) is a live token about one of them, wk-120d7c9685, and says it stands on refs/se/claims and on no commit of v4.

So a row naming the fetched object fails util/checks/archive-rows-travel, which resolves against what HEAD reaches, and deleting the id from the sentence throws away a true trace of where the work came from.

The fifteen: wk-0909cb7db7, wk-120d7c9685, wk-1bb23ea110 (another box), wk-2cdaae953c, wk-32c0df8d1c, wk-3747494a3c (another box), wk-37bfa974e3, wk-4243c04e79 (another box), wk-5d6e638e96, wk-6542703f66 (another box), wk-ab9b2b6b1e, wk-bd6c665ee8, wk-e51c579664, wk-e80e5c912a (another box), wk-f9233114b0.

Split out of wk-7d2d36115f, which names two shapes and meets a third here.

## proposed action

Decide what a reference to work this branch never carried resolves to. Either the notes are brought onto the branch from the box or the ref that holds them, or the lint learns a shape for an id whose note is elsewhere, so a true sentence stops being a finding.

## approach

The second route, because the first is shut. No branch and no archive tag on this remote reaches any of these ids, so there is nothing to bring over.

The shape is a mark the writer writes beside the id, "(another box)", read once per note. idsNamingNothing in src/engine/lint.go collects the marked ids from the note text and skips them. An unmarked id that reaches nothing is a finding exactly as before.

The writer marks it because the branch cannot tell another box's work from an id nobody minted, and the writer can. The mark reads as English, so the sentence still says where the work came from.

The decision goes to doc/rationale, and the notes the detail names carry the marks.
