## detail

Cross-cutting left this undesigned, and it is live now with no rule behind it. Two of v3's reference notes already point at local digest paths rather than at addresses. So a reference that resolves on one machine and not another exists in the tree today.

This is not a deferred decision. It is behaviour running with nothing governing it, which is the shape a defect takes before anybody names it.

## what we gain

A reference that says whether it can travel. A reader on another box learns that a citation is unreachable there, instead of following it into nothing.

## what breaks without it

A note cites something no other machine can open, and nothing says so. The reader cannot tell a bad link from a link that was never meant to leave one box.

## appetite

Small to write the rule. Larger if every existing reference has to be judged against it.

## what we do not know

Whether the answer is a field on the reference, or a check that reads them, or both. And how many references in the tree already resolve on one machine only, which nobody has counted.
