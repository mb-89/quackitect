## detail

No console window opens when the system boots.

WINDOWS GIVES A CONSOLE TO A PROCESS STARTED FROM ONE THAT HAS NONE. The
extension spawns nine children on boot and the engine probes for a tool by
running its version command, so booting flashed a window for each.

ONE DOOR PER PROGRAM. A start that skips the door is a window, and one door is
the only way to keep that from coming back.

- the engine and the stub: Quietly(cmd) sets HideWindow and CREATE_NO_WINDOW on
  Windows and does nothing elsewhere. Both flags are needed. One stops the
  console being made and the other covers a program that makes its own.
- the extension: a local spawn wrapper sets windowsHide. The raw import is
  renamed so every call site is unchanged and only the wrapper reaches
  node:child_process.

EACH CHECK GOES WHERE ITS DEFECT IS. A Go test per Go package reading its own
source, and a script for the extension. Each one refuses to pass when it finds
nothing to check, so it cannot go green by the code disappearing.

## lesson 1 · round 1 · by reviewer

**the class:** A guard written as a text search for one spelling of the thing it forbids, then proved red against the single instance it was written from. The demonstration is circular: the check is shown to recognise itself, which was never in doubt, and stays blind to every sibling of the defect. The gap is widest where a language offers several routes to one resource, and that is exactly where a one-door rule is worth having, so the rule and its blind spot arrive together.

**instead:** Anchor the guard on the resource, not on the identifier. Name the edge every use must cross, the module import in a script language or the type construction in a typed one, assert on that edge, and let call sites be spelled however they like. Then, before trusting the guard, write the call that reaches the resource by a route you did not use, and watch the check still pass. Proving a check red against the defect you just removed shows only that it recognises itself. A check earns trust when it goes red for a defect its author did not write.
