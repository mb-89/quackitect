## detail

LoadRunning at watch.go:83 accepts the engine record when the file parses and alive(PID) answers yes. alive_unix.go sends signal zero, which any process holding that number answers. A reused PID reads as a live engine and the editor attaches to nothing. Started is written at main.go:463 and Beat at main.go:511, and nothing reads either. Fix: LoadRunning treats a Beat older than three times HeartbeatSeconds, read from config, as dead. Also hold identity: write the engine start time or a random run identity at start and compare it on load. When a record is refused, the reason names the field that failed. Test first: a record naming the test process with a Beat an hour old reads as dead, with a fresh Beat as alive.
