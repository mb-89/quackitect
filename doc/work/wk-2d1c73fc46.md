## detail

An arriving agent is meant to reclaim what its dead predecessor left holding, as arrival.go says. arrivals.json keys on the engine session, and the engine outlives agents. A harness restart is therefore not seen as an arrival and the reclaim never fires. Every session record in the log already carries the harness session id and whether it came from startup or from a compaction. Key the arrival record on the harness session id, with source distinguishing a restart from a compaction. A compaction must not count as an arrival. Add a test with one engine session and two harness sessions where the second agent reclaims. Add a test where a compaction inside one harness session reclaims nothing.

## done when

- Arrivals key on the harness session id, source separating restart from compaction (arrival.go).
- A second harness session reclaims, a compaction reclaims nothing: go test -C src/engine, red then green.
