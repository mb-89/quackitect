## detail

A group session starts on whatever the clone happened to carry. A box that works a stale tree hands out tokens another box already finished, and every push after that is a merge. Nothing makes it land first. The card asks the agent to remember, and the card has been wrong three times in one session with nobody noticing. A cloud box clones the branch tip as it stood when the session was made, so a person who pushed a minute later has a box that is behind and says it is current. Two sessions were asked whether they were up to date, said yes, and were wrong.

## proposed action

Before the first token, the pull refuses and names the landing. It fetches, says both commits and the ahead-behind count, and puts the tree on the tip.

IT FORCES ONLY WHILE THE TREE HAS NOTHING OF ITS OWN. That is the definition of the beginning: no uncommitted change, and no commit ahead of origin. At the beginning nothing of ours exists, so there is nothing to lose, and refusing would be stopping over an empty risk.

Either of those two means this is no longer the beginning. Then it stops and says what it found, rather than throwing work away.

The refusal is the shape the staffing shortfall already uses: refuse the call, name the next move.

## done when

- a pull on a group branch before landing is refused, and the refusal names both commits, decided by: a Go test in src/engine
- a stale tree with nothing of its own is put on the tip, decided by: the same Go test
- a tree with an uncommitted change is not forced, and the answer says what it found, decided by: the same Go test
- a tree with a commit ahead of origin is not forced, decided by: the same Go test
- after landing, the next pull hands out a token, decided by: the same Go test
