## detail

A session can run with no guard at all and nothing says so. Where the harness root sits above the repository, the settings file never loads and no hook fires.

That happened for a whole session. Every hook-written line in the record belonged to a different session, and every rule built that day was enforced against nobody in the session that built it.

The failure is silent by construction. An agent cannot tell a guard that passed everything from a guard that never ran.

## proposed action

The engine says at session start whether the guard is live, in one line an agent cannot miss, and the record carries it.

## done when

- the engine says at session start whether the guard is live: a test starts one with the hook reachable and one without, and reads a different line each way
- the record carries the same answer: the session log holds one line naming it
