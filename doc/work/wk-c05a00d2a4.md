## detail

THE LANE TAKES A FIELD IT DOES NOT KNOW AND SAYS NOTHING.

Measured here in September 2026. se_apply and se_run were called with the actor named as by. The lane reads actor, so by decoded to nothing, orMain answered main, and both writes were filed under a name nobody chose.

Nothing was refused and nothing was said. The next call through the shell door, naming the worker the caller meant, was then refused because the token was held by main.

taking in src/mcp/main.go decodes the arguments with json.Unmarshal, which discards a field the struct has no place for. schema.go carries the mirror of this fault in its own header, where a field the door had not advertised was dropped by the harness instead.

The write gate makes it easy to walk into. Its refusal spells the shell flag, which is --by, and an agent reading that and reaching for the lane sends by.

## proposed action

Decode with DisallowUnknownFields in taking, so a field the tool does not take is refused rather than discarded. Answer with the field and with the names the tool does take, read off the same struct the schema is read off.
