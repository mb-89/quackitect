## detail

THE LANE HANDS THE GATE A NAME THIS SESSION ALSO ANSWERS TO, AND THE GATE REFUSES IT.

Measured here on 2026-09-05. se apply and se run through the tool lane both answered that wk-34d11d2caf is held by worker-relay-trial, which is this session.

TakeUp in src/engine/gate.go compares the holder on the token with the actor, and refuses where they differ. se --doing lists two names against this session, main and worker-relay-trial, and the hold carries the second.

The same call through RUNME.sh naming worker-relay-trial goes through. So the lane either drops the by argument or resolves the actor before the alias is applied.

The cost is that a session whose worker name holds a token cannot write through its own lane. Everything then goes through the shell door, where the write gate refuses any payload carrying shell characters. The two faults compound.

## proposed action

Resolve the actor through this session's names before comparing it with the token's holder. The shell verb and the lane then go through the same door, and the by argument means the same thing on both.
