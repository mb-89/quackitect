## detail

SPIKE. The event that fires while assistant text is displayed exists. Whether a refusal there is honoured is undocumented, so Level 0 ruled it is measured rather than assumed.

WHY IT MATTERS. If the refusal holds, the cage has a live guard over what the agent says, and the voice rules reach conversation rather than only the write path. If it does not hold, the design promises a guard it has not got, and the honest thing is to say the layer delivers rather than enforces there.

WHAT TO MEASURE. Fire the event, return a refusal, and watch whether the text still reaches the person. Not whether the hook ran. Whether the words appeared.

WHERE THE ANSWER GOES. Straight into the Level 0 design as a ruling, either way. This one does not need a discussion: the measurement decides it, and the sentence that is currently a spike becomes a sentence about what the cage does.

IF IT CANNOT BE MEASURED, say so and say what was tried. An unmeasurable spike is a finding about the host, and it still closes.
