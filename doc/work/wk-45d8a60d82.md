## detail

A guard carves out an exception and tests it on a proxy for the thing it gates. runsTheEngine in src/engine/hook.go tests whether a command runs only the engine, while the guard is about whether a command can write. A redirection writes and runs nothing, so an engine command redirecting into a source file stays inside the exception and never reaches WriteNeedsAToken. Write the exception in the vocabulary of the guard: this command cannot write. Enumerate every way a shell command can write, running a writer, redirecting and a heredoc, and put each into the negative list. Related: wk-4e8eeb76aa, wk-083709584c.
