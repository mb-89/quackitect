## lesson 1 · round 2 · by reviewer

**the class:** An escape hatch written as a state flag rather than as evidence that somebody is still there. A status like in_review means a live worker only for as long as the worker lives; it survives the process, so the flag outlasts the fact it stands for and the guard is left permanently open by the very failure it was built for. The same shape appears wherever a check reports success for a state in which it did nothing: a linter that returns clean because it could not read its input is the same mistake, since absence of findings is being used as evidence of absence of defects.

**instead:** Make the thing that opens a guard decay, and make the absence of input loud. When a guard has an escape, ask what the escape looks like the moment the actor behind it disappears, and if the answer is that it stays open, tie it to something with a clock on it: a hold taken this session, a heartbeat inside a window, a stamp that goes stale. When a check cannot read what it was asked to check, that is a finding and never a pass. Test both by taking the actor away rather than by taking the defect away: kill the holder, delete the input file, and see whether the guard still says everything is fine.

## lesson 2 · round 3 · by reviewer

**the class:** A submission that answers the findings it knows how to fix and goes quiet on the one it does not. Nothing in the evidence is false, every section is careful, and the omission is invisible from the inside because the sections that exist are all true. From the outside it is indistinguishable from the work being finished, so the next reviewer spends a whole round rediscovering a defect that was already written down, and the queue pays for the same finding twice.

**instead:** Answer every finding by name, including the ones you are not going to fix. A finding you cannot close in this token is one sentence in the evidence saying so and naming what owes it, and that sentence costs nothing and passes. Silence costs a round. The same rule holds for anything you looked at and set aside: the reader cannot tell a decision from an oversight, so write down which one it was.

## lesson 3 · round 4 · by reviewer

**the class:** A fix that replaces a fact which never decays with another fact which never decays, one scope smaller. A status was true until somebody changed it; an arrival is true until the session ends. Both answer the question is somebody there with something that was recorded when they arrived and is never revisited, so both stay true after the actor is gone. What conceals it is the test, which is written from the fix rather than from the world: it constructs a holder that never pulled, which the engine cannot produce, so the guard is proved against a state that cannot occur and is never asked about the state that can.

**instead:** When a guard asks whether somebody is still there, the thing it consults has to be refreshed by them still being there. Ask what writes the fact and what would ever unwrite it, and if the answer to the second is nothing, it is a flag and not evidence, whatever it is called. Then build the fixture from the outside in: produce the state through the engine's own verbs rather than by writing the record by hand, because a state you can only reach by hand is usually a state the system never reaches, and a check that only ever sees that one is testing a case nobody will meet.
