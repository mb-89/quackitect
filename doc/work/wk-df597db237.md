## detail

A guard that simulates another language's lexer is checked only against rows written by the hand that wrote the simulation. On wk-1b81149187 theQuotings calls itself bash's state machine, but bash has a backslash state and no row carries a backslash. Three commands drove past the exception: `se work --detail \" ; touch M`, `se work --detail \' ; touch M` and `se work --detail \'$(touch M)\'`. Derive the rows from the interpreter's own manual, one pair of rows per state transition it names. Wider still, generate commands over the guard's alphabet of special characters and run each through bash with the did-a-file-appear oracle. Require the guard to refuse exactly the commands that reached the filesystem. Before calling a walk another language's state machine, open that language's manual and write one line of the walk per state it names.
