## detail

Level 2, parked until the state machine is built. The Level 2 model is a workflow net, and the v3 failure of 25 tokens gone into nothing is a soundness violation. With no parallelism the check is graph reachability over the authored UML. When a factory emits or modifies a machine, or a hand edit lands, the engine walks it and refuses an unsound one, naming the defect. Defects: a state unreachable from start, an end unreachable from some state, a bucket token with no closer, a door that can never open. Tests: one fixture machine per defect class, each watched red before the check is trusted. The check binds the drawn machine only, and tokens minted at runtime are held by the Level 1 barriers. Prior art: van der Aalst, Verification of Workflow Nets, https://www.vdaalst.com/publications/p44.pdf.
