## approach

StaffingOf keeps its walk of AgentsPresent and gains a second one, over ActorsThatPulled. That is the arrival record WhatIsHappening already merges the register with. An actor no present row answersTo is counted under the role it pulled with, from the record's Roles map:

    for _, actor := range ActorsThatPulled(r) {
        if any present row answersTo(actor) { continue }
        switch roles[actor] {
        case RoleWorker: s.WorkersHere++
        case RoleReviewer: s.ReviewersHere++
        }
    }

Three things to disagree with.

First, the witness is the arrival record rather than .se/actors.json. The aliases there say what name a process pulls as. Arrivals say who pulled, in this run, and on which queue.

Second, an actor that pulled and holds nothing still counts. So the walk is over ActorsThatPulled rather than WhatIsHappening's Present, which drops a waiting actor.

Third, the run boundary is ActorsThatPulled's own. A record whose session is not this run answers nothing, which is what keeps an earlier run out.

The panel is left alone. Widening its merge would draw a waiting agent in the header, which this token was not given.
