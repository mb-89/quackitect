## detail

Every markdown this system creates comes from a template for its type, and the engine refuses one that does not fit. The owner's words: every markdown we use needs to adhere to quality standards, and that means it is created from a template. Nothing writes another spec format until this is settled. Settle before building: what a template is, a markdown file with the headings and frontmatter a type must carry, kept with the method's other declarations. What refuses: the mint, so a bad note is never written, and the lint, so a hand edit is caught. What a template may demand: a heading present, a heading non-empty, a frontmatter field, a field from a list, and never prose. Research prior art first, in issue templates, architecture decision records and the documentation frameworks the voice cites.
