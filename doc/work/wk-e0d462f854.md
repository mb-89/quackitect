## detail

A finding on wk-808abd40a4, archive without a ref.

func (a Archived) Where() in src/engine/archive.go names the first of blob, on_branch and tag that is set. Its one caller in the whole tree is src/engine/archive_test.go:158, where the test uses it to predict the path FindArchived reports.

FindArchived does not use it. It takes the second answer from readArchived, which is the object that actually answered rather than the first one named, and readArchived carries its own copy of the same order. So the product holds two statements of the precedence, one of which nothing in the product reads, and they can be made to disagree: a row whose blob is set but swept answers from on_branch, and Where still says blob. The test would then pass on a prediction that is wrong.

TestNoExportedFunctionHereIsUncalled is the check for this class and it does not see it, because it reads exported functions and Where is a method. It fails today on ParseYAML alone, before and after this change.

- Where is gone and archive_test.go asks readArchived what the reader asks, or Where is the one statement of the precedence and readArchived reads it
- TestNoExportedFunctionHereIsUncalled names methods as well as functions, so a method only a test calls is caught, and it is watched red on a method planted for the purpose
