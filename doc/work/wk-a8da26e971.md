## detail

The collection writes one file: manifest.jsonl. One line per thing, JSONL like the record. Each line carries the name it has in the retro folder, where it came from, and what happened to it: taken, kept and why, or looked for and missing.

IT REPLACES index.md RATHER THAN JOINING IT. Two files for one fact is the duplication this project keeps finding. The index holds three things and none of them earns a second file. The counts are derivable from the manifest. The looked-for-and-missing list is data and belongs in it. The instruction, that a script worth keeping is moved into the method, is guidance the retro method owns, and copying it into every retro folder is a per-folder copy of a rule that lives somewhere else.

Nothing but src/engine/retro_test.go reads index.md, so the removal is bounded.

A human reading is rendered, not stored. The manifest answers it.

WHAT IT DOES TODAY. Collected carries Logs int and Scripts int, and the folder note says 'log: 4 file(s)' and 'scratchpad: 37 thing(s)'. The files were moved by os.Rename, so nothing is destroyed, and nothing records which name came from the scratchpad and which from the log directory. After a retro the folder is a pile with no origin, and fixing a reference to something inside it means guessing.

WHY IT UNLOCKS THE ORDERING THE OWNER WANTS. The retro can build the replacement first and drain afterwards. That ordering needs the promotion step to know what came from where, and the manifest is that. Without it the promotion works from a folder listing and its own memory.

AND IT CLOSES A CLASS THIS PROJECT ALREADY NAMED. A count written in prose beside the list it summarises, never recounted against it, is the lesson on wk-61af3a054e. With the count derived, a file that moved without a line makes the two disagree instead of passing quietly.

WHAT IS ALREADY RIGHT. citedInOpenWork walks every token that has not ended and keeps any scratchpad entry one of them names by path, folders included, because taking the folder takes the file. The retro does not take what open work still points at. The manifest is for everything it did take.
