## detail

Whether a rule in the standing layer changes what an agent does is unmeasured. The cost half is answered by `uvx --from tiktoken python util/checks/count-standing.py .` and the effect half is not. Take one rule whose effect a check can see. Run a piece of work with it and without it in a separate tree, and count how often the check goes red either way. Whatever is built names the rule taken away, the piece of work, the check counted, and how many runs each way. One run either way is not evidence and the token refuses it. Related: wk-23801b6603.
