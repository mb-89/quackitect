## detail

A control beside the ask button, so agents can later put their own ideas in rather than only working the tokens they are handed.

What it does is not designed and is not part of this. It goes in as a declared control that toggles a value nothing reads. The surface then exists, and the behaviour can arrive later without a panel change.

The icon check fails on a glyph the table does not hold, so the lightbulb has to land with the control rather than after it.

## done when

- the control draws beside ask and toggles, decided by: read the panel
- the icon table holds the glyph the control asks for, decided by: the icon check
- nothing about the engine changes when it is on, decided by: turn it on and run the battery
