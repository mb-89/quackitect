## detail

runsTheEngine in src/engine/hook.go runs the separator scan over withoutQuotedSpans(command, "\"'") and the substitution scan over withoutQuotedSpans(command, "'"). Each pass re-derives the quoting for itself. An apostrophe inside a double-quoted argument opens a span the second pass believes in and bash does not. A bare substitution after such an argument is then exempt from the write gate. Walk the string once in the shell's own state machine and read every question off that walk. Add cases to the table in src/engine/substitution_test.go with two quotings in one command, and run the harmless twin through bash to compare. Related: wk-15c3f409dc, wk-1b81149187.
