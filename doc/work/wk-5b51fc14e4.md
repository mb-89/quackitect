## detail

Everything the engine carries should be actionable and in the present tense, and it is not. schema.go, gate.go and store.go carry paragraph-long ALL-CAPS arguments about why a thing is the way it is, and so do the MCP tool descriptions, which cost 3780 bytes on every turn. Guidance already has the shape: Actionables says what to do, Discussion holds the argument. Nothing else has anywhere to put a rationale, so the argument lives where the instruction should be, and every reader pays for it. The owner rules a rationale is a kind of its own with a template and a folder. Consumes wk-f302064e96.

## approach

A rationale is a kind like any other: src/schemas/rationale.schema.yaml, notes in doc/rationale/, read by the lint the way guidance is. The shape to disagree with:

- frontmatter carries kind, title, and explains, a list of the files or notes that hold the instruction this argues for.
- the body runs decided, why, costs, revisit when. Four sections, none optional.
- the walk goes both ways. The rationale names what it explains, and the thing explained names the rationale back by link and does not repeat its sentences. TestARationaleIsNamedNotRepeated drives that through every note: the link is there, and no sentence of why appears verbatim in the file it explains.

Two cases rather than a sweep: src/mcp/lane.go, where a turn pays the cost, and src/schemas/work-token.schema.yaml, which carries the heaviest standing argument. The ALL-CAPS blocks left in schema.go, gate.go and store.go are ordinary work afterwards, one token each.

## done when

- rationale is a kind with a schema, and a note of that kind lints: .bin/se.exe lint
- a rationale carries what was decided, why, and what it costs, and the thing it explains names it by link rather than repeating it: go test -C src/engine -run TestARationaleIsNamedNotRepeated
- the MCP tool descriptions carry the instruction and name their rationale, and what a turn pays for them falls, with the note saying from what to what: se find --regex 'description.:' --path src/mcp/lane.go

## note

A rationale is a kind now: src/schemas/rationale.schema.yaml, notes under doc/rationale, and LintRationales reading them the way LintGuidance reads guidance. Two arguments moved out of the code carrying them. src/mcp/lane.go and src/schemas/work-token.schema.yaml each kept the instruction and gained a link to the note that argues for it, so the walk goes both ways.

TestARationaleIsNamedNotRepeated drives both halves over the shipped corpus: the explained file names the note, and holds none of its sentences.

The descriptions had already been trimmed under the token this one consumes. Measured on lane.go, they fell from 43 descriptions and 5249 bytes at 7f22e1a3 to 11 and 883. This change did not move that number. It moved the argument left behind beside them.
