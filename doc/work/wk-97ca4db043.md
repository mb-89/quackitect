## detail

CLASS: A CRITERION THAT MAKES A LINE NUMBER A STANDING RULE, ON A TOKEN WHOSE OWN METHOD SAYS NOT TO RECORD ONE.

The method says an observation names the test and what it said, because a line moves the moment anybody adds a function above it. A token then writes a check that holds its own recorded observations to their citations, which is the right instinct: an observation nobody can follow leaves the criterion with nothing behind it. The check is built from what the record happens to hold, and what it holds is file and line, so the criterion asks that the file have at least that many lines and that the line carry the assertion. The rule the method forbids is now enforced by a command.

WHY IT READS AS RIGOUR. The criterion is about the token's own evidence and it is stricter than what came before, so a reviewer sees a token holding itself to its own standard. Nothing on the page says that the handle it holds is the one the method rejected.

WHAT IT COSTS, MEASURED ON wk-2b78b911b1 RATHER THAN PREDICTED. I copied doc, util, .se and src/engine into a scratch tree, inserted one five-line helper above the first test in src/engine/drain_test.go, and ran the check. TestEveryRedSaidResolves went red on five of its six citations, each saying that line makes no assertion, and not one recorded observation had become false: every message was still asserted, by the same code, in the same test. The redraft under review had already paid that cost inside one commit, moving four of its own citations, 440 to 471, 637 to 668, 334 to 365 and 522 to 553, with no change to what was watched.

WHAT TO DO INSTEAD. Choose the handle from the producing side. A test message comes out of an Errorf, so the durable handle is the test function that called it, and the check resolves the message inside that function rather than at an offset from the top of the file. That is stable under every edit above it and it is stronger than the line form, because it proves the message belongs to the test the observation is about rather than to some line of the file.

THE CHECK, RED TODAY: resolve each recorded red against the test function it names, and require the message inside that function. wk-2b78b911b1 records file and line and no test name, so the check refuses every one of its six observations until the record carries the producer instead of the address.

BEFORE IT: before writing a criterion that requires an address to go on resolving, ask what an ordinary edit above it does. If adding a function makes it red without changing what it asserts, the criterion is about the file's shape and not about the claim.
