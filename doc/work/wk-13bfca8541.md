## detail

An empty group answers wait today, and wait reads as nothing to do. It is the opposite. The group is done and the closing work has not started. So a box stops with its notes private, its branch unmerged, and its learnings dying with the container. The card asks the agent to remember four steps at the end of a session, which is the moment an agent is least likely to remember anything. Every other rule the engine cares about is a refusal that names the next move, and this one is prose.

## proposed action

On a group branch, an empty queue opens a sequence rather than answering wait.

Each step refuses until it is answered. Run the retro. Turn every note into a tracked token. Merge to trunk and push. Then say the branch is ready to sweep.

The note ceiling already does the second at twenty, and here the floor is zero.

WHAT MARKS A STEP DONE IS THE RECORD, rather than a checklist beside it. The retro, the mints and the merge are all written there already, and a second list would drift from the first.

A box never widens its own filter, so empty always means done and never means go shopping on trunk.

## done when

- an empty group answers the retro demand rather than wait, decided by: a Go test in src/engine
- the demand does not repeat once the record carries the retro, decided by: the same Go test

- with the notes turned in, the answer is the merge, decided by: the same Go test
- when the closing is done, the answer says the branch is ready to sweep, decided by: the same Go test
