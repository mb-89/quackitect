## detail

An empty group answers wait today, and wait reads as nothing to do. It is the opposite. The group is done and the closing work has not started. So a box stops with its notes private, its branch unmerged, and its learnings dying with the container. The card asks the agent to remember four steps at the end of a session, which is the moment an agent is least likely to remember anything. Every other rule the engine cares about is a refusal that names the next move, and this one is prose.

## proposed action

On a group branch, an empty queue opens a sequence rather than answering wait.

Each step refuses until it is answered. Run the retro. Turn every note into a tracked token. Mark the branch done with a file on it. Merge to trunk and push. Then say the branch is ready to sweep.

The delete is never attempted, because it answers 403. Somebody outside sweeps, reading the marker.

THE BOX WRITES THE MARKER AND THE ENGINE READS IT. The engine writing it would be the engine saying the work is done, which is the box's claim.

EACH STEP IS READ OFF THE WORLD, not a list beside it.

THE CLOSING LOOPS BACK. A retro that mints into this bucket makes the group not empty, so the sequence returns to work. The group is done when the bucket is empty, the retro has run, and the retro added nothing to it.
