## detail

A criterion asks the check to compare a rendered line against the template that produced it, up to the first rendered value. The check holds only the rendered text and a source tree, so it cannot find that boundary. The rule collapses to the longest leading run of the message some source carries, which has no floor and cannot fail. State a matching rule only in terms of what the check holds when it runs. Name the durable part by a whole identifier or a minimum length written as a number. Related: wk-42adef4818.
