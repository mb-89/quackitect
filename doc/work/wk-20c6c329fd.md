## detail

The states a work token can be in, named and enforced in one place. The owner's list: backlogged, then spec_open, spec_in_work, spec_submitted, spec_in_review, then imp_open, imp_in_work, imp_submitted, imp_in_review, imp_done, and the engine's aborted makes eleven. An agreed spec is imp_open, so there is no spec_done. An abort comes off any non-terminal state and must carry a reason, while disposition stays its own field. done and became end in imp_done, dropped ends in aborted, and old names read back under the new ones with no note rewritten by hand. The design documents and the icon named open are left alone. Related: wk-097b2cac17.
