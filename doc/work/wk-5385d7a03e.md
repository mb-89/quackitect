## detail

A check that reads source and matches one of the language's spellings for a literal rests on a style the tree does not enforce. Found on wk-1412093cd8: the guard over flags in extension.ts fails when the flag carries double quotes and answers 0 failed with single quotes or backticks. Before writing a pattern over source, list the ways the language can spell the thing matched and write the list into the pattern's comment. Cover all of them, or say what rule the tree enforces that makes the missing ones impossible. Having watched the guard go red on the defect, retype the defect in each other spelling and watch it go red again.
