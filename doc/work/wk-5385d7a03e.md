## detail

CLASS: A CHECK THAT READS SOURCE AND MATCHES ONE OF THE LANGUAGE'S SPELLINGS FOR THE SAME LITERAL, RESTING ON A STYLE THE TREE DOES NOT ENFORCE. A guard is written over source text, the pattern is drafted from the lines in front of the author, and every one of them uses the house style, so the pattern encodes the style without anybody deciding to. It is complete against the code that exists and blind to the code somebody types next, and the difference is one character. It is a sibling of the two-spellings-of-a-path class and the harder half of it: there the producer was a program and could be read, here the producer is a person, and a person may spell a string three ways in TypeScript, two in Python, and in most languages more than one. WHAT HIDES IT is that the check DOES fail for the defect, so it can be watched red and the red is honest. Nobody re-runs it with the same defect written differently. MEASURED ON wk-1412093cd8: the guard over flags written at a call site names extension.ts and fails when the flag carries double quotes, and answers 0 failed when the same flag carries single quotes or backticks, on a token minted because a wrong flag reached the engine from a call site. INSTEAD, AND THE FIRST HALF IS WHAT STOPS IT BEING MADE: before writing a pattern over source, list the ways the language can spell the thing you are matching, and write the list into the pattern's comment. For a string that is a single quote, a double quote and a template. For a number a separator and a radix. For a name an alias and a re-export. Then either cover all of them or say what makes the missing ones impossible, and impossible means a rule the tree enforces rather than a style everybody happens to follow. A check resting on an unenforced convention is a check resting on a habit, and habits are what new code breaks first. THE SECOND HALF IS THE CHECK THAT CATCHES IT, and it is a re-run rather than a new test: having watched the guard go red on the defect, retype the same defect in each of the other spellings and watch it again. One red proves the guard can fire. Three reds in three spellings prove it fires for the thing rather than for the typography, and that is the difference between a guard and a coincidence.
