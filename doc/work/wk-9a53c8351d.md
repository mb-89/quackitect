## detail

util/checks/binaries-live-in-bin.mjs exists and the battery's for-loop never names it, so it is a check nobody runs. checks-live-in-the-method reports this as FAIL on every run: "the battery runs every check in util/checks". Adding the name is one word, but it will then run for the first time and is expected to fail: src/engine/engine.exe is a 19MB binary sitting outside .bin, which is exactly what that check exists to catch. So the fix is two parts, the name and the stray binary. Found while proving wk-4700fc5ccd by running the battery against a copy of the tree.
