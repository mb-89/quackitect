## detail

A follow-on from [[wk-2f51c2156a]], which gave a session its name back and left the table drawing the name it gave up.

AgentsPresent in src/engine/doing.go draws a row under names[len(names)-1], the last name in the alias list. The rename appends the given-up name to that list, so the last name is now the old one. One row is drawn, it names the right token, and the count is right. Only the label reads main plus a short id where the session is main again.

The owner's bar in September 2026 was that the table and reality agree. A row labelled with a name nothing else uses does not meet it.

The comment above that line says the last name it pulled with is the name the record uses, and that was true while the register's name was the stale half. The rename inverts it: the register now carries the current name and the alias table carries the history.

## proposed action

Draw the row under the register's own name, and keep the alias list for recognising a token held under an older one.
