## detail

The engine starts, answers one question and dies, five times per tool call, so every fact it must remember becomes a file. A resident engine on a local port would hold that state in memory. The guard, the VS Code window and the MCP stub become three clients of it. Settle before building: who starts it, what a hook does when it is not running, and whether the command line stays a client. Also which port, how a second project avoids collision, and what stays on disk. The owner asked for this to be discussed rather than built.
