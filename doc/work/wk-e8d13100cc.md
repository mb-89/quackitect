## detail

Every agent that ends on this box leaves its hold behind, and each stale hold makes a fresh investigate notice. A worker pull answers the notice rather than work, so the queue spends pulls on the dead.

Measured today. Nine actors ended over one session and each one produced a look. Two were one-off actors that made a single pull. Three separate agents reported the same loop in their own words, one calling it the queue looping on silence notices.

The engine already knows when a holder is gone. HasGone in src/engine/gone.go judges it by silence in the record, and SilenceBeforeGone reads the pulse. The sweep uses it on a start, and the notice uses it on a pull. Nothing uses it between, so a hold sits until somebody pulls and is sent to look.

What is gained: the queue hands out work rather than looks, and a hand that ends costs nobody a pull.

What breaks if it is never done: every ended agent costs a look and a pull from whoever comes next, and that grows with the fleet.

## proposed action

Run the same judgement on the engine's own beat. The engine has a pulse, limits.heartbeat_seconds, and HasGone already answers the question from the record. Sweep the holds on that beat, release the ones behind a hand that is gone, and write the record line the arrival sweep writes.

Leave the notice where it is. A hold released by the beat never reaches it, and one the beat cannot judge still asks a person to look.

## done when

- a hold behind an agent silent past SilenceBeforeGone is released with no pull, decided by a Go test that takes a hold, ages the record and waits one beat
- a hold behind an agent that is still calling is left alone over the same beat, decided by the same test
- the release writes the record line the arrival sweep writes, decided by reading the record in that test
