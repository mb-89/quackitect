## detail

A rule taught to one half of a machine built as two mirrored halves. No test asks the two to agree, and the other half accepts the shared payload and does nothing with it. Seen on wk-40ae28cd1a, where the reclaim skipped the two spec mirrors, and on wk-7f0b46d99f, where the re-watch refusal is in judge and not judgeSpec. When adding a rule to a system with mirrored states or verbs, write both members down first, in a table the code reads. The check asks the pair: enumerate the halves where the system declares them, drive the rule through each, require one answer. When the halves share a payload, assert that a field the second half ignores is refused rather than accepted.
