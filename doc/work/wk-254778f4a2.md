## detail

CLASS: A RULE TAUGHT TO ONE HALF OF A MACHINE BUILT AS TWO SYMMETRICAL HALVES. A system is deliberately made as two mirrored halves with the same verbs, so that somebody who has learned one has learned the other. That symmetry is what makes the next rule land on one of them: the author is looking at the half the finding came from, the code there reads complete, and the mirror is somewhere else in the file with a different function name. Nothing goes red, because each half is internally consistent, and no test asks the two to agree. WHAT TURNS IT FROM A GAP INTO A LOSS IS THE PAYLOAD: the shared shape means the other half ACCEPTS the field and then does nothing with it, so the caller who does the work gets no error and no record, which is worse than a refusal. And the prose written for the change says the rule plainly, with no qualification, because when it was written the author was thinking of one half. MEASURED TWICE IN ONE DAY ON THIS QUEUE. wk-40ae28cd1a: the reclaim answered imp_in_review and imp_in_work and not their two spec mirrors, so a drafter that died holding a token stranded it for good. wk-7f0b46d99f: the re-watch refusal is called from judge and not from judgeSpec, and a spec acceptance takes a rewatched entry and drops it, which is 8 of the 41 acceptances in the record. INSTEAD, AND THE FIRST HALF IS WHAT STOPS IT BEING MADE: when you add a rule to a system whose states, verbs or paths come in mirrored pairs, write both members down before writing either one, and put the pair in a table the code reads rather than in two functions that happen to agree. THE TELL is a switch, an if on a status, or a function name carrying half of a pair, spec against imp, read against write, open against close. Whenever you touch one, the question is not whether the other needs it but what the other does instead, and if the answer is nothing, that is a decision to write down. THE SECOND HALF IS THE CHECK THAT CATCHES IT, and it asks the pair rather than the member: enumerate the halves from wherever the system declares them, drive the new rule through each, and require the same answer or a stated difference. A test written against the half you built cannot see the other one, so name the check after the pair. And when the two halves share a payload, assert that a field the second half ignores is refused rather than accepted, because silence is the failure that costs the caller their work.
