## detail

A keep rule on a destructive sweep was justified by a sentence about how the tree is arranged, and nobody counted. For every criterion that keeps something back from a destructive pass, run its rule over the real tree. Print how many entries it keeps, how many it takes, and how many of the actors or tokens alive today it covers. Never build a keep on a sentence about the tree without the command that counted it. Key a protection off a fact the engine writes, such as who holds a token, rather than a convention. Related: wk-4d0912e39c, wk-339068932c.
