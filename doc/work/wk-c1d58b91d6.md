## detail

A stop claim made through the lane is stored under the name the agent pulls with, and the stop hook looks it up under the name the harness gives the same agent. The two differ for every agent that pulled under a name of its own, so the stop is refused with NO CLAIM IS STANDING however many times it is claimed.

Measured on 51b0d06, 2026-09-05, session 20260905-103015. The main agent pulled as fable-cloud and claimed `se_stop {because: decision}` five times between 10:41 and 10:43. .se/stop-claim.json holds the claim under "fable-cloud", at 10:43:32, unspent. .se/log/session.jsonl records every one of those calls with actor "main", which is what the harness names the agent, and every Stop hook answered NO CLAIM IS STANDING. The same file holds a claim under "reviewer-glass" whose harness name is general-purpose-3. Nothing in src/engine/hook.go names the alias table: decideStop calls StandingClaim(roots, actor) with the harness name, SpendClaim(roots, actor) likewise, and the table NoteTheNameItActsAs writes in src/engine/gate.go, harness name to the names it pulled with, is read by nobody on this path. The engine even says the link out loud when it refuses a Bash call: "The harness calls you main and you pull as fable-cloud". The notice the refusal gives blames a call after the claim, so the agent reads a refusal it cannot act on.

## proposed action

One name resolves to every name it acts as. A function in src/engine/stop.go, namesOf(r, harness) []string, answers the harness name followed by TheNamesItPullsWith(r)[harness]. StandingClaim answers the first claim standing under any of them, and SpendClaim spends all of them, so a claim under a pulled name is found by the stop and ended by the next call, whichever name the call carries. ClaimStop is unchanged: it stores under the name it was given, and a claim typed at the shell under the harness name still works. A test in stop_test.go writes the alias main to fable-cloud, claims as fable-cloud, and asserts StandingClaim(r, "main") finds it and SpendClaim(r, "main") ends it.
