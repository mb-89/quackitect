## detail

Sort and Group by take more than one level, like v3.

TODAY THE ENGINE REPLACES EVERY LEVEL WITH ONE. SetSort and SetGroup were
written that way on purpose, so a column heading and the level list could not
disagree about what is in force. That was the right call for one level and it is
the wrong call for many.

WHAT CHANGES:
- the engine keeps a list. A level is added, removed, or rewritten by position.
- a heading press sets the FIRST level rather than replacing the list, which is
  what kept the heading and the list agreeing.
- the editor draws a row per level with a way to add one and drop one, and an
  empty list still draws one blank row so there is something to fill in.

THE ORDER OF THE LEVELS IS THE ORDER THEY SORT IN, and that is the person's, so
it is what the file says and not what the data suggests.

CHECKED BY DRIVING THE PAGE. .se/scratchpad/drive-editor.mjs presses things in
a real DOM and reads what was sent. Two levels added, one removed, and the
message that reaches the engine names both in order.
