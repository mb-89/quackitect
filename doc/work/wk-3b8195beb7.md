## detail

The tree calls it traced and the owner calls it tracked. Both name the same thing: a token in doc/work, which git carries.

TracedDir is the function, and the guidance and the mint now say tracked. So a reader meets two words for one idea, which the voice rule forbids.

EphemeralDir is the other half and has the same problem. The owner says local, the code says ephemeral, and the folder is .se/work.

A rename is mechanical and the tests name the functions, so it fails loudly if it is half done.

## proposed action

Pick the owner's words: tracked and local.

Rename TracedDir to TrackedDir and EphemeralDir to LocalDir, and every comment that says traced or ephemeral of a token.

Leave the folder names alone. doc/work and .se/work say where, not what.
