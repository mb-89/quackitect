## detail

LEVEL 3. Nothing here is doable at Level 0 or Level 1, and this exists so the debt survives until the level that can carry it.

WHAT IS OWED. doc/coverage.md maps a story and a case to the test that proves it, and a person keeps it by hand. It stops at Level 0. Level 1 shipped built and tested with no row in it, and nothing went red, because nothing mechanical is watching. That is the whole of the coverage rule today: an intention held up by somebody remembering.

WHY IT CANNOT BE BUILT YET. A mechanical check needs three things this system does not have. A use case as a thing the engine knows. A user story as a thing the engine knows. A graph joining both to the tests. Level 0 controls how the agent behaves and holds none of them. Level 1 teaches the agent to do work at all, and a work token describes work rather than a requirement. Forcing the concepts in early means building them in a level that was not meant to carry them, and the level stops standing on its own, which is the first acceptance test in the cross-cutting document.

WHAT CLOSES IT. At Level 3, where the process is the thing being run: a use case and a user story the engine can read, an edge from each to the tests that prove it, and a check that fails naming what has no edge. Then doc/coverage.md is drawn rather than written, and the hand-kept map goes away.

RETROACTIVE. Level 0 and Level 1 are the backlog that check inherits on the day it runs. Expect it to be red, and expect the first pass to be a sweep over work already done rather than a gate on new work.

UNTIL THEN. The map says where it stops, and cross-cutting-design.md carries the ruling that this is Level 3 work. Both were written on 1 September.
