## detail

Work is not owned by whoever drafted it: a finished specification goes to any free worker and a waiting submission to any free reviewer. Today both queues hand out only tokens whose assignee names the actor, so a finished spec sits idle while its named worker is busy. The pull hands an open token to any actor in the matching role unless the assignee is human. It writes the holder as it does now. An agent never starts work assigned to human, and every other assignee is a label rather than a gate. A person putting a token first stays an order, and four-eyes still asks who submitted rather than who owns. Rework the mint refusal that says every token is somebody's with this.
