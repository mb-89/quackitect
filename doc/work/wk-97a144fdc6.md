## detail

The queue held 113 open tokens with one hand on it, and the staffing guard never fired.

The fault is that a hand which has gone home is still counted.

StaffingOf counts every actor that pulled in this session, and nothing takes one out again. The arrivals record on this box lists thirteen actors, of which three are here.

So the count answered eight workers and five reviewers where one session and three helpers were working. It wants three of each, found more than three, and never fired.

The guard itself is sound. It runs before every other guard and it holds the session's own work. The register names that session main, which is the name the guard asks for.

What is missing is that a stopped agent and a gone agent are both still hands to this count.

## proposed action

Hold the session's own agent under whatever name it pulls with, and count as a hand only an agent that has neither stopped nor gone.

## done when

- an actor with a standing stop claim is not counted in workers_here
- an agent the register says has gone is not counted in workers_here
- a spawned worker that is working is still counted, so the guard stops asking once the hands are here
- with the hands gone home, the guard refuses the session's work and says how many to spawn, proved by a Go test

## approach

Two small changes in staffing.go, and no new state anywhere.

The count drops a hand that has gone. An actor with a standing stop claim is stopped, which the record already answers, and an agent the register marks gone is gone. Neither is a hand.

What stays is the fallback. An agent that pulled and was never registered still counts. On a harness that sends no start for a subagent, the pull is the only witness there is.
