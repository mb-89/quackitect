## detail

Before agreeing a draft that changes a gate, read the gate trigger set out of the code and check every member against the detail. Case in point: wk-45a742fbeb round 1 said only writes, but the gate triggers on WriteTools, which is Write, Edit, MultiEdit, NotebookEdit, Bash and PowerShell. A Bash call is gated whatever it does, because insideTheScratchpad refuses a call with no path. All four criteria drive the gate through a Write. When drafting a change to a gate, write one sentence per trigger member before writing a criterion. Related: wk-32cbd5092d.
