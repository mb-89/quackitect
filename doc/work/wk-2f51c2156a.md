## approach

THE LANE INVENTS A NAME BECAUSE IT HAS NOTHING ELSE TO SAY.

orMain at src/mcp/lane.go:690 answers the literal "main" when no actor is named, and nothing in the lane names one. TheActorOf at evidence.go:306 answers TheSessionName, which the register wrote. Here that is main-41d2115e. So the hook records one name and the lane pulls under another.

aSessionName gives main to a run's first session and main plus a short id to the next. A session then keeps that name.

THE LANE CANNOT BE HANDED A SESSION. roots.go reads no session id, and .mcp.json is static. So the register has to stop needing the lane to know.

THE OWNER PICKED THAT, in September 2026: give the name back, and the table and reality agree.

A session named main plus a short id takes main back, once no live agent of this run holds it. A name is given up only toward main, so it settles rather than moving.

The rule it argues with is that a session keeps its name. That rule protects tokens held under the old one, so the rename carries the alias. The old name goes into the alias table as one this agent answers to.
