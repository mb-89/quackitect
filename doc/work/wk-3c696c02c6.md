## detail

Pressing hold, or finish up, changes nothing a person can see. The button does not draw as on.

Unbound draws as on, and ideation draws as on. Hold and finishing do not, so the one control that quietly changes what every agent may do is the one control with no state on its face.

THE OWNER'S WORDS: I just clicked the hold or the finish up button, and I don't see it toggled. That's not good. I need to see it toggled. The same way I see the unbound toggled and the same way I would see the ideation toggled.

It is not cosmetic. Finishing refuses a take-up: a token was claimed in September 2026 and the engine answered that a person had put the work on finishing, and that answer was the first sign the mode was on at all. An agent meets the mode as a refusal, and a person meets it as a button that looks the same either way.

The state exists in the engine. LoadHold answers Held and Finishing, and the staffing guard already reads both. Nothing is missing behind the button. What is not known is whether the panel is handed those two, or is handed them and does not draw them.

## proposed action

Draw hold and finishing as on, the way unbound and ideation are drawn.

## approach

Find out which of the two it is before changing anything, because they are different repairs.

Read what the engine hands the panel on the beat, the way unbound and ideation arrive, and see whether hold and finishing are in it. If they are not, they join it at the same door those two use, and no second transport is added. If they are, the drawing is what is missing.

Then the button draws its state the way the others do, and one check drives all four toggles rather than the two that happen to work.

## done when

- with the engine on hold, the hold control draws as on, and draws as off when it is not, decided by: util/checks/drive-panel over both states
- with the engine finishing, the finishing control draws as on, and draws as off when it is not, decided by: the same check
- one check covers all four toggles rather than two, so a toggle added later cannot ship undrawn, decided by: the check naming unbound, ideation, hold and finishing
