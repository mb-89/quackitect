## detail

Found closing wk-aa039204a4, which this token names.

TestTheQueueIsStaffed stores limits.parallel_agents as three in its tree, at src/engine/standard_test.go line 259. Three is also the shipped default, at src/engine/config.go line 499.

So the test is green whether or not the store works. Measured on a detached worktree at the branch tip. Taking the theParametersSay line out left the test passing, because the hook fell back to the default and read the same three.

That is the exact class wk-aa039204a4 was minted for. The hook loads its own config out of the tree it is given. A test whose number matches the default cannot tell a working store from a broken one.

Proving the store does work needed a second mutation. With the default moved to five and the tree still saying three, the test stayed green, so the tree value does reach the hook. With both mutations together it failed at line 293, the hook asking for four subagents.

A number the default does not carry makes the test bite on its own.
