## detail

A FINDING WHILE WORKING wk-40abb881a7.

deltaSince in src/engine/tests.go diffs the tree against the token's last began snapshot. That snapshot is a commit under refs/se/steps, which no push carries. A token taken up on one box and worked on another has a began hash the second box never had, and git diff on a full hash it does not hold says fatal: bad object <hash>. deltaSince reads the error for Could not access, bad revision, unknown revision and ambiguous argument, and bad object is none of those, so se test --on that token answers an error and nothing runs. Measured on wk-40abb881a7 on this box: git diff: fatal: bad object c2682c671c7ab75306367de55d36104c0ec51b96, while every other tracked token tested. The take-up added no snapshot here, because openStretch sees a stretch already open (three began, two ended) and does not open another.

## proposed action

Treat bad object the way bad revision is treated: no history to diff against, so the untracked list is the delta. Better still, when the last began is not an object here, fall back to the newest began this box does hold, and then to HEAD, and say in the answer which since was used.
