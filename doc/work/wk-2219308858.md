## detail

A THIRD SHAPE THE HOLD RULE READS AS A CLAIM, ON A NOTE WRITTEN SINCE IT WAS MEASURED.

wk-6741a3e30a took the rule from nine findings to two. Both that remain are wk-24cdeae29b, and both are the word unheld used of tokens in general rather than of one:

  title: unheld tokens want approaches
  Read each unheld token the check names, and write an approach onto it

claimsAHold in src/engine/lint.go counts unheld as a claim where the word before it is is, was, are or were, or where the word after it starts with token. That last half is what catches these. A plural, and a singular under each, name no token and no session, so neither goes stale when the session rolls.

It is the same defect the rule was narrowed twice for: a sentence about the rule read as a claim about the token it sits on. Here it reaches a title, which is the token's name.

That note is in another hand, worker-tallis, so it was not touched. The rule is what changes: the note says exactly what it means.

## proposed action

Narrow the unheld half of claimsAHold so a generic subject is not a claim. Where the word after unheld is a plural, or the words before it are each, every, any or no, the sentence is about tokens rather than this one. Add both lines to the clean table in src/engine/holderinprose_test.go, whole, and watch them go red first.
