## detail

The investigate flow judges a holder stale by pulls alone. A worker deep in one long proof arrives rarely by design, so it stands accused while it is working.

Seen twice. One worker was writing its token test file and running the test door minutes before it was called stale after 48 quiet rounds. Another recognised the same shape against itself and declined to pull, so as not to strip a live hand.

StillPulling counts arrivals and nothing else. The token carries a trace the engine already writes and nobody reads on this path.

## proposed action

Staleness reads the token own trace beside the pulls. A write under the held token, a run naming it, or its file changing counts as still working.

The investigate notice then fires only when both the pulls and the token trace have gone quiet.

## done when

- a holder that wrote under its token recently is not called stale: a test drives a quiet pull count with a recent write and reads no notice
- a holder quiet on both counts is still called stale: the same test drives both quiet and reads the notice
