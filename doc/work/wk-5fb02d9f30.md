## detail

A criterion says a thing exists and then says what it must be the same as, with a command that only checks existence. On wk-66a28ca311 the criterion says the .kinds rule is the same divider as the .top one. util/checks/render-check.mjs asserts only that a div of class kinds sits between the last query and the first bucket. Changing the .kinds declaration in src/extension/editor.ts to a dashed 4px line left render-check, drawn-classes-have-rules and one-look green. When a criterion carries the words the same as, name the second place and write both locations into the criterion beside the command. The check reads both declarations out of the source and compares them field by field. Related: wk-66a28ca311.
