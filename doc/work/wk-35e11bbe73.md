## detail

The queue answers investigate for a token whose holder has stopped pulling, and raises the same alarm on every pull after the walker has looked. Let the walker answer the investigation, have the engine record that somebody looked, and leave that hold alone for a while. The length of that while is a number of the same kind as the staleness and belongs beside it. The staleness count is also wrong for a reviewer, since a reviewer reading one token looks the same as a dead one. Either make the number depend on the role, or make looking answerable, or both.
