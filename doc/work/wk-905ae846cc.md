## detail

writing-go rule 14 asks a test to compare with cmp.Diff, and github.com/google/go-cmp is required by no go.mod in the tree. So the clause cannot be obeyed anywhere.

The four modules are src/engine, src/mcp, src/viewer and util/setup. Two dependencies are already required by src/engine, fsnotify and go-sqlite3, so this sets no precedent.

There are two places to use it at once: reflect.DeepEqual appears in one test file in src/engine, twice.

## proposed action

Require go-cmp in the four go.mod files, and replace the two reflect.DeepEqual comparisons with cmp.Diff.

- no _test.go file under src or util calls reflect.DeepEqual
