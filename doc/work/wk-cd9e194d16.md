## detail

From the verdict on wk-887e9a126a, the engine archives.

src/engine/archive.go says of the archive list: "It travels, because a box that reads the tree out of git should see what has been archived without asking git."

It does not travel. .gitignore line 5 is *.jsonl, and git check-ignore -v doc/work/archive.jsonl answers .gitignore:5:*.jsonl. git ls-files --error-unmatch on it says the path is known to no one. The engine writes it and never commits it, by design, because it never touches the branch.

So a clone has no archive list at all, and the only way to get one is se archive --sweep, which asks git. That is the very thing the file exists to spare a reader. The one reason the file is allowed to exist beside a ruling that refused an index is unmet on every box but the one that closed the token.

Either the list is committed and travels, or the comment stops claiming it does and says what it really is: a local rendering the sweep puts back.

## done when

- the archive list travels or stops claiming to: git check-ignore -v doc/work/archive.jsonl answers nothing, or the comment on ArchiveList no longer says it travels
- a check catches the class: a check asserts that no file the engine writes for a reader to open is one git ignores
