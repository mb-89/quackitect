## detail

In src/engine/gate.go, WriteNeedsAToken asks everyNameOf(r, actor) for open tokens but builds its menu over the raw harness name. No token is assigned to a harness name, so a subagent is told nothing is open when its own tokens are open. The suggested command also prints the harness name in --by, so an agent that obeys it holds the token under the wrong name. Build the menu over everyNameOf(r, actor), print the pulled-with name in the suggested command, and say which name is which when they differ. Check: drive the gate with a harness name linked to a different actor holding an open token. Require the refusal to name that token and spell --by with the pulled-with name. Related: wk-4e8eeb76aa.
