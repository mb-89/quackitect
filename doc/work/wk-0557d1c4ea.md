## approach

One package at a time, and each package is a sub-token of this one. The queue hands sub-tokens out before their parent, and the parent cannot close while one is open.

Order is smallest first: src/mcp with three files, util/setup with two, src/viewer with seven, then src/engine with a hundred and thirty.

Inside a package the unit is a file. A file is converted, built and tested before the next one starts. A package left half converted stops every other hand from building any test in it, and that is the cost this order exists to avoid.

A table earns its place where cases share setup. A single case stays a single function, and each sub-token says which files it left alone and why.
