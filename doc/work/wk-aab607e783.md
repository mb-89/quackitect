## detail

Found working wk-113887f540 on a cloud box cut for group/tests.

util/git/land.sh names trunk twice and reads the branch nowhere. Line 88 is git fetch origin v4, and line 104 is git push origin HEAD:v4. So a land from a group branch commits the work onto trunk and answers PUSHED, and the group branch never moves.

Measured on 2026-09-07. Four lands answered PUSHED and CLONE AT. origin/v4 went to f7aa7d7e carrying all four, and origin/group/tests stayed at 770a7d65, where the box woke. Nothing said the branch had been passed by. The stop hook found the tree dirty, and that is the only reason it was looked at.

The card this box was handed says the branch is the group, and says to merge back when the group is empty and leave the branch standing. A door that lands on trunk means there is nothing to merge back, and a group branch reviewed before it merges is reviewed empty.

AGENTS.md calls land.sh the push door, so an agent following the tree's own instruction lands on trunk without being told.

The work was recovered by pushing group/tests forward to the same commits, a fast-forward from 770a7d65 to bb2fd802. Trunk keeps them too, because nothing rewrites a pushed trunk.

## proposed action

land.sh pushes to the branch this tree is on, and says which branch it landed on.

## approach

Read the current branch with git rev-parse --abbrev-ref HEAD, fetch that branch rather than v4, and push HEAD to it. Trunk stays the target for a tree already on trunk. The PUSHED line names the branch, so a land that goes somewhere unexpected says so. A detached HEAD has no branch to read, and that case decides the default.

## done when

- land.sh run on a group branch moves that branch and leaves trunk where it was. Decided by: a land on a scratch branch, then se run git ls-remote origin over both refs
- the line land.sh prints names the branch it pushed to. Decided by: reading the output of that same land
- land.sh run on trunk still pushes to trunk. Decided by: a land from a tree on v4, then se run git ls-remote origin refs/heads/v4
