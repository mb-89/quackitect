## detail

Three panes, not two, in the generic editor.

THE NUMBER TWO IS WRITTEN INTO THE EDITOR. There is a left and a right, a
button that shows the second, and one seam. The owner wants three, and the
right answer is that the editor stops knowing how many.

WHAT THAT MEANS: the view file declares the panes, the page draws one per
declaration with a seam between each pair, and the control shows and hides them
by name rather than by being the second one.

PROPERTY COLUMNS AND NESTED ROWS COME WITH IT. Both are the generic editor's
own capability rather than the work editor's, so they are built here and the
work editor gets them by being two of these.

THIS IS THE GENERIC EDITOR AND NOT THE WORK EDITOR. The owner asked for the
generic one first and the work one on top of it, and the number of panes is
exactly the kind of thing that belongs below rather than above.

CHECKED BY DRIVING THE PAGE. Three declared panes draw three, the control shows
and hides each one, and a seam sits between each pair rather than a single one
between the only two.
