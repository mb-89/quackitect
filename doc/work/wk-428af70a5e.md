## detail

An anti-vacuity guard placed on the members rather than on the set. The check drives one producer and refuses only when that producer emits nothing. Nothing guards the number of producers, which is what the word every was about. Before writing the guard, name the set every refers to in the criterion, count the producers, and write the count into the criterion. Then add a second producer that violates the claim in a copy of the tree and run the check. If it stays green the guard is on the member. Related: wk-40ae28cd1a.
