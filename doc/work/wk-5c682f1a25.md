## detail

Nothing checks that a token's tests passed before it closes. The standard process carries a row saying se test on this token answered ok, and an agent writes that row itself. checkEvidence asks only that each row is ticked or carries a sentence. So done means an agent said so. Measured 2026-09-06 while working wk-857e0a4f99, which made the battery answer honestly and then showed that nothing reads the answer at a close.

## proposed action

Gate the close on what the engine ran rather than on what the agent wrote. A token whose last run over its delta did not pass does not reach done.

## done when

- A submission on a token whose last run failed is refused, and a test drives it and reads the refusal.
- A submission on a token whose last run passed is accepted, and a test drives it.
- A submission on a token whose battery has not finished is refused as not yet green, and a test drives it.
