## detail

A rejection mints the lesson's token, and the engine does it rather than the reviewer. Owner's decision: the engine only accepts a rejection if it can name the new token it minted, and that is automatic. One token per lesson and not per finding. A class is the key, so the same class is never minted twice and the answer names the token that already exists. The minted token is backlogged. Related: wk-c22f29af7b.
