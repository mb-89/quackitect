## detail

A check built after the work, from the work, cannot go red. Write the check first, run it against the defect and watch it go red, then do the work. The rule is written in doc/guidance/reviewing.md under findings, where a reviewer reads it, and nowhere a worker reads before submitting. Put the same rule in doc/guidance/behaviour.md under Evidence, in the worker's own words. Better, have the engine refuse a submission whose evidence does not name a check that was seen to fail. Related: wk-bc3c5ba905.
