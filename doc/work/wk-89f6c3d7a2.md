## detail

Before replacing a fragile pointer with content, go to the thing that produced the content and ask whether it holds it as text. A format string, a template or a renderer does not. There the durable handle is the name of the producer: the test, the template, the function. Before writing the remedy, apply the new rule to every row in the record and paste into the draft the count it converts. Case in point: wk-42adef4818, where 26 of the 32 observations naming an address carry text that appears nowhere under src, each from an Errorf.
