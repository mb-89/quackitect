## detail

A configurable constant exercised only at its default, so nothing can tell the config from a hardcoded number. On wk-d898634fd3 the criteria refuse a draft of nine, allow eight, and read the value back from config. DraftReady comparing against a literal 8 passes all three. The tell: count how many distinct values of the parameter the criteria drive the behaviour at. If the answer is one and it is the default, no check can see the wire. Instead, set the parameter to a value that is not the default in the fixture, then assert the behaviour moved with it in both directions. src/engine/config.go carries SetValue and src/engine/config_test.go already writes values into a fixture tree. When a token says a number is configurable, write the fixture number different from the default before writing anything else.
