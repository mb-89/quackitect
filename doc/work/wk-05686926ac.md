## detail

A finished battery comes back as one ran entry, kind battery, whose said is its last line. So a token whose delta reaches util/parameters.json runs the whole battery and inherits every red in the project.

TestsRefuseTheClose already scopes a check failure to the delta: a check naming only files this token did not touch is the project red and no longer stands in the way. A battery names no file at all, so that scoping never reaches it.

MEASURED, September 2026. wk-8fb3314926 landed green on its own twenty tests. Its close was then refused by a battery whose eight reds were golangci-lint being older than the target, a panel column rule, thirteen older tokens with no approach section, and a flat package this token added five lines to.

The battery page already has the shape. Each step is a line: a name, ok or FAIL, its seconds, and what it said, with continuation lines indented under it.

## proposed action

When se test reads a finished battery, expand its page into one ran per step rather than one for the whole. A step that builds or runs Go tests, including the race detector, is kind go and is never excused. Every other step is kind check, and the existing scoping applies to it.

## done when

- a Go test drives a battery page of one foreign check failure and one passing step, and the close is not refused
- the same page with a go test step red refuses the close, whatever paths it named
- the ran the engine answers with names each failing step by its own name, not battery
