## detail

The reflect walk reaches a map as one node, so the table gets one row about the value. The key is written by different rules. In this record a map key becomes part of a heading line and the value becomes a block. A Token.Submission or Token.Rewatched key carrying a newline saves without complaint and reads back cut, with the rest prepended to the value. Before writing the walk, read the writer, count how many strings it takes out of each field, and yield one entry per string. Add a round trip for every map the record writes that saves a key carrying a newline, the heading delimiter and the section lead. Require the entry back byte-identical in key and value, or refused by name. Related: wk-24be1c06ae.
