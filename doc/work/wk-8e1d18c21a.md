## detail

Closing the editor window has to shut the engine down, and today the engine outlives both the window and an agent restart. The owner ruled that this system never has the engine without the editor, so build both mechanisms. Heartbeat: the editor writes a beat as the engine does into .se/engine.json, and the engine reads it with the function in src/extension/liveness.ts. Two missed beats and the engine shuts itself down, but only when the extension spawned it, so a headless terminal run stays up. Job object: on Windows JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE, on Linux PR_SET_PDEATHSIG or a process group, via koffi as src/extension/keys.ts already does. On the way out the engine puts down what it holds with se work --put-down. Proof: close the window or kill the editor process and see the engine gone within two beats. Start from a terminal with no editor and see it stay up.

## done when

- Close or kill the editor: the engine is gone within two beats. A bare-terminal engine stays up.
- Only extension-spawned engines self-stop. Held tokens are put down on exit.
