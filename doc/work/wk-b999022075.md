## detail

CLASS: A CRITERION THAT SPECIFIES THE CONTENT OF A FILE ANOTHER CHECK ALREADY
GUARDS, WITHOUT ASKING WHAT THAT CHECK REFUSES.

The deliverable is prose. The last round said a search for a topic word decides
nothing, so the next draft asks for the evidence itself: the literal path, the
literal command, the literal value the argument turns on. That is the right
answer to the finding. It is also the exact thing a standing check keeps out of
that file, and nobody asked, because a guard over a file is not something a
drafter reads while writing sentences.

THE TWO CHECKS THEN DISAGREE AND ONLY ONE OF THEM IS ON THE LIST. The token's
criterion goes green when the literal is there. The battery goes red for the
same state, and the battery is not a criterion, so the draft is agreed with the
contradiction inside it.

THE WORKER MEETS IT AT THE KEYBOARD AND SETTLES IT ALONE. The usual settlement
is to weaken the criterion until both pass, which is the shape the previous
round rejected, so the round is spent and the defect comes back wearing the
remedy.

MEASURED ON wk-8573243384, round 3. Criterion 3 asks the rule to carry the
spelling that was looked for and the spelling every cage file writes, which are
two spellings of this machine's root. I wrote both into a copy of the tree and
ran the tree's own guard. TestNoCagedFileNamesTheMachineItWasWrittenOn went red
on all three projections of that file, at src/engine/cage_test.go:59. It is the
same guard the token's own story is about.

INSTEAD, ASK WHAT ALREADY READS THE FILE BEFORE SPECIFYING WHAT GOES INTO IT.
For a guidance file that is the projector and every check over its targets. The
question takes one search and it is the drafter's, because the worker cannot
change a criterion that has been agreed.

AND RUN THE BATTERY OVER A DRAFT OF THE SENTENCE, IN A COPY, BEFORE THE
CRITERION IS AGREED. A criterion about prose is cheap to try: write the
paragraph, run the checks, see what refuses it.

AND WHERE A LITERAL IS REFUSED, SAY IN THE CRITERION WHAT STANDS IN FOR IT. A
description of the value is what the previous round rejected, so the criterion
names the substitute it will accept and says how the check tells it from a topic
word. Leaving that to the worker hands them the contradiction and no way out of
it.
