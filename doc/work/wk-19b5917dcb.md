## detail

SPIKE. Level 0 wants to warn the agent to save what it needs before the context is compacted, and marked it OPEN, verify first: it only works if the agent gets a turn between the hook firing and the compaction.

WHAT TO MEASURE. Fire the pre-compaction hook and establish whether anything the agent does after it survives. Not whether the hook runs. Whether a turn exists in which the agent can still act, and whether what it writes in that turn is there afterwards.

WHY THE ORDER MATTERS. If there is no turn, the warning is unactionable and it creates false confidence, which is worse than having no warning: the design would claim a save point that never runs, and the agent would be told to rely on it.

WHERE THE ANSWER GOES. Into the Level 0 design as a ruling. If there is a turn, the warning is admitted and it says what to save. If there is not, the entry is struck and replaced by whatever does work, which is likely the engine writing the state rather than the agent being asked to.
