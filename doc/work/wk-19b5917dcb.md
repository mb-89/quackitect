## detail

Spike. Level 0 wants to warn the agent to save what it needs before the context is compacted. That only works if the agent gets a turn between the hook firing and the compaction. Fire the pre-compaction hook and establish whether such a turn exists, and whether what the agent writes in it survives. Record the answer in doc/levels/level-0-design.md as a ruling. If there is a turn, the warning is admitted and says what to save. If there is not, strike the entry and replace it with whatever does work, likely the engine writing the state itself.
