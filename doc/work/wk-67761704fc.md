## detail

Front Matter (https://frontmatter.codes) ships schema-driven frontmatter dropdowns and validation, and Foam (https://marketplace.visualstudio.com/items?itemName=foam.foam-vscode) ships wiki links, backlinks and link completion. Do a timeboxed read of both sources and answer the three spike questions with file references before any editor work begins.
