## detail

wk-03303bac3f moved the cherry-pick door into util/checks, because rule 7 sends a script that earns its place there and git carries it. The engine's test guard then refused to run it.

So the door travels and cannot be opened. What made that push work was the forward left at .se/scratchpad/land.sh, which the guard lets through and which hands off to the tracked file. A fresh clone carries no such forward. An agent there reads rule 12, finds the door where the rule says, and is refused when it runs it.

TWO SHAPES. The door moves to a folder of its own that git carries and the guard does not read as checks, and rule 12 names that path. Or the guard learns which files under util/checks are checks, which is a list the battery already keeps.
