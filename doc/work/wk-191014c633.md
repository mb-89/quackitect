## detail

Hook event names are switched on as bare strings, the MCP tool schemas are nested map literals, and the engine's own answers are assembled the same way, so a typo is silent and the compiler checks nothing. writing-go rule 4: a set of known strings is a named type with constants, and map[string]any stops where the JSON is decoded. ## approach

Start at the two edges where a typo is silent: the hook event names become a named type with constants used in the switch and in the cage's settings check, and each MCP tool's arguments become a struct decoded once at the door. The tool schemas are derived from those structs by reflection so the schema and the decoder cannot disagree. Answers assembled as maps are left for a later token; this one is the two edges.
