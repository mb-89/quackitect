## detail

SIX FLAGS THE SHELL HAS AND THE LANE TOOL CANNOT SAY. lane-carries-every-flag reads the flags each engine verb declares and the fields each se_ tool advertises in util/cage/tools.json, and on origin/v4 at 79cc5e6f it answers 6 failed. se_apply cannot say --manifest. se_claim cannot say --sync or --no-publish. se_find cannot say --archive. se_stop cannot say --list. se_test cannot say who is testing, which the shell says with --by and every other lane tool says with actor. Each is a thing an agent can do at a shell and not through the door it is handed, so the cage and the shell disagree about what the engine offers, and a session with a lane reaches for RUNME.sh to get the sixth of what the verb does. What passes the check is named in it with a reason, so none of these six is a shell-only flag or a rename. They are gaps.

## proposed action

Add each field to the tool struct in src/mcp/lane.go and pass it through to the verb, regenerate util/cage/tools.json with .bin/se-mcp --tools, and let lane-carries-every-flag decide it. Where a flag should stay the shell's alone, say so in the check with the reason, beside the ones already named there.
