## detail

A finding on wk-b75b6ebff3, notes become tracked tokens.

src/engine/notesgohome.go:47 holds a call on `actor != "main" || !heldDuringShortfall[tool]` alone. heldDuringShortfall carries "Bash", and TooManyNotes never sees the command. AStaffShortfall, the guard this one was copied from, has the escape at src/engine/staffing.go:216: `if runsTheEngine(command) && !engineWork(command) { return "", false }`, so `se work --title ... --tracked` at a shell goes through a shortfall. The hook already holds the command: src/engine/hook.go:801 passes ti.Command to AStaffShortfall and src/engine/hook.go:812 does not pass it to TooManyNotes.

THE DAMAGE. This guard fires only on a cloud box, and the cloud box is exactly where a lane may be absent: the engine's own refusals say "IF YOUR LANE HAS NO se_ TOOLS, this is the same call at a shell". On such a box at twenty notes, every one of the three answers the refusal demands is a Bash call the refusal itself refuses: `./RUNME.sh work --abort <id> --why "..."` to drop a note, `./RUNME.sh work --title ... --tracked` to mint from one, `./RUNME.sh work --set --field needs_human --to true` to flag one. The agent has no legal move, which is the deadlock staffing.go:188-199 records as already having happened once and names the deny side to prevent.

THE FIX. Give TooManyNotes the command, and let an engine command that is not apply/run/test through, the way AStaffShortfall does.
