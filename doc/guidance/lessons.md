# Lessons from review

- **Borrowed recorded red** — A criterion carries a red copied from its neighbour, so nobody watched its own command fail.
Instead: Take one red per criterion in its own run and paste its output.
From: wk-041484ce8f
- **Guard fitted to the shape** — A guard built from a reviewer's offered shape refuses the extreme and misses the real case.
Instead: Write the fixture from the real case and replay every named case through the guard.
From: wk-071945d72d
- **Live fact in standing text** — Guidance carries a present-tense citation or live number nobody re-derives, and it rots.
Instead: Write the case in the past tense, pin it to a commit, and keep numbers on the token.
From: wk-0fee3718f6, wk-aea7597e98
- **Two writers, no merge rule** — Two paths assign one field, each tested alone, so the second write erases the first.
Instead: Decide the merge rule at the declaration and test both paths in work order.
From: wk-21d21caf22
- **Old path left reachable** — A fix adds a correct path beside the defective one and leaves inputs reaching the old one.
Instead: Route every input off the old path in the same change and re-run the decoys.
From: wk-2654d6d230
- **Walker calls it differently** — A check written for its own flags lands in a folder whose walker passes one argument.
Instead: Find every walker of the folder first and give its call a criterion.
From: wk-27fe035dde
- **Count over the neighbour set** — The corroborating count runs over a neighbouring set, so a quietly added member hides.
Instead: Count the named set a second way and plant the defect by adding a member.
From: wk-2c3b160ae9
- **Command misses the sentence** — The command decides something other than its sentence: borrowed, a proxy test, or older than it.
Instead: Name the state that falsifies the sentence and require the command to fail there.
From: wk-4a1ee98339, wk-6262773775
- **Caption names unread file** — A criterion names its file, but the check also reads another, which carries the assertion.
Instead: Build each assertion's haystack from one named place and derive the failure text from it.
From: wk-4ad9aaeea2
- **Instrument picks the member** — The detail names a forbidden set, and criteria assert only the member the easiest instrument sees.
Instead: Write one criterion per member before picking an instrument and explain any omission.
From: wk-54c96c4002
- **Rows derived, answers guessed** — The table's members come from a walk, but each row's answer comes from reading, not running.
Instead: Feed every row the value it forbids, save, load, and record the result beside it.
From: wk-5697d58b1b
- **Nothing over the seam** — One criterion covers the producing half, another the drawing half, and none the call joining them.
Instead: Write the criterion over the call site first, naming file, function, and invocation.
From: wk-710f55bdb0
- **Criterion without a subject** — A criterion names a property and no file, so the check picks one copy and the other stays a stub.
Instead: Give every criterion a subject by path and make content checks walk every copy.
From: wk-7338fd6609
- **Sibling missing its instrument** — One criterion lacks the data and value its siblings carry, and a non-empty guard fills the gap.
Instead: Read the criteria as a column and write instrument, data, and value beside each.
From: wk-936df2f551
- **Allow list permits the unknown** — An allow list keeps a default of pass, or a permit branch reads a broken instrument's silence as yes.
Instead: Write the refusal first, add permitted forms one at a time, and make "could not tell" refuse.
From: wk-fdbd94a73c, wk-95d84f593e
- **Paperwork instead of the act** — Criteria cover recording, refusing, and reporting a change, and none loads the record back.
Instead: Make criterion one reload the record from the store and assert the changed field.
From: wk-b19987415f
- **Guard already refuses the literal** — A criterion demands a literal that a standing check keeps out, so the worker weakens it alone.
Instead: Ask what already reads the file, run the battery on a draft sentence, and name the substitute.
From: wk-b999022075
- **Nothing redraws the value** — A criterion renders a live value from two inputs and proves it draws, but nothing redraws it after boot.
Instead: Ask what redraws the value and make the check change the record with the page up.
From: wk-c47479d7b4
- **Literal nobody derived** — A criterion greps for a literal that claims something about the tree, and nobody ran the command behind it.
Instead: Run the deriving command before writing the criterion, or derive the literal in the check.
From: wk-dcb697c1b1
- **One member, not the set** — A finding asks for a check over a whole set, and the round fixes only the member it cited.
Instead: List every clause of the detail with its answer and build the set-wide check that round.
From: wk-dfb8fae699
- **Search cannot cross a wrap** — An absence check greps for a phrase the formatter wrapped across two lines, so it finds nothing.
Instead: Quote the fragment from one line of the file and run every search now to confirm a hit.
From: wk-ee6d5c6ab0
- **Live fact demoted to prose** — A live-fact criterion becomes prose after a quoting failure, though a command reads the world at the gate.
Instead: Run the command through the engine's own door both ways before demoting.
From: wk-f0c30a2363
- **Declared side still a photograph** — The check derives its members, but the table it holds them against stays typed from the finding.
Instead: Run the derivation first, write the table from its answer, and put count and commit in the draft.
From: wk-f22cbd19f4
- **Containment as string prefix** — A path check asks HasPrefix, so a sibling whose name extends the parent's passes, and temp-dir fixtures miss it.
Instead: Use filepath.Rel, refuse results starting with "..", copy the tree's existing instance, and hand-build sibling paths.
From: wk-f4731bc18b
