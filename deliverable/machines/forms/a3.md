# The A3 sheet

Every evidence form is one sheet in this shape (owner ruling 2026-08-04).
The engine derives a state's form from THIS file plus the state's own
markdown: the state note or matrix row carries the statement, the
motivation, the evidence fields and their templates; the reading list is
generated; this file carries the boxes every form shares.

A box line reads: `- <general heading> | <source> | <fill?> | <help>`.

- The SOURCE says where the box's content comes from:
  - `state` — authored on the state's markdown (statement, motivation).
  - `derived` — computed live (the reading list, the survey).
  - `filled` — written into the instance while the work happens.
- A `filled` box is an instance section, has a template (free-form unless
  the state names one), and multi-pass storage applies.
- The concrete slash-name after a general heading comes from the state's
  markdown, and most boxes need none.

## Boxes

- Description | state | | What this work package is — the statement and the guidance's first breath.
- Motivation | state | | Why it exists — one authored line on the state.
- Current situation | derived+filled | fill | What stands right now, opened from the survey, written in a few lines.
- Inputs | derived | | The one reading list: generated pull, declared reads, every referenced template. The method carries the before-entry mark.
- Evidence | state+filled | fill | The state's evidence fields, each with its template.
- Follow-up | filled | fill | What this work produces as next steps — work to pull in, or notes parked with their ready-when.

## The brief

The Description box IS the state's brief. Every surface that lists next
states shows it beside the name — the statement is its source, and no
second summary exists to drift from it.

## Header

- The title is `Evidence form / <state>`.
- Context rides the header:
  - the project
  - the machine position the form was born in
  - the status
  - when it was opened
  - when it was signed off
  - by whom
- Every form is a CLAIM until its gate passes it. The author field names
  who claims; an ingested fill is marked imported.
