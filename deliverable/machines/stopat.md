# The stop-at scale

FOUR NOTCHES, and each names WHERE the agent stops. It answers one question,
the neighbour of the autonomy dial's: autonomy says what the agent may decide
alone, and this says how far it may walk before handing back.

Set the control to a notch and the agent walks to that point and no further.
The notches are cumulative in the same sense the autonomy rungs are — a looser
notch permits everything a tighter one did.

`agent judgement` IS THE DEFAULT, and it is where a session starts. The two
notches above it are unlocked deliberately, one press at a time, exactly like
the autonomy rungs above the resting one. You do not jump to `blockers only`.

## Why it exists

THE STOP HOOK READS THE WALK'S POSITION AND CANNOT SEE THE REASON. So a stop
the contract REQUIRES looks exactly like an overcautious one, and on 2026-08-16
the hook overrode a rule-9 stop five times — the agent had correctly refused to
open an iteration unasked, said so, and was pushed past it anyway.

The same day, the same hook was right about eight other stops.

A RULE THAT IS RIGHT EIGHT TIMES AND WRONG FIVE CANNOT BE TUNED INTO SEEING THE
DIFFERENCE. The person can, so the notch is theirs.

ONE LINE PER NOTCH BELOW, and the parser means it. Everything under the
heading is read as a notch, so a wrapped line or a stray sentence is a
malformed level line and the whole file refuses — the same rule scale.md keeps.

THE NOTCHES CARRY NO NUMBERS, AND THE ORDER OF THE LINES IS THE SCALE (owner
ruling 2026-08-18). Tightest first, loosest last. Moving a line moves the
notch; adding one between two others puts it between them.

## The notches

- SE | state end — the engine blocks every transition; the person releases each one
- AJ | agent judgement — the agent decides when to hand back; today's behaviour
- BL | bless — the agent does not stop until a bless is owed
- BO | blockers only — the agent stops only when it cannot continue at all

## What each one is for

`state end` IS FOR WATCHING. Seventeen presses for a seventeen-state re-entry
is not a defect of the notch; it is the notch doing its job. Somebody who does
not want that moves one notch down.

`agent judgement` is the working setting, and the one whose behaviour the whole
contract already describes.

`bless` IS FOR A LONG SUPERVISED STRETCH. The agent runs a milestone and stops
where a person's thumb is owed anyway, so the stop costs nothing extra.

`blockers only` IS FOR AN UNATTENDED RUN, and it is the dangerous one in the
same way ideation is dangerous on the autonomy dial: nothing brings the person
back until the machine cannot continue. It is the setting an overnight run
wants and cannot have today.

## The press grants permission and never advances

req-controls-never-advance-walk STANDS UNCHANGED. Under `state end` the engine
HOLDS a transition and the person's press stops it refusing. The agent's next
pull is still what moves the walk.

Nothing the person presses moves a state. It only stops the engine saying no.
