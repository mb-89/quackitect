## detail

TakeBackWhatWasLookedAt in src/engine/investigate.go deletes the walker's look at line 194, inside the lock, before it has decided anything. Five guards follow, at 197, 201, 204, 209 and 218, and each returns nil in silence. So the look is spent whether or not the hold moved. pull.go:152 then finds the same quiet hold and :153 writes the look straight back. The walker gets the same notice word for word and is told nothing about which guard refused. The alarm cannot be cleared and the walker cannot learn why. The look must be spent only on the path that actually releases the hold. A refusal must name the guard that refused in the answer the walker gets.

## proposed action

Read the look under the lock without deleting it. Decide against the five guards, returning a named reason for each refusal. Delete the look only on the path that saves the token with the hold cleared. Carry the reason back through pull.go so the walker sees it. Write the tests first and watch them go red.

## done when

- the look survives every one of the five refusing paths, and is spent only when the hold is released
- a refused take-back names which guard refused, in text the walker receives
- a walker pulling again on a hold whose holder is genuinely gone still gets it released, once
- a test drives each refusing guard and asserts the look is still recorded afterwards
