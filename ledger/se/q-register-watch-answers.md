## The ported question

answer paths are ntfy/brief now

## v1 ruling (NOT ported — context only)

A register answer records over the WATCH SERVER onto the existing ask path. In --watch mode, the local server accepts the questionnaire answer and dispatches the same validated, actor-and-channel-stamped apply the i15 lane runs. The static render degrades to emitting the exact console command per red row. Datum: phone-only ntfy round-trip (B3). It loses on the owner law that the desk must never go phone-only while live, and on latency. The killer-guard holds on BOTH lanes: a killer row renders no questionnaire, only the pager pointer. Reverse-sensitivity: if the M5 spike shows the watch server cannot re-enter the engine safely while a build swaps binaries, fall back to command emission everywhere. The tripwire is a wedged binary swap during an answer.
