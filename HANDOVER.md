# The retro

Four things surprise me, and one dead end costs the most time.

## The nobody list grows

A cloud box runs `git config user.name` as `Claude`, and this tree carries the
word `claude` in a path, a folder and a dozen notes. So `NothingPrivateTravels`
reads the whole tree red on any cloud box.

`NOBODY` in `private.js` holds the names carrying no person, and the agent
names sit beside the four nobody users. A name matching on a word boundary is
the other half: a two-letter handle stands out of the middle of `combine`.

## A dead end, Vale exceptions

`existence` with a `tokens` list and an `exceptions` list looks like the whole
shapes rule in ten lines. Vale 3.20 reads the `exceptions` list and applies
none of it, so `/home/user` refuses beside `/home/somebody`.

A `script` rule answers instead, and it answers better: the line number comes
out right, and the nobody users compare as whole words.

## A script reads any scope

`GuidanceCap` and the shape rules all take `scope: raw`, so a script rule looks
like a whole-file rule. A script rule under the default scope works, and Vale
then hands it the prose with every code block gone.

The offsets it answers land on line 1 there, whatever line carries the match.
So `raw` wins anyway, and the rule skips the code blocks itself.

## A capture group matching nothing

A tengo script calling `text.re_find` with a group matching zero times dies
with `slice bounds out of range`. The group answers a begin of minus one, and
Vale slices on it.

Every group in a shape stands non-capturing now. A rule file breaking this way
says the file and the line, and the message points at line 1 of the rule.

## The token reads a dot

v3 counts a slash, an at sign and a backslash as separators. The brief adds a
dot between letters, which pulls `example.com` and `level0.js` in, and a
version number with it. Nothing in this tree trips on that yet.
