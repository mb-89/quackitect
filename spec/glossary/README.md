# glossary - one note per term

Each file is ONE term. The frontmatter carries:

- term: the canonical name (use it, always the same spelling)
- long: the first-use long form (rendered on a term's first linked use per chapter)
- class: domain or meta, PER VEHICLE (in quackitect's own book the method terms ARE domain)

The body is the definition, in the audience register, provenance-marked like all prose.
Usage in content is a LINK to the term note - never trusted plain text.
The book renders a used-terms-only glossary chapter from these notes; the meta-quarantine
lint reads the class field. (adr-glossary-discipline)
