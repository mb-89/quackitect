# Scope

Every paragraph the agent writes meets one schema, in a file and in the chat
alike. The schema is a whitelist: it names what a paragraph can hold, and a
door refuses the rest. The schema, its projection into Vale, the doors that
read it and the loop that grows it stand built. For details, see
[[spec/design_output/projection#the-second-target]] and
[[spec/design_output/vocabulary]].

The measurement behind the build reads a window of answers. Three in four
carry a finding under the rules the tree holds at that time. The bound sessions
and the unbound sessions score within noise of each other. So the standing
guidance moves the chat by nothing a linter sees, and the doors move files by
everything.

These pieces the schema declares reach no code:

| the piece | where it stands |
|---|---|
| the list row, a sentence naming three or more parallel things in a row | `shape.listWhen` stands in the schema, and no projected rule reads it |
| the count that finds a rule refusing one phrase too often | `misreads` stands in the schema, and no code reads it |

# What stands open

| the question | what hangs on it |
|---|---|
| whether `.vale.ini` becomes a projection target | a register then lives in the schema alone, and one file fewer is hand-written |
| whether the list row lands as a projected rule | a sentence of parallel things reaches a door, or stays a guidance rule alone |
| whether the `misreads` count lands | a rule that misreads meets a count, or a person catches each misread by hand |
| a strict register with the OpenSTE words alone | whether a procedure or an error message here ever wants it |
