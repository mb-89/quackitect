## detail

The unbind tooltip in `spec/config/parameters.json` reads: take the queue off, no token on a write, no token on a command, nobody made to spawn.

Two of those four are false. `src/engine/rungsnametokens_test.go` holds a table where a write naming no token is refused at bound and at unbound, and allowed only at god. The comment beside it says Bash carries no way to name a token, so the queue being off is no licence to run unnamed commands.

What unbind does is in `src/engine/pull.go` line 407: the queue hands out nothing, and naming a token still takes it up.

Measured in September 2026. The owner set the rung twice expecting the token requirement to lift. It never lifts.
