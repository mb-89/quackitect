## detail

Three rules need judgement and no pattern holds them.
A sentence carries information the reader cannot recover.
A paragraph is a list, a table or a diagram.
A sentence is a second copy of one that stands elsewhere.

`$.model.classify(text, labels, options)` answers one label for one text.
It runs on the session's own client and on the engine's small fast model, and it answers `undefined` where the model named no label.

The owner rules that the judge refuses, and accepts that it will sometimes refuse good prose.

## approach

The judge runs in the same `tool.call` hook, after the patterns pass.
The third rule needs no model, because a sentence hash answers it.

A refusal carries one row for each span it refuses: the span, the verdict, and the sentence to write instead.
Every refused span carries the replacement, because the owner asks that a block say how to do it better.

`undefined` from the classifier passes the write, which matches how the engine treats a checker that cannot run.
Every verdict goes to `$.store`, so the disagreement rate is measurable before a retro exists.

## done when

- a paragraph of recoverable sentences is refused and the refusal names each span, decided by driving one write under `claude --plugin-dir`
- each refused span carries the sentence to write instead, decided by reading that refusal
- a paragraph that carries information is written, decided by the same drive
- a classifier answering no label writes the text, decided by a drive with the model unreachable
- every verdict is kept, decided by reading `$.store` after a hundred writes
