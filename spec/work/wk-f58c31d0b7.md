## detail

Voice rule 2 allows six sentences to a paragraph.
`voice.Check` counts words in a sentence and never counts sentences in a paragraph.

`maxSentences` exists in the schema layer, read at `src/engine/schema.go` line 602.
It counts a whole section, and one section in the tree declares it: guidance `Motivation`, at ten.
So the paragraph rule has machinery near it and no reader.

370 markdown paragraphs of 5427 run past six today, and the worst runs to 28.

## done when

- the style folder carries the limit as an `occurrence` rule, decided by reading it
- `se lint` refuses a paragraph over the limit and names the count, decided by a fixture with a seven-sentence paragraph
- a six-sentence paragraph passes, decided by the same test
- a table and a list are not paragraphs, decided by the same test with one of each
