## detail

`isProse` in `src/engine/hook.go` line 1386 answers true for `.md`, `.markdown` and `.txt`.
Every Go, TypeScript and mjs file is outside the voice check.

A comment is prose and a person reads it.
The tree holds 19528 comment lines in Go and 3107 in mjs.
No check reads one of them.
The engine's own messages to a person are string literals in those files, so they go unchecked too.

`voice.Check` skips fenced code already, and a source file needs the mirror of that: check the comments, skip the code.
