## detail

17 help strings in `spec/config/parameters.json` run to 516 words.
The median is 25 words and the longest is 114.

Each opens by saying what the control sets and then adds a pair of halves.
`Short frees work quickly when a machine never comes back. Long stops two machines racing for it.`
`A helper that returns what it read has saved you nothing. Higher asks for a shorter answer.`

The panel already draws the unit beside the box, so the tooltip carries no unit.
A tooltip says what the control sets, in one sentence.
