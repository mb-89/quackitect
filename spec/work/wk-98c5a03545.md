## detail

src/engine/hook.go line 1216 guards the write-token rule with binding.At != God. That comparison can never be false.

The god check at line 838 is in the same function, decidePreToolUse, and it returns. So line 1216 is unreachable when the rung is god, and the guard beside it reads as though god were still being weighed there.

A reader working out what god does reads that line and concludes the write rule is the one god-specific carve-out. It is not. God drops every guard below line 838, and this is one of them.

Found while reading the rung for the owner, in September 2026, after a wrong answer built on exactly this kind of misreading.

## proposed action

Delete the && binding.At != God from line 1216, and say in its comment that god never reaches here because line 838 returned.

Do not delete the comment about god above it. The reason the rule exists is worth keeping; only the comparison is dead.
