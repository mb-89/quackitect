## detail

Voice rule 8 asks the writer to say what is.
Nothing checks it, and the tree holds 3679 constructions that say what is not.

Measured over 813666 words, excluding the `doc` mirror:

| phrase | count |
|---|---|
| `rather than` | 1215 |
| `never` | 1114 |
| `and not` | 643 |
| `is not a` | 336 |
| `X, not Y` | 308 |
| `instead of` | 63 |

Each is a line pattern, so each belongs beside the four already in `spec/config/voice-rules.json`.
The owner names this the worst tic on the surface.
The shape is a first half that says the thing and a second half that says the other thing.

## done when

- `spec/config/voice-rules.json` carries a rule for each of the six patterns, decided by reading the file
- each rule says what to write instead, decided by reading its `says` field
- a write carrying `rather than` is refused and the refusal names the phrase, decided by a Go test over `voice.Check`
- the count over the tree falls, decided by running the counter in the evidence before and after
