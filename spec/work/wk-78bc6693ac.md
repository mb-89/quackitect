## detail

`go test .` under `src/engine` fails 243 times on a fresh clone at the branch tip.

Measured in September 2026. The count is the same before and after the changes on this branch, so nothing here caused it.

Two causes carry nearly all of it.

201 say `open ../../src/processes: no such file or directory`. `src/engine/fixture_test.go` line 870 joins `..`, `..`, `src` and the folder name. The specification left `src` for `spec` in commit 7a85c71, and this line stayed.

32 say the engine was built without the `sqlite_fts5` tag, so the index cannot be made. That needs the environment the installer pins in `cgo.env`.

Five more read `../../src/config`. `SpecAt` and `DeclaredAt` answer this at run time, so the engine is not broken. The tests reach around them.

## approach

The reads that name the real tree take `SpecAt` and `DeclaredAt`, which prefer `spec` and fall back to `src`. That is one line in `fixture_test.go` and three more in `applyvoice_test.go`, `standard_test.go` and `fixture_test.go` again.

A fixture that writes into `root/src/...` is left alone, because the readers fall back and a rewrite there risks assertions this token does not own.

The build-tag half is separate. A test needing the index says so and skips where the tag is absent, or the battery builds through the installer. Split that out if it grows.

The count before and after goes on this token, from `go test .` under `src/engine`.
