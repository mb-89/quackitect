## detail

The installer derives the method root as two folders above itself.
It moved from `util/setup` to `src/scripts/setup`, which is three folders deep.
The derivation stayed at two, so the root comes out as `<root>/src`.

The install then fails, reading `<root>/src/src/scripts/setup/manifest.json`.

Two places hold the same derivation.
`src/scripts/setup/install.sh` line 12 joins `$here/../..`.
`src/scripts/setup/main.go` line 83 joins `here`, `..`, `..`.

A cloud box clones with nothing built, so the engine never comes up there.
A session on such a box runs with every guard off and no record.
This is the first token in the group because every other one needs an engine.

## done when

- `src/scripts/setup/install.sh` derives the root three folders above itself, decided by reading line 12
- `src/scripts/setup/main.go` does the same, decided by reading line 83
- a clone with nothing built installs, decided by `./RUNME.sh` from the root, where `.bin/se` exists afterwards
- the diagnosis names no `src/src` path, decided by `node src/cage/diagnose.mjs` and reading the lane log it quotes
