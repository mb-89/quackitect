## detail

TestNoExportedFunctionHereIsUncalled counts a test as a caller, so the class it was written for walks past it.

Archived.Where was the case. It stated the precedence among an archive row's three objects, readArchived stated the same order again, and the only reader of the method was archive_test.go. wk-e0d462f854 took the method out and taught the check to read methods, and the check still would not have named it, because a test called it.

The check's own words are that an exported name nothing calls and no test drives is dead or a claim. A name only a test drives is the third case, and it is the one that hides a claim. The test proves the name works, not that anything wants it.

MEASURED, on 54dacf1d, with the check reading methods as it now does. A caller that is only a test counts: 293 names declared and 4 named by nothing. Three of those four are MarshalJSON, UnmarshalJSON and Unwrap, which the standard library reaches through an interface. A test does not count: 19, the same four and fifteen more, among them Arrived, ParseFront, SetFilter, SetGroup, SetSort, TheOnlyCopy, TheRungBelow and Verbs.

So the stricter rule is fifteen judgements, not one line.

## proposed action

Read the fifteen. Each is dead, or a claim nothing wants yet, or reached from outside the package in a way the search cannot see. The first two come out, and the third goes in the exclusion list with its reason beside it.

Then calledSomewhere passes over a file whose name ends _test.go, and the check's own comment says a test is not a caller.

## done when

- calledSomewhere counts no caller in a _test.go file: plant a name called only from a test and watch the check name it
- the check is green with the fifteen either gone or excused: se test --propose TestNoExportedFunctionHereIsUncalled
- no exclusion is added without a reason a reader can disagree with: read the reached map in src/engine/lesson_test.go
