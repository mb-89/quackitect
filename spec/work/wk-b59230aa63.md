## detail

The line that returns work says what it did and not why it believed it.

`work held by agents that are gone went back to the queue` carries the tokens it
released and nothing about the judgement behind them. A reader who thinks a hand
was still working has no way to check: the sentence is the same whether the
holder ended an hour ago or three seconds ago, and whether it was judged gone by
a missing heartbeat, a closed session or a name that never registered.

WHAT THIS TOKEN IS NOT. It does not say the sweep is wrong. Returning work a
dead hand is holding is what `goneputsdown.go` is for, and its comment names the
nine tokens that sat reserved before it existed. An earlier draft of this token
claimed the sweep was taking work from live agents and that this stalled a box.
The record does not support that: of four sweeps on 2026-09-08, three were
followed by the agent acting again within five minutes.

What remains is that a decision with a consequence is unreadable, so the next
person to suspect it has to do what this one did, which is guess.

## approach

The line carries the reason `HasGone` gave, per holder: what was asked and what
answered. One field, on the record that already exists.

Nothing about the decision changes. If the reason later turns out to be wrong in
some case, the line is what shows it, and that is a different token written
against evidence rather than against a hunch.

## done when

- the line names, per token released, why its holder was judged gone: a Go test that plants a holder in each way HasGone can answer and reads the sentence back
- a reader can tell a hold released three seconds after a start from one released after an hour: both cases are in the test and their sentences differ
- nothing else about the sweep changes: `sh src\scripts\checks\battery.sh` is green and no existing sweep test is edited
