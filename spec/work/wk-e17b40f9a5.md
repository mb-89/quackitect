## detail

4627 paragraphs in 635 files open with a shouted sentence and then explain for four more.
`src/engine/hook.go` holds 116 of them and `src/engine/pull.go` holds 110.

No rule names the shape and every file demonstrates it.
An agent reads the tree before it writes, so the tree teaches the pattern faster than a rule forbids it.

The shape is a line pattern: ten or more characters of capitals, ending on a full stop or a comma.
It goes in `spec/config/voice-rules.json` beside the others.

## done when

- `spec/config/voice-rules.json` carries the rule, decided by reading the file
- a write opening a paragraph in capitals is refused, decided by a Go test over `voice.Check` with one such line
- an acronym inside a sentence passes, decided by the same test with a line holding `SQLite` and `JSON`
- the count over the tree falls, decided by running the counter in the evidence before and after
