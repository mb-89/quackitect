## detail

util/checks holds standing scans that walk the tree. A sweep finds a defect after it is in, on a run somebody has to remember to make, and it gets slower as the tree grows. Several cannot fail at all. One excused any call site carrying a comment. One was dead on the box it protects. One resolved the icons itself and then asserted the panel echoed it. Two match a doc/work path that no longer exists.

## proposed action

Every check becomes a refusal at the engine door that decides it, a Go test that plants its case in a fixture, or is dismissed. util/checks empties, and util goes with it.

## done when

- The checks folder holds no script file
- Every guard added carries a planted case that is refused and a clean case that is not, and se test answers ok on them
- The battery names no check that is gone
- A cloud clone runs everything the battery runs
