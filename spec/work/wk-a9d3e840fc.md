## detail

util was the folder anything landed in that had nowhere else to go. It came to hold the installer, the cage, the checks, five declarations, the push scripts and the views, and its name said nothing about any of them. Worse, a script left there became a battery gate: a-merge-reverts-nothing was a forensic scan somebody wrote once, and it ran on every battery and was 92 per cent of a 1438 second run.

The owner's ruling: util goes. Everything written or run is source. Everything specified is spec. An improvised script goes under .se and is mined for tests later.

MEASURED while moving: a path built by joining segments survives every grep for the literal. wk-345a943f66 named this hazard before any of it, and it was still missed four times in one afternoon. A test joining the segments with the name in a variable. Fixtures that made a util folder and wrote into src/config. Two shell scripts the sweep did not search because it listed file types. And .se/runme.json, a data record carrying the installer path, which no code grep reaches at all.

## approach

One folder at a time, landed on its own, so a break is one commit to find.

Before each move, replace the segmented joins with one function that answers where the thing lives: viewFolders, DeclaredAt, theLandDoor, TrackedDir. Both places are answered while trees carry the old one, new first, so a tree that has moved is never read out of the old folder.

Then move, fix every reader by searching for the string across every file type rather than guessing which languages mention it, build all four modules, run the tests the move touches, and land.

The checks are the long part and are not a move. Each becomes a test with a named input, a guard at the moment the class can be refused, or is dismissed. Test the class, never the specifics.
