## detail

`se format` reaches Go, at `src/engine/format.go` line 117.
wk-bb6d003644 carries the work of reaching TypeScript and shell.

The owner rules that prose is formatted before it is linted, and that a fix a program can make needs no agent.

Several voice rules are fixes a program makes:

| rule | fix |
|---|---|
| a paragraph opens plainly | sentence-case the shouted lead |
| write both words | expand the contraction |
| write it out | expand the Latin abbreviation |
| end lines on sentence ends | one sentence to a line |
| a described field takes no comment | drop the comment line |

## approach

`se format` gains a prose row beside its language rows.
The row applies the `edit` action each Vale rule carries, so one rule holds the check and its fix.

Each fix is a rewrite that keeps the meaning.
A rule the program cannot fix is left for lint, and format says nothing about it.

Fenced code is left alone, the way `voice.Check` already leaves it.
A rule with no `edit` action is left for lint, and format says nothing about it.

## done when

- `se format` sentence-cases a shouted lead, decided by running it over a fixture and reading the file after
- it expands a contraction and a Latin abbreviation, decided by the same run
- it puts one sentence on one line in a paragraph, decided by the same run
- it leaves fenced code untouched, decided by the same run with a code block in the fixture
- a second run changes nothing, decided by running it twice and comparing the file
