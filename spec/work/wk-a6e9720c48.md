## detail

Voice rule 11 calls a repetition a defect.
681 distinct sentences appear in two or more files, over 5115 occurrences.

The largest source is the token template.
`every done when line is decidable and names the command where one decides it` stands in 147 files.
`write one test, watch it go red, make the change, watch it go green` stands in 168.

A repeated sentence needs no model to find.
Normalise the sentence, hash it, and ask the index whether another file holds it.

## approach

The index already holds the tree, so the question is a query.
A sentence is normalised by lowering it, dropping links and code spans, and joining whitespace.
Sentences under eight words are ignored, because a short line repeats for good reasons.

The check reports the sentence, the file it is written in, and the files that already hold it.
A write introducing a new duplicate is refused, and the refusal names the file that has it first.
The 5115 already in the tree come out with the template change, which is its own token.

## done when

- a check names every sentence of eight words or more standing in two or more files, decided by running it over the tip
- it reports the first file and the later ones for each, decided by reading its output
- a write adding a sentence another file already holds is refused, decided by a Go test over a two-file fixture
- a sentence under eight words is ignored, decided by the same test
- it is named in the method where the battery reads its checks, decided by `se test --propose checks-live-in-the-method`
