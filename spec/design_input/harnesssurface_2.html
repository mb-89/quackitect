Private, dated 2026-09-08, revised the same evening. What the survey turned up that no token carries yet, and the drawings for the one package that came out of it. The transport is ruled and the bucket is eleven tokens, both since the first draft.

What this is not. It is not the specification for level zero as a module. That is spec/design_input/level-zero-is-a-module.md, it travels, and the tokens reference it. Everything about that package — the measurements, the argument, the costs, the order, the transport ruling — lives there and only there.

Two documents saying one thing drift after the first ruling, and this pair already did. So this one keeps the drawings and the survey findings that have no home, and nothing else.

2The $ surface

Reference, from the declarations /plugin-types writes. Every noun is also a hookable event, so one plugin can intercept another's. The design input names only the ones the package uses.

Two measured facts that bite: a registered tool's result must be a string or an array, and an object is refused with invalid_union. And $.session.surface() answers null at session.start under the editor, so the surface is not readable at that event and $.ui.toast may not draw there.

3Hook events worth taking, with no token

The cage registers 14 events across two files. These four are not among them. Two of them, PostToolBatch and UserPromptExpansion, are now named in an allowlist names events — as events that can block, which is not the same as taking them for what they give. Nothing takes any of the four yet. They stay worth taking whether they end up as settings entries or as module hooks.

EventWhy
InstructionsLoadedFires when a CLAUDE.md or .claude/rules/*.md reaches context, with a matcher on compact. The standing layer is projected and there is no proof it arrived. This is that proof. Moot if prompt.section replaces the projection.
PostToolBatchOnce per model call, after a parallel batch resolves. Per-turn quantities are counted here and nowhere else, at a fraction of the cost of once per call. It also blocks, which makes it the cheapest place to hold a turn that owes a token — Stop fires after the model has already written its answer.
UserPromptExpansionThe only door in front of the ~35 se-ctrl-* commands. A control the state forbids can be refused by name before it becomes a prompt.
PreModelSwitch / PostModelSwitchPostModelSwitch also fires for switches Claude Code makes on its own, such as a fallback model — the ones nobody would otherwise see. A model swap inside a record changes what its evidence is worth.

Two numbers that constrain whatever is registered: UserPromptSubmit has a 30 s timeout, not 600; and all SessionEnd hooks share 1.5 s, so a daemon shutdown slower than that does not finish.

4Workflows

Narrower than it first looked. The script has no filesystem and no shell, so nothing is automated away that the pull does not already do. It buys two things:

  • Fan-out over many items, with intermediate results in script variables rather than in context. Up to 16 concurrent, 4096 items per call, 1000 agents per run.
  • A schema the model cannot dodge. One required field per criterion makes an unanswered criterion a schema failure rather than a judgement call.

Neither pays for a single token walked by a single agent. Not a layer, and not the process. Where it pays in this tree: one agent per spec/rationale/*.md; one agent per hunk of git diff began..ended for the verdict activity; a sweep like the 176-merge one. Level 3, allowed by one Workflow(<name>) rule.

Two constraints if it is ever used: a run cannot wait for a person, so a human gate ends it; and Date.now(), Math.random() and no-argument new Date() throw inside the script, which matches the-token-carries-no-time.

5What v3 has that v4 does not

v4's cage is a generation ahead of v3's, which registers five command hooks and nothing that can refuse but Stop. What v3 has is the enforcement. Only item 1 became a token.

#v3The v4 gap
1Proof of reading. Three fill-in-the-blank probes at ~30/60/92 % of a document, containment not equality, punctuation and case stripped, wrong probes named and right ones banked, credit keyed to the content hash so an edit re-owes it.Tokenised: reading is evidenced.
2assertCanSupply. Refuses at compile time when a state's evidence form demands an artifact its legal_tools cannot produce.No equivalent. A criterion naming a command the token's agent may not run fails at run time, once, per token.

5Pin, demands ledger, drift. seeded.json stores the compiled demands per step, so when the matrix moves the engine computes which signed steps reopened. Escalation-only re-pin.began/ended says the tree moved. It does not say which criteria moved.
6The privacy one-door. A raw note never enters version control; the mint re-authors it, and a statement sharing a six-word run with its source is refused.The .se/knowledge-base split has the same shape and no guard. The six-word-run check is a cheap mechanical test for "the digest is not the source".
7se_test as a question. The agent asks "did X break Y"; the engine decides scope and hands back a handle; polling is refused. Measured: 494 calls, 66 verdicts, 428 polls.Check whether se test --on refuses polling or merely discourages it.

11doors.md with no off-switch. Every module crossing a boundary listed with a written reason; a bullet with no reason refuses. Ships no --ignore.one-core-many-satellites rule 4, already built once. Start its token from this.

One v3 measurement that argues against a v4 ruling

v3's spawn ceiling defaults to 0, with the reason recorded: "Delegated WRITING was measured over a full day and lost: three hands each spent about fifteen minutes rebuilding context the guide already held." It also measured narration crosstalk — five readers pushed the parent's stall counter from 2 to 9 while the parent made no update of its own.

v4's cast gives the scribe the mechanical reading and writing. That is the delegation v3 measured and lost; its reviewer and researcher stand outside the ceiling precisely because they are not the ones writing. Before building the scribe, read that measurement and say why v4 is different. A 1:10 compression ratio is a hypothesis about the same trade, and there is a day of data on it.
