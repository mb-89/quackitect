# Scope

The owner asks that the private folder say what each file is for. Three kinds
stand there under one name today, and a reader tells them apart by knowing. The
retro reads one of the three, and it walks past the other two.

The asks, one to a line:

- Split the private folder into the retro's files, the runtime's files, and the
  rest.
- Let the retro read the rest, and leave it the first two.
- Walk the private folder in the index, and leave the runtime half outside the
  walk.

# The three kinds

| kind | what stands there | what the retro does |
|---|---|---|
| retro | what a retro writes, and what it reads back | reads it as its own |
| runtime | state a box holds while it works, which dies with the box | walks past it |
| the rest | the notes, the handover, the private tickets | reads it |

# The index walks it

The index names the folders standing outside its walk, and the private folder is
one of them. So a question over a private note answers off the disk, or answers
nothing. Every other note in the tree answers off the rows.

The owner rules that wrong. The runtime half stays outside the walk, because its
files move under every question and no reader asks one of them. The rest joins
the walk.
