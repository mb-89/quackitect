## decided

An actor is a session rather than a word.
The register links a harness name to the names it has pulled with, and the gate asks over all of them.
A name a different live session holds is refused, and the refusal names that session.

## why

A reviewer holds its token under the name it pulls with, and the guard is handed the name the harness uses.
The two never matched.
Every subagent reviewer was refused every command including ls.
It could not deliver a rejection through the one door left to it, and closed a token it had not read.

The link is the pull itself.
The guard sees a command go past before it runs, and that command carries the name.
A harness name that has pulled as nobody is linked to nobody, and is refused exactly as before.

The lane is the other door.
Its tools carry the actor as a field rather than in a command, so a worker that never typed a shell pull was never linked.
Five workers held five tokens under names the register had never heard.
The panel drew them waiting with nothing in hand while the header showed each one working.

Two sessions then ran over one tree and both said main.
Naming a token puts back everything that actor holds, so each time one named a token the other's left its hands.
The register keys each session by the id the harness sends, and the guard sees that id on every event.
A live session is one of this run, because a session killed without an end keeps its name for ever.
The pick is the lowest id, because a map hands its keys back in nobody's order.

## costs

The link is only as good as the pulls the guard has seen, so a session that never pulls is two names to the gate.
A helper's name is its own and nothing links it, which is right until a helper wants work of its own.
The refusal leans on the register being honest about who is live.

## revisit when

- the harness sends its session id on every call, so nothing has to be linked by watching pulls
- a helper needs to hold work of its own, so its name stops being nobody's
- two live sessions under one name become legal, so the refusal has nothing left to protect
