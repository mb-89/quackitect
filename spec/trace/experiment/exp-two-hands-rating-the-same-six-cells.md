## The run

TWO READERS WITH NO SHARED CONTEXT were given the same five-rung ladder, the same
six rows, and told to rate the `major` column of each from the row's own text.
Neither saw the other's answer. Both were told to ignore any rating already on a
row; both reported that none of the six carried one.

## The result

| row | first hand | second hand |
| --- | --- | --- |
| M1_40A scope-non-goals | C3 | C3 |
| M2_90 gate-inputs | C1 | C1 |
| M4_10B partition-functions | C1 | C1 |
| M5_20 reverse-sensitivity | C2 | C2 |
| M6_10 rank-unknowns | C2 | C2 |
| M7_40 build-steps | C0 | C2 |

FIVE OF SIX IDENTICAL. On a five-rung ladder, chance agreement is one in five.

AND THE FIVE THAT AGREED AGREED ON THE SAME EVIDENCE. Both quoted "The engine
proposes; you confirm or move" for partition-functions, both quoted "the judgment
the counts cannot make" for gate-inputs, both quoted "THE PICK METHOD, three
filters in order" for rank-unknowns. THE LADDER IS NOT ONLY REPRODUCING A NUMBER,
it is reproducing the sentence the number rests on.

## The one disagreement, and both hands predicted it

M7_40 build-steps: C0 against C2, two rungs apart and the widest gap available in
the sample.

BOTH READERS NAMED THIS ROW, UNPROMPTED, AS THEIR LEAST-SURE RATING. Both gave
the same reason in their own words: whether the row's rung covers the DISPATCH it
performs or the AUTHORING inside the chunks it delegates to.

THE ROW SAYS BOTH THINGS. Its major note reads "the seeded chunk machine runs,
parallel where independent, every fill recorded", and the row is described as
"the placeholder the seeded chunk machine fills".

SO THE DISAGREEMENT IS NOT NOISE AND IT IS NOT A HARD ROW. It is a row that has
no single difficulty to declare, because the work it names happens somewhere
else.

## What this settles and what it does not

IT SETTLES THAT THE DECLARED ARCHITECTURE'S BET IS SOUND FOR ORDINARY ROWS. 308
figures typed by hand is a large surface, and on rows that are one act two
independent hands land on the same rung from the same sentence.

IT DOES NOT SETTLE THE RISK IT PROBES. `raid-risk-a-hand-declared-rung-drifts-upward-and-nothing-ever-says-so`
is about DRIFT OVER TIME — a number typed once and never revisited while the work
under it changes. Two readers in one session measure agreement, not drift. THE
RISK IS NARROWED AND STAYS OPEN.

## The class this found, which was not what it was looking for

A PLACEHOLDER ROW THAT SEEDS A SUB-MACHINE HAS NO COMPLEXITY OF ITS OWN.
M7_40 build-steps is one. So are M4_25 run-candidates and M6_15 run-spikes, which
this record has already walked as placeholders that a drawn machine fills.

RATING SUCH A ROW FORCES A CHOICE THE ROW DOES NOT MAKE, and two careful readers
made it differently. That is a rating that will be wrong for one of two readers
however carefully it is typed.

THE PROMOTION IS THEREFORE NOT "RATE MORE CAREFULLY". It is that the loader
should refuse a complexity on a placeholder row, or the rating should attach to
the states the sub-machine seeds — where the work actually is.
