## Setup

The probe ran itself, five times, in production: every engine reload this
session replaced the process and rebooted the walk. Each resume was
through the real stack — boot reading, position recomputed from the
record's files, the signed chain fast-forwarded.

## Result

2026-08-10. Five restarts, five clean resumes. The bound record re-entry
walked 28 signed states from files alone, worst 15.2 seconds. One
context compaction in the same session resumed the same way. The cost
each time: the in-flight reading credit, re-owed by design.

The limit is named in `faked`: a sanctioned restart is not an OS kill
mid-write. The write path is compare-and-swap through the lane, which
bounds what a mid-write kill can corrupt to one file — untested claim,
and it rides the deferred POSIX and host-swap probes.
