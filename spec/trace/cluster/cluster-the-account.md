## Rationale

This is where the tree drains. Keeping the record consumes from six other
functions and showing consumes from six, and three of the flows run straight
from the first to the second: the call log, the trace graph and the reference
corpus.

TEACHING THE NEWCOMER JOINS THEM AND IT IS THE ARGUABLE ONE. Its own
rationale insists it is not showing, and that is true of the act. It is still
the same material: an explanation derived from the live system and put in
front of a person who cannot ask anybody.

Nothing in this cluster decides anything. Everything in it derives.
