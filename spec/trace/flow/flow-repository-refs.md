## It crosses OUT, and nothing here consumes it

WHAT RESOLVES THE REFS HANDS THEM TO GIT, not to another function of ours. The
local branches stand in the clone from that moment, and every later `ref:` read
goes through the file lane to git rather than through this flow.

WITHOUT THE FIELD the closure check read it as work nobody wanted. Same mint,
same iteration, same reason as its neighbour.
