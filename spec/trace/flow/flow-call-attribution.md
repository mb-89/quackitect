TWO COORDINATES, ONE FLOW, and that is deliberate. Either alone answers nothing: a model with no state says which of fifty-three it walked, and a state with no model says who walked it.

ONE HALF IS AN OBSERVATION AND THE OTHER IS A CLAIM. The state is known where the call is served. The model can only be self-reported today, and the flow carries that mark rather than hiding it.
