## Scope

The absence of a second door. Every writer of the option kind, read rather than
exercised.

## Why inspection and not test

A TEST PROVES A PATH BEHAVES. ONLY READING PROVES THERE IS ONE PATH. No test
can assert that a shortcut does not exist somewhere else in the tree, because a
test can only exercise the doors it knows about — and the whole risk is a door
nobody remembered.

THIS IS THE CHEAPEST METHOD THAT WOULD CATCH THE ROW FAILING, which is the rule
for picking one.

## Checklist

- Every call site that writes a file under the pool's directory is found, by
  searching for the writer rather than by memory.
- Each one is reached only through the drain.
- No call site takes a flag, a role or an actor that changes which demands
  apply.
- The lane's own tool surface offers no verb that writes an option directly.
- The refusals the mint raises name no actor, so an agent and a person get the
  same text.

## What a failure looks like

A SECOND WRITER READS AS AN EFFICIENCY. The pressure is real and it comes from
a good place: an unattended agent filing mid-walk wants one call, and note-then-
drain is two. Whoever proposes that shortcut will be right about the ergonomics
and wrong about the boundary.
