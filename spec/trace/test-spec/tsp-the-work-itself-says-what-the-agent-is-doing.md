## Scope

THE CLAIM IS THAT SILENCE STOPS LOOKING LIKE STUCK. An agent working quietly
and an agent hung are indistinguishable when the only signal is chat. This asks
whether the work itself now tells them apart.

IT IS A DEMONSTRATION AND NOT A TEST because the pass is a watcher's
understanding, formed while the agent is running and without interrupting it.
Interrupting to check would destroy the thing being measured.

WHAT IS DELIBERATELY OUT. Whether the agent's split of a job was a GOOD split.
This asks only whether the split is readable.

## Approach

THE DESIGN METHOD IS SCENARIO-BASED, and the extreme is a long silent stretch:
the agent is given work that takes several minutes with nothing to say.

THE LEVEL IS ACCEPTANCE. The pass is what the watcher knew without asking.

DEPTH IS ONE PASS over a real piece of work, not a rehearsal. A staged split
would prove the display and not the claim.

## Procedure

FIVE STEPS, and each names what is WATCHED as the pass.

- ONE. Give the agent a piece of work large enough to take several minutes.
  OBSERVED: the piece appears in work with the hand on it, before any result
  exists.
- TWO. Wait through a silent stretch. OBSERVED: the watcher can still say what
  the agent is on, and does so without asking.
- THREE. Let the agent find the piece bigger than it looked. OBSERVED: it opens
  further work rather than widening the first silently, and the parts are
  readable as separate objects.
- FOUR. Read the log while it runs. OBSERVED: each act carries the piece's NAME
  and the hand's own comment, so the trail says what and why rather than that
  something happened.
- FIVE. Let the state complete. OBSERVED: the ephemeral parts are gone and the
  evidence they produced remains.

STEP TWO IS THE ONE THE STORY EXISTS FOR. Steps one, three, four and five
describe good bookkeeping. Only step two tests the sentence the story opens
with: silence looks the same as stuck.

## What this demonstration cannot settle

WHETHER A LONG COMMENT SURVIVES THE DISPLAY. The feed brief is capped, so a
comment past the cap is cut and only the name is certain to arrive. A watcher
reading short comments will not meet that.

AND WHETHER A DEEP SPLIT STAYS READABLE. One piece broken into two or three is
what this procedure produces. A job broken many ways, several levels down, is a
different question about the same surface.
