## Mechanism

TWO READERS WANT DIFFERENT THINGS, and the conflict only exists because both
were assumed to read the same thing. A person wants a file they can open with
no software. The system wants an answer in milliseconds.

SEPARATE THEM IN SPACE. The files stay exactly as they are, and they remain
the truth. Beside them sits an index the system rebuilds when the files move,
and every count, filter and offer is answered from it.

WHAT IT COSTS. A second thing that can disagree with the first, which is the
failure this corpus hunts hardest. It is only safe under the rule the corpus
already holds: the derived answer never beats the files, the index is keyed to
their content, and a disagreement is reported rather than resolved quietly.

WHAT IT BUYS. Fossil's clutter objection and the vault's volume question both
stop being about speed, and become only about how a folder looks.
