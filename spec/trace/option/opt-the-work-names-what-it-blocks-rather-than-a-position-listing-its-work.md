## Mechanism

TODAY THE POSITION OWNS THE LIST. Its form names its fields, and leaving is
checked by walking that list. Reverse it: a piece of work names what it holds
open, and a position is leavable exactly when nothing points at it.

WHAT IT BUYS, and it is more than a restatement. Work placed from elsewhere
needs no cooperation from the destination — it simply names it, and the
destination is held by construction. The round's own demand that placing work
makes the destination owe it stops needing a second act.

IT ALSO MAKES ONE PIECE OF WORK HOLD SEVERAL POSITIONS, which the list shape
cannot express at all. A finding that blocks two states is one thing pointing
twice rather than two copies that can drift.

WHAT IT COSTS. Nothing can be answered by reading one position any more. What
a position owes is a query over everything, so this option only stands with
something that answers that query cheaply.

IT IS THE SAME SHAPE THE TRACE ALREADY USES. A requirement names the use case
it refines; the use case keeps no list. That is this inversion, already
shipped elsewhere in the corpus.
