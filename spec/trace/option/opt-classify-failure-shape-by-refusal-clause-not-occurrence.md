## Mechanism

The contradiction: improving thoroughness (route every non-misuse failure
toward durable work) degrades attention (a register that floods with one
row per occurrence buries the pattern that actually matters).

The IN LEVEL separation dissolves it without a principles-matrix lookup:
count at the level of the SHAPE a failure takes (which clause, which tool,
which remedy), and only the shape's aggregate crosses into iteration
evidence or a RAID entry. An individual occurrence stays in the call log,
already durable there, and is never re-recorded by hand.

WHAT SURVIVES THE TRANSFER. route-a-failure-shape classifying by shape
rather than by call is this option, adopted directly.

WHAT DOES NOT. The separation says nothing about the THRESHOLD at which a
shape counts as repeated — that is a measure this project still owes its
own number for, not something TRIZ hands over.
