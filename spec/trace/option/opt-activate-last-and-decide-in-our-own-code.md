## Mechanism

THE HOST IS TOLD NOTHING ABOUT WHICH FOLDER MATTERS. One activation event is
declared, it fires when the editor has finished starting, and our code runs in
every window on every folder.

WHAT DECIDES A PROJECT IS THEN OURS. The code looks for the machine-state
folder and stops if it is not there.

## This cell exists because a row needs its zero

THE OTHER TWO CELLS ON THIS ROW BOTH COST SOMETHING, and a chart that shows
only the alternatives hides what they are alternatives TO. A candidate that
picks this cell is choosing to change nothing here, which is a real choice and
should be visible as one.

IT WAS ADDED AT build_chart RATHER THAN BY A FINDER. Six finders were looking
for what could be done differently, and none of them proposes the incumbent.
That is the shape of the search rather than an oversight, and it is why a row
can arrive with its zero missing.

## What it costs

THE ENTRY-POINT ROW'S CLOCK HAS NO LEVER. `req-the-desk-is-usable-soon-after-the-folder-opens`
bounds the open, and this event is defined as happening after everything else
the editor does. Nothing here can move it earlier.

THE OWNER'S RULING KEEPS IT LEGAL. Waking everywhere is acceptable provided a
folder with no machine state is identified and then left alone, so this cell
does not fail `req-a-folder-is-driven-only-with-consent`. It competes on timing.

## What it buys

NOTHING NEW TO BUILD, and nothing new to be wrong. It also needs no marker the
host can recognise from outside, which the pattern-matching cell on this row
commits to.
