## Mechanism

TAKE AWAY THE ONE THING EVERY WORK TOKEN HAS — that it must be answered — and
ask what is left. What is left is a visible list of everything a position is
carrying, which is most of the value and none of the friction.

SO BLOCKING BECOMES A PROPERTY rather than the definition. A piece of work
declares whether it holds the position. Most report; a few refuse.

WHAT IT BUYS. The harmless finding stops being an exception the system
carries specially. It is just work that does not block, sitting where anybody
can see it, and the rule that a state may not be left with work outstanding
becomes a rule about the blocking kind.

WHAT IT COSTS, and the register already knows this cost. A non-blocking
work token is one nobody has to do, and the corpus has a standing demand that
a carried finding names an open entry precisely because unheld work rots. This
option is only safe with that demand kept.

WHAT IT ARGUES WITH. The round's exit rule is written as though every piece
of work blocks. Taking this option means restating that rule rather than
quietly narrowing it.
