## Mechanism

TWO POPULATIONS, NOT ONE. The live population is one record's work tokens,
which the probe puts at 320 to 402 files. The dead population is every
record ever closed, which the same figures put at more than twenty-two
thousand.

SO CLOSE THE SECOND ONE. While a record is open its work tokens are files a
person can open, move and count. When the record closes, each settled one is
folded into the evidence it produced and its file goes. The archive keeps
what was learned rather than the bookkeeping that produced it.

WHAT IT BUYS. The folder a person browses never exceeds one record's worth,
and the clutter objection that two shipped trackers raised stops applying at
the scale that made them raise it. The corpus grows by evidence rather than by
work tokens.

WHAT IT COSTS. The history of HOW a record was worked is gone, and only the
result survives. Somebody asking which work tokens were closed as duplicates
in a record from six months ago has no answer.

IT IS THE ROUND'S OWN RULE TAKEN ONE STEP FURTHER. The register already says
a settled piece of work IS the evidence inside a record. This says the file
stops existing once that is true.

## Mechanism — what the probe faked

THE STATE COUNT WAS TAKEN FROM THIS MACHINE and assumed typical of a major.
A patch-sized record has far fewer positions, so 320 is an upper figure for
the biggest vehicle rather than an average.

THE PER-POSITION FIGURE COUNTS EVIDENCE SECTIONS, not work tokens, and the
two are only equal if one marked step becomes exactly one work token. That is
itself an open assumption with its own probe, so this number moves if that one
fails.
