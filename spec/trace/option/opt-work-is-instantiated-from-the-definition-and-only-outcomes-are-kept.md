## Mechanism

THE DEFINITION IS THE ONLY THING STORED. Entering a position reads the method
and computes what it owes, right there. Nothing is written for an work token
that is still open. When one is answered, the answer is written, and the next
computation subtracts it.

WHAT IT BUYS. There is nothing to migrate when a method card is reworded,
because nothing was ever minted from the old wording. The matching problem
that re-entry creates disappears, along with the orphan and the duplicate it
can produce.

WHAT IT COSTS HERE, and it is fatal to two of this round's demands. A piece
of work that exists only while it is being computed cannot be MOVED to
another position, and it cannot carry a mark somebody raised. Both of those
demands are in the register, so this option is only whole if the design also
finds somewhere to put the handful of facts that must outlive the
computation.

IT IS STILL WORTH SCORING. It is the cheapest thing that could possibly work,
and the chart is dishonest without the option that stores nothing.
