## Mechanism

REVERSE THE INITIATIVE. Today the caller asks and the lane answers. Here the
lane says it on every answer, and the caller never has to ask.

TASK UNIFICATION IS THE SAME MOVE FROM THE OTHER SIDE. Every lane answer
already travels to the caller. Giving it a second job costs one more field
rather than one more call.

WHAT RIDES IS SMALL. A count of what is running, and whatever changed since
the caller last heard. Not the whole account, which stays behind the verb that
asks for it.

## Why the transformation is worth having

POLLING EXISTS BECAUSE ASKING IS THE ONLY WAY TO FIND OUT. Remove that and the
reason to poll goes with it.

A CALLER WORKING STEADILY NEVER WAITS AT ALL. It writes a file, patches a
module, fills a form, and somewhere in there an answer tells it the run
finished. The information arrives inside work it was doing anyway.

## What it costs

EVERY ANSWER GROWS. The lane already fights answer size — this project moved
big results to disk and pages them back by reference for exactly that reason.

SO THE RIDER MUST BE TINY, and that is a real constraint rather than a detail.
A rider that carries the whole account reintroduces the problem the reference
mechanism was built to solve.

AND IT IS NOISE WHEN NOTHING IS RUNNING. An answer that says "nothing out of
sight" on every call is a field nobody reads. The honest shape is that the
rider appears only when there is something to say.

## What it does not replace

The verb that asks. A caller that has just started work and wants to know now
still needs a door, and `opt-one-operation-object-serves-every-kind-of-long-work`
is that door.

This rides beside it, and the two answer different questions: what is running,
and did anything change.

## Where the vision already asked for this

The iteration's rough vision says the state should ride ordinary calls too, so
an agent doing other work learns a job finished without asking.

That sentence had no option node behind it until this sweep, which is what the
forced transformation is for: it reaches things somebody wanted and nobody
proposed.
