## Mechanism

An aircraft may dispatch with a named item inoperative, and the entry carries a
letter rather than a date. Category B is three consecutive calendar days,
category C is ten, category D is 120, each excluding the day of discovery.
Category A takes its own period from the entry's own remarks.

The interval starts at a defined moment — when the discrepancy is entered in
the record — rather than when somebody gets round to noticing.

WHAT SURVIVES THE TRANSLATION. The closed set. An author picks a category, not
a number, so an expiry is one choice from four rather than a negotiation. The
categories carry the argument once, in the rule, instead of once per entry.

AND THE DEFINED START. A departure's clock begins when it is written, which is
the only moment the system reliably sees.

WHAT DELIBERATELY DOES NOT TRANSFER. Calendar days. An aircraft flies daily
and a module may sit untouched for months, so a wall-clock interval punishes
quiet code and forgives busy code. The equivalent unit here is releases, or
sweeps, or nothing at all.

NOR DOES THE DEFAULT. In FAA practice an item with no category falls to
category D, the longest. That is silence granting the most generous exception,
which is exactly what
req-absence-from-the-exemption-list-means-not-exempt refuses. Here an
uncategorised departure has to be the shortest, or refused.

WHAT IT COSTS. Somebody must set the categories, and a wrong set is worse than
none because it looks considered.
