## Rationale

A rule with no enumerated set governs whatever somebody remembered to list.
The set has to come from the same source that defines the things, so that a
new export joins the set by existing rather than by being registered.

It stands apart from the judging because the two fail differently. An
enumeration that misses a thing reports a clean sweep over a hole. A judgment
that misreads a thing reports a wrong verdict about a thing it did see.
