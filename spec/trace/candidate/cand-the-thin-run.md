## Why this one

It is the cheapest curve through the box that still measures something honest. Every cell it picks either already exists or was probed in minutes.

## How it works

A person names an iteration. The content subtree is exported at the commit before that iteration started. A binding opens, and while it stands every commit or ref is tested for ancestry against the rewind point. The benchmark history is invisible for the length of the binding. The agent walks, and each absence-shaped measurement runs a positive control beside it. The run fills a report naming the stop point and the state reached, with the three unrecoverable conditions written at bind time.

## What it costs

ONE VERB. `merge-base` is not on `se_git`'s allowlist, so either the list grows or the ancestry answer is derived from `log` or `rev-parse`.

AND THE GUARD IS CHECKED RATHER THAN STRUCTURAL. A checked guard fails open when the check errors, and a guard going quiet looks exactly like a guard passing. The control mitigates that for measurements; it does nothing for the ceiling itself.

## What it leans on

git's ancestry primitive, which was probed and answers exactly. The export, which was probed and took seconds. The person being in the loop, which the owner already ruled. It leans on nothing that has not been run.
