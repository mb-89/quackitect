## What it leans on

THE MEASURED ACCRETION. Two surfaces grew over months with nothing objecting,
and the probe found their widget code shares nothing at all.

THE REFUSAL MACHINERY THIS PROJECT ALREADY HAS. A typed rejection carrying a
remedy is the shape every other guard here takes, so the guard is a new rule
rather than a new mechanism.

THE ASSUMPTION THAT "emits a widget" CAN BE DETECTED. Unprobed, and the whole
candidate rests on it.

## Why this one

IT IS THE ONLY CURVE THAT STOPS THE FAILURE RECURRING. Every other candidate
removes today's second surface. This one also refuses tomorrow's.

THE FAILURE WAS ACCRETION, NOT A DECISION. Nobody chose to build two surfaces;
they grew one reasonable commit at a time over months, and nothing objected
because nothing could.

## How it works

THE COLLAPSE HAPPENS FIRST. The second surface goes, and each of the six
widgets is ported into the surviving view or dropped with a signed reason.

THEN ONE EXPORTED ENTRY POINT OWNS WIDGET EMISSION, and a check refuses any
other module that emits surface markup. The refusal is typed and carries a
remedy, like every other refusal in this system.

## The seams

THE SEAM IS BETWEEN THE ENTRY POINT AND EVERYTHING ELSE, and it is one
import away from being wrong. Any module that reaches past the entry point and
emits markup directly is the failure this candidate exists to stop, so the
seam has to be checkable from outside the code that crosses it.

THE CHECK RUNS WHERE THE OTHER CHECKS RUN. It is a rule in the lint pass, not
a runtime guard, because a second surface is written before it is ever run.

THE ESCAPE HATCH IS PART OF THE SEAM. A fixture, a diagnostic page and a
vendored component all emit markup legitimately, so the rule needs a declared
exemption rather than a silent exception.

## What it costs

THE GUARD NEEDS A DEFINITION OF "emits a widget" precise enough to check, and
nobody has written one. If that cannot be made precise, the guard degrades to
a convention with extra words.

IT ALSO NEEDS A FINDABLE ESCAPE HATCH for fixtures, diagnostics and vendored
components, which are all legitimate markup that is not a second surface.

## What it does not do

IT DOES NOT STOP TWO SURFACES DISAGREEING, because it stops there being two.
That is a weaker guarantee than the repeater's, and it is cheaper.
