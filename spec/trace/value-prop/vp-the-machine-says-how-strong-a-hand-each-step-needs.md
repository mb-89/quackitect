## Success criteria

- EVERY STATE CARRIES A RATING, and the rating was arrived at with evidence
  rather than typed by whoever was passing.
- THE ANSWER IS THE SAME ON EVERY MACHINE. The same milestone names the same
  driver whoever walks it and wherever they walk it.
- THE MACHINE SAYS AND DOES NOT DO. It names the driver; starting a process
  stays outside the lane, with pushing and opening records.
- ASKING FOR MORE IS FREE AND ASKING FOR LESS COSTS A SENTENCE. The judgment
  stays with the agent, and the asymmetry runs the safe way.

## Unlike

[[vp-a-cheaper-model-does-the-mechanical-work]] is the neighbour and the
ancestor, and the difference is who decides. That one asks that the mechanics
cost no capability, so a small model can walk them at all. This one asks that
the MACHINE be the thing that knows which is which, rather than the person
guessing at session start.

BOTH ARE NEEDED AND NEITHER IMPLIES THE OTHER. Mechanics that a cheap model can
walk are worth nothing if nothing ever routes a cheap model to them; and a
machine that routes perfectly is worth nothing if the guidance is only legible
to a strong model.

[[vp-autonomy-range]] is the other axis entirely. It asks how much the agent
decides alone. This asks how capable the agent is. A walk can sit at full
autonomy and still be under-powered for the state in its hand.

## What this is not

IT IS NOT A ROUTER. Nothing here predicts a difficulty per request or learns
from outcomes. The rating is declared in the repository and read live, which
buys reproducibility and gives up fitness — and the giving-up is deliberate and
registered, not overlooked.

IT IS NOT AN ORDER EITHER. The machine recommends; the agent judges. A
recommendation the agent may not refuse would put the sizing decision inside
the very state whose difficulty is in question.
