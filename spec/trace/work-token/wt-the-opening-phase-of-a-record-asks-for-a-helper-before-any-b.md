## Why it stands

The opening phase of a record asks for a helper before any budget for helpers has been agreed, so the request is always turned down. Either the budget is agreed earlier, or the phase that asks moves later.

## When it comes back

ready when a record's helper budget is agreed before the phase that asks for helpers, or that setup step is moved after the gate that agrees it
