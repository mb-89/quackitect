## Why it stands

Re-signing an answer that others rest on knocks those others down every time, whichever way the walk happens to be pointed. One case worked and one did not on the same day, so the guard fires only sometimes. A stale scoring table left standing is the worst outcome: it looks solid, it quotes its sources, and every quote answers a question nobody asks any more.
