## Why it stands

A chart row is currently a whole group of functions, which is far too broad to be one choice, and the rule that a candidate takes exactly one entry per row is stated in five separate places. One round put all thirteen of its ideas into a single row, with six independent questions separating them, so the combinations the chart exists to generate could not be written down at all. The engine keys the chart on that row identity, and nothing tells the step building the rows to divide one that asks several questions at once.

## When it comes back

ready when the partition step or the chart template is next opened — the rule to add is that a row asking more than one independent question is split until each asks one
