## Why it stands

A chart field meant to be drawn accepts typed text, and that text is read by column position into the records behind it. One typed table renamed four design records and removed five more belonging to an earlier iteration, and the step then signed. Three guards are missing and each stands alone. A drawn field should refuse typed input outright. A row that is simply absent should never count as an instruction to delete. A cross-reference naming a record nobody can resolve should refuse rather than be skipped.
