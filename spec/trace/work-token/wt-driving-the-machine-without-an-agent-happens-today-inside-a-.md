## Why it stands

Driving the machine without an agent happens today inside a pane that is scheduled for deletion, and there is nowhere else for it. So the deletion takes the only place that act has. What is owed is a dedicated view for it, plainer than what exists: the person needs to see which step stands, what that step is asking for, and how to give it, without decoding a view built for a different purpose. The form rendered inside the doomed pane is also disliked, and that half stops mattering once the pane goes.
