## Why it stands

Editing a rule page updates the generated copies by itself, and the agent is told what changed rather than asked to trigger it. The lane already sees every write, the start-up check already compares a generated copy against what it came from, and the writer already announces each file whose contents differed before it replaced them. So the only missing piece is the trigger. Today an agent must remember to run it, and forgetting turns into a red check some steps later.
