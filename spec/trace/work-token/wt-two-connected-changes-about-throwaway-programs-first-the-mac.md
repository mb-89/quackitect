## Why it stands

Two connected changes about throwaway programs. First, the machine should test at start-up which outside interpreters this computer actually carries, working from a written list, and say plainly which answered. The wording today asserts a per-platform answer and never checks, so one interpreter sat present and unknown until a stray remark mentioned it. Absence must be a fact told to the agent, never a failure to start. Second, the look-back should hunt out the throwaway programs somebody wrote, and turn the repeated ones into proper tools. A program that varies still counts, gathered by what it does rather than by how it reads. Every command is already kept whole, and nothing reads them for this purpose.
