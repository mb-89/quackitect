## Why it stands

Completed work should exist only in version history, never as folders left where nothing consults them. A rule that already holds implies it: finished work can no longer be entered or acted upon, so its only remaining use is reading, and reading-only material belongs in history. The gain is an unbounded checkout brought back under control, with every sweep, search and listing no longer paying for material nobody can act upon. One thing is owed first: a way to read finished work without restoring it to disk, since occasional reading is the entire reason for keeping it. Something similar may already stand in the pool, so look before opening anything.
