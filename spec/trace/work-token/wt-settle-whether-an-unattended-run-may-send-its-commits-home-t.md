## Why it stands

Settle whether an unattended run may send its commits home. The owner has ruled that it must, because a disposable box is reclaimed and a commit nobody sent is a commit nobody has. The engine rules the opposite way, without exception, and the guidance card carries both halves and says which one is unbuilt. Every unattended run therefore ends with work sitting on a machine that will be thrown away. The decision is the owner's: either the engine grows the exception with its own guard, or the guidance stops promising it and the handover moves to something else.

## When it comes back

ready when an engine round takes the git lane, and before the next unattended run is started
