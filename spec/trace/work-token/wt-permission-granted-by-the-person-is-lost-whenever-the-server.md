## Why it stands

Permission granted by the person is lost whenever the server process comes back, while the walk's location is preserved. Twice inside a single day a silent restart returned a raised setting to its floor. The following weighted step then declined to proceed and looked exactly like a legitimate threshold, so the agent reported an obstacle that was actually forgetfulness. Either the setting persists like the location does, or a pull announces that it changed since last time.
