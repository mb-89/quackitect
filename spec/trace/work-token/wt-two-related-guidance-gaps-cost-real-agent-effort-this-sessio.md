## Why it stands

Two related guidance gaps cost real agent effort this session and are worth a joint pass before any decision on auto-routing weaker models: (1) build-chart's "the state authors this file" wording gave no fallback instruction for when the automatic step does not fire, and the agent could not tell that hand-authoring the seeded sub-machine file was the expected recovery until the owner pointed at existing examples; (2) boot's read/prove verbatim-quote loop cost roughly 100k tokens before reaching the front desk, with a missed probe re-serving the whole document rather than the missed span. Both point the same way: guidance and boot mechanics assume a reader who can self-recover from ambiguity or source-reading, which a weaker or more literal model may not do.
