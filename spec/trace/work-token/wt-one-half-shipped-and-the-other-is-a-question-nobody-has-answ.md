## Why it stands

One half shipped and the other is a question nobody has answered. The emergency switch does lift the hold that standing work puts on the walk, it takes that switch as an argument, it returns a stated reason rather than a bare no, and the code records that it was exercised. WHAT IS UNANSWERED is whether the little count beside a position moves on its own when work opens or closes. The live client carries no handling for those marks at all and refreshes the whole page instead, so the honest answer is that nobody has watched it happen.

## When it comes back

ready when a record is walked with the surface open and the first work appears at boot, so the owner can see for themselves whether the owed count falls without navigating
