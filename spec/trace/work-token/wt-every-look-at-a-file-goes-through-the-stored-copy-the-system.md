## Why it stands

Every look at a file goes through the stored copy the system keeps, unless somebody writes down a reason to avoid it. That widens into a question a sweep can put to everything: is each job done by exactly one piece of code? A reader holding no memory is not merely slow. Nothing can tell it that its answer expired, so it silently drifts away from what is true as soon as somebody edits, and no alarm sounds. The counters that hold direct access down belong to the same question, because they stop a number growing and never bring it back.
