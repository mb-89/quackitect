## Why it stands

Warn before a routing edit unsigns work across every open record. The stored fingerprint of a pinned demand folds in what that demand relies on, so touching one row of the rigor matrix quietly invalidates signatures nobody was thinking about. Either stop the fingerprint counting that field, or say plainly what is about to fall before the edit lands.
