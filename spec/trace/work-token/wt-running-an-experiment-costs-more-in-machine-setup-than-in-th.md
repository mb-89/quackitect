## Why it stands

Running an experiment costs more in machine setup than in the question being asked. One measured case: four attempts, three of them lost to interpreter naming, file encoding and patch mechanics, none of which touched the design under test. One third of that is already solved, since the shell verb now picks its own interpreter per platform. Still absent are writing a script with the leading byte marking that Windows expects, and handing out a disposable version-controlled folder. A run submitted with no control should also be refused.
