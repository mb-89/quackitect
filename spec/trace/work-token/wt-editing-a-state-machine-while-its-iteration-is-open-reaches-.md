## Why it stands

Editing a state machine while its iteration is open reaches only half the engine. Route planning re-reads the file. The half deciding which move is legal keeps whatever shape it held on entry. No call made during a walk forces the refresh, since the reload verb works only while nothing is running. Wanted is for an edit through the file lane to refresh the enforcing half as well.
