## Why it stands

Measure how large an answer this host will carry, and record it. The ladder verb was built and has never been climbed, because a verb added mid-sitting is invisible until the next one starts. Until it runs, every answer is bounded by a conservative guess. Climb it by doubling until the end marker stops arriving, halve, settle, record. Better still, have the opening of a sitting do it once per host.

## When it comes back

ready at the start of any session after this one, since the verb needs a fresh session to become callable
