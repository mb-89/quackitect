## Why it stands

Work that only a human can do loses that label the moment it lands on trunk. A session-held item carries a flag saying so, and every one of the 23 in this container has it. Not one of the 263 committed items does. The document listing what an item may carry never names the flag. So the label lives while the container lives and disappears on the way to version control. A ledger entry standing since i33 waits for this system to be able to route a task to a person; it now reads as satisfied while the single field bearing that meaning is lost in transit. Two repairs are wanted: carry the flag across the boundary, and add it to the declared vocabulary so mechanical checks can find it.
