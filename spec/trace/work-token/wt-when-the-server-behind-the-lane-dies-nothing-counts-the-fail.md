## Why it stands

When the server behind the lane dies, nothing counts the failures and nothing says whether it will return. The guard that notices a refusal repeating is blind here, because a dead connection never arrives at the counter in the first place. So a caller retries forever with no clause, no remedy and nothing to act on. Two things are missing: a way to tell a brief death from a final one, and an answer that names which happened.
