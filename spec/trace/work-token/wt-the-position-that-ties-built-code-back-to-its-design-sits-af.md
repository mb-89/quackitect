## Why it stands

The position that ties built code back to its design sits after every build step rather than inside them, so a step can finish with nothing anchoring it and nobody finds out until later. The matrix confirms the placement. Nothing in the code answers whether it should move, because the question is a ruling rather than a defect — and it needs all three parts answered together or the middle one has no meaning.

## When it comes back

ready when the owner has ruled three things: whether the trace check becomes each build step's own leaving condition, whether it replaces the later position or joins it, and what a step with nothing to anchor to does
