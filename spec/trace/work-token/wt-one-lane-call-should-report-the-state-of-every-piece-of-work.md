## Why it stands

One lane call should report the state of every piece of work running out of sight, each entry carrying a figure for how much longer it needs. Today a test run is asked about one at a time, and the answer names a rate rather than a time remaining. The listing verb that does exist covers shell work only, and the refusal for the other kind sends the caller to a list which cannot hold it.
