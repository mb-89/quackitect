## Why it stands

Separate a person shutting the window from the plugin host restarting under them. Only one means the sitting is over. Nothing tells them apart today, so a sitting either outlives a deliberate goodbye or dies on a routine reload. Close the sitting for the first; leave the walk untouched for the second.

## When it comes back

ready when somebody settles how the two events can be told apart, since the editor offers no clean signal for one of them
