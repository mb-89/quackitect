## Why it stands

Make an agent find the settled shape before inventing one. Twice in a single sitting a fresh answer was written where the repository already held a law covering it, and the prose forbidding exactly that was loaded both times without firing. Three candidate mechanisms: a gate on any state allowed to write to the specification, a typed rejection when hand-written markup arrives at a surface whose spec expects declared fields, or a state that names the precedent file it wants read on the way in.
