## Why it stands

The matrix rows served to a reader match the rows on disk. A check currently reads 126 where 63 stand, and a companion view reads 34 where 68 are listed. Each figure is off by a clean multiple, so one fault is likelier than two limits drifting apart. Whether they share a single origin is unproven.
