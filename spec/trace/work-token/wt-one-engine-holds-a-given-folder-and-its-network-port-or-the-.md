## Why it stands

One engine holds a given folder and its network port, or the second one says plainly what it did when the port was already taken. Four such processes stood on this machine in two pairs, started 47 seconds apart with identical arguments, and the same four still stood a day later. Two engines sharing one folder while keeping separate memory means a decision held by one is invisible to the other. Whether this is intended, with each client starting its own, is not established.
