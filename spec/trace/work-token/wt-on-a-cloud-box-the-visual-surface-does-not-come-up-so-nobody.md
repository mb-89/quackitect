## Why it stands

On a cloud box the visual surface does not come up, so nobody can watch a run from outside. Arrival reports that the port it wants is already held by something that will not answer as the surface, and it then carries on. The text lane attaches normally and every verb answers, so the walk itself is unaffected; what is lost is the only way a person has of observing an unattended run while it happens. The existing card describes a different collision, where a second copy of the engine holds the same folder. This one is a stranger on the port. Wanted is either a free port chosen at start-up, or arrival failing loudly enough that the run is known to be blind.

## When it comes back

ready when a run on a cloud box needs to be watched on a screen, or when the arrival script's port handling is next opened
