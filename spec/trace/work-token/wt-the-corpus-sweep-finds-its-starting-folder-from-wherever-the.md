## Why it stands

The corpus sweep finds its starting folder from wherever the shell happens to be, so running it one level down finds nothing and declares everything fine.

AN EMPTY WALK SATISFIES EVERY TEST, without a word. No step asks whether any material was found before pronouncing on it.

ONE GUARD REVERSES ITSELF IN THE SAME RUN. Started from the inner folder it goes red on a producer nobody had declared. Started from the top it goes green. Identical tree, identical commit, opposite answers.

BOTH BREAK THE SWEEP'S OWN HARDEST LINE, which says a category it cannot examine must report itself unexamined rather than quietly passing. Finding nothing is exactly that case wearing a pass.

THE REPAIR HAS TWO HALVES. Derive the starting folder from the project itself. And treat a count of nothing as a refusal instead of a success.
