## Why it stands

The counters that hold a line offer no way to move that line down. Each watches something the system ought to be doing less of, blocks any rise, and complains once its limit sits far above what is actually there. That pins a number and never asks whether it could be lower. One went from 100 to 129 over a dozen separate raises, each defended at the time and none looked at since. What is wanted is a pass that takes a counter, writes out everything it watches, weighs each item against why the counter is there at all, and cuts the limit to what remains. Such a pass already turned something up with nothing helping it: fourteen of those 129 read a file directly and then parsed it directly, on exactly the file kind the shared door was built to serve.
