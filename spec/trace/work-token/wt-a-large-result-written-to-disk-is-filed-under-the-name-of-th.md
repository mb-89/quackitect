## Why it stands

A large result written to disk is filed under the NAME OF THE VERB that produced it, one file per verb, overwritten each time. Its own comment states that as the design. So two hands calling the same verb at once destroy each other's cursor, and the second reader following the offered continuation silently receives a different document. Nothing refuses and nothing warns. A test pins the verb-named path, so the repair moves a test as well as the code. THE SEVERITY IS THE SILENCE: a wrong answer that succeeds is worse than a refusal.

## When it comes back

ready when parallel hands are worked on again — and sooner if a reader following a cursor is ever handed the wrong document
