## Why it stands

Close the side entrance to the work pool. The rule is that only the retro mints, and the reason is that minting is where a raw private jotting becomes an authored public statement. That rewrite is the privacy boundary. A hand can bypass it entirely by writing the file itself, because file writing is legal wherever editing is legal and nothing asks what folder is being written to. The fix is to make the pool's folder refuse a write that did not come through the mint, so the boundary is mechanical rather than a rule people remember.

## When it comes back

ready when an engine round takes the pool or the write guards
