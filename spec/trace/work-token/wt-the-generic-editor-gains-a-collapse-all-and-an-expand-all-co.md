## Why it stands

The generic editor gains a collapse-all and an expand-all control, and neither is allowed to grow the heading bar.

THE OWNER ASKED FOR IT IN CHAT on 2026-08-28: "the generic edit[or] we use for the work editor, it should have a collapse all and expand all buttons, but make them small, just a symbol so they don't blow up the heading bar."

TWO CONTROLS, ON THE GENERIC EDITOR the work editor is built from. One collapses every section, one expands every section. Every surface built on that editor gets them, which is why it goes there rather than into the work editor alone.

THEY ARE SYMBOLS, NEVER LABELS. The heading bar must not grow to fit them. The owner said so twice in one sentence, and that is the whole design constraint.

THE OWNER RATED IT LOW THEMSELVES: "Anyways, it's a note. Not that important." It lands with the rest of the UI sitting rather than ahead of anything.
