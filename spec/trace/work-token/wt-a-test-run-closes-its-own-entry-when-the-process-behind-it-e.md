## Why it stands

A test run closes its own entry when the process behind it exits. Today the child records its exit correctly and the owning entry keeps claiming to be going, so ghosts accumulate: three stood for fifteen hours, all showing complete. The loss sits in the handover from the child process to the operation that owns it.
