## Why it stands

Half of a correction landed and half did not. The demand was rewritten so it no longer names a place, and it carries a section saying it used to. THE NODE ITSELF IS STILL ON DISK under its old name, cited 34 times across 31 files, and one check still asserts against it. The position that made the correction could create a node and could not remove one, so the deletion had nowhere to happen. A reader meeting the old name has no way to tell it from a live demand.

## When it comes back
