## Why it stands

Only one generated artifact rebuilds itself, and even that one is a verb a reader is told to run rather than something that happens. The editor bundle still carries a banner telling a person to edit the source and then run a build by hand. Nothing anywhere enumerates what is generated, from what, by which producer — so nothing can notice a stale one at the moment it matters. The list has to exist before the rebuild can.
