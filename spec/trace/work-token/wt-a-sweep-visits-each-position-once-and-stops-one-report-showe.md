## Why it stands

A sweep visits each position once and stops. One report showed the same short ring of five positions walked around six times before it gave up, which wastes the whole run and hides whatever it was meant to find. The trail it prints is enough to detect the repetition mechanically.

## When it comes back

ready when a sweep next reports the same position more than once in its own trail
