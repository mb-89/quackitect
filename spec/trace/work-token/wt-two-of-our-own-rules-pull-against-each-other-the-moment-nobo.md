## Why it stands

Two of our own rules pull against each other the moment nobody is sitting beside the machine.

THE FIRST RULE splits the roles. One hand keeps custody of the piece of work; a second hand does the actual walking.

THE SECOND RULE forbids the custodian from ending its turn while work remains. Beside a person that is harmless, because the custodian simply passes control back and waits. On an unwatched box there is no one to pass control to, so it keeps going.

WHAT FOLLOWS. Both hands now advance the same walk, each recomputing where it stands from one shared session, and they overwrite each other.

WHAT IT COST, SEEN ONCE. One composed answer applied to the wrong position, four abandoned entries in the working checklist, and a spoiled document that had to be written again.

WHAT IT BOUGHT ANYWAY, and this is worth keeping. Every correction in one high-level design statement came from the second hand. The split was right. Only the traffic control failed.

TWO CANDIDATE REPAIRS, NEITHER BUILT.

- The stop guard learns that a registered second hand is a legitimate reason for the custodian to rest.
- A refusal states which position a form was written for. A displaced hand then reads its own displacement in the reply, instead of guessing at an absent field.
