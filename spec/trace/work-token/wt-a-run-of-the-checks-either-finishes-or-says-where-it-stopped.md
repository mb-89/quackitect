## Why it stands

A run of the checks either finishes or says where it stopped. On 2026-08-25 two runs on one Windows machine were abandoned after seven and twenty-three minutes, having written nothing to the file that records how far along they were, while a run of thirty-three files on the same machine that morning finished in forty-one seconds. The instrument that would name the file it stalled in is the progress record, and it stayed empty both times, so the first repair is to make that record arrive as the run goes rather than at the end.

## When it comes back

ready when the next run on a Windows machine covers more than thirty-five files, which is most changes now
