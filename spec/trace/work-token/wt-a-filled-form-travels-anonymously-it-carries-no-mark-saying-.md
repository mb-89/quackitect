## Why it stands

A filled form travels anonymously. It carries no mark saying which form it was written against, so when the walk has moved on, the contents land wherever the walk now stands.

WHAT HAPPENED, ONCE. Three fields whose names appear on both documents were written onto a checkpoint nobody meant to touch. Two further fields, belonging only to the intended document, went nowhere at all and no message said so.

THE REFUSAL POINTED THE WRONG WAY. It listed the checkpoint's own empty fields. That reads as though somebody had tried to complete the checkpoint, and it is silent about the three values quietly overwritten there.

WHERE IT HURTS MOST. A checkpoint is precisely the document two hands must never both write. This is a route by which a second hand writes to one without intending to.

THE SHAPE OF THE REPAIR. Let a payload name its intended document, and refuse where that name and the current position disagree. Which document was offered is already stated in the answer that offered it, so nothing new has to be tracked.
