## Why it stands

Big investigations belong in the knowledge base rather than in a scratch file that version control ignores. Every address cited would become an entry in whatever holds citations. Two matters want deciding together. First, whether somewhere to keep citations is actually standing, since a check found neither a node type for one in the schema nor a folder for one in the corpus. Second, what mechanism would later interrogate that store, because one which only accumulates and is never consulted repeats the very loss it was built to prevent.
