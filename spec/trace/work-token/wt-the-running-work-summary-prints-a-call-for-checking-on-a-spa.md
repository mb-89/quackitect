## Why it stands

The running-work summary prints a call for checking on a spawned hand, and the position gate then turns that very call away.

WHERE IT BITES HARDEST. One position's own instructions tell the agent to spawn a fresh pair of eyes for testing. That same position permits three reading verbs and none of them reaches the spawned hand. So the machine asks for help it has arranged to be unable to hear.

TWO WAYS OUT.

- Fetching a job by handle becomes free of the gate, the same way reading a served answer already is.
- Or the summary stops printing a call that the current ground will reject.

THE FIRST LOOKS RIGHT. Asking after a job is not starting one, and the handle was issued by the same machinery that then refuses to honour it.
