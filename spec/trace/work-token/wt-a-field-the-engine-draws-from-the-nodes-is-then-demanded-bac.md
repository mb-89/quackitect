## Why it stands

A field the engine DRAWS from the nodes is then demanded back as a typed copy, and echoing it costs tens of thousands of characters per submit. Half is already fixed: the template states outright that the stored copy is a rendering rebuilt on every look, and the binding is implemented on the viewing path and the export path. THE EMPTINESS CHECK IS A DIFFERENT PATH AND SAYS SO in its own comment — it keeps emptiness as the required-check's job and never consults what was drawn. So the drawn field still reads as unanswered unless a person retypes it.

## When it comes back

ready when an engine round takes the form checks — the emptiness check has to read the bound view for every drawn field, so a drawn field never demands its own echo back
