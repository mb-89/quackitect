## Why it stands

The report saying what a built system's owner has changed for themselves compares two commits. So edits sitting in the working folder, and files nobody added, read as untouched. A freshly written method card is the commonest case and the one it misses hardest. It is worse than a missing feature, since what comes back positively misleads. The test covering it must commit first before it sees anything, which is the defect standing in plain view.
