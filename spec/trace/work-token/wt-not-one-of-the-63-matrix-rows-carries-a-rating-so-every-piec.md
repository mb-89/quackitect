## Why it stands

Not one of the 63 matrix rows carries a rating, so every piece of work minted from them comes out unrated, and the offer that routes work by strength has nothing to route on. The engine short-circuits the whole check while ratings are absent, so nothing goes red and nothing explains why the offer hands out nothing. The code is right to wait, because grading those cells is a person's judgment and no agent may take it. THIS IS A DECISION BLOCKED ON SOMEBODY, not a defect.

## DONE 2026-08-28. 182 cells rated and the refusal armed.

EVERY ACTIVE CHANGE-SIZE CELL CARRIES A COMPLEXITY. Four hands rated the 63
rows against their full shape, each with a written reason, and two rows were
rated per column by hand to settle an open register entry that named them as
its own test.

THE LINE IS WRITTEN. `EVERY ACTIVE CELL CARRIES A COMPLEXITY.` stands in
`deliverable/machines/rigor_matrix/README.md`, which is what arms the load-time
refusal. All four columns compile with it on.

TWO OF THE ENGINE'S OWN REFUSALS CORRECTED THE FIRST ATTEMPT, and both were
right. `specification` is not a change-size column and owes nothing. Five rows
that RUN a sub-machine are placeholders whose work happens in the states below.
The honest count is 182 rather than the 257 first written.

WHAT THE README RECORDS, so a later reader does not have to reconstruct it: the
row's pair went onto every column that applies, so a `tailored` cell carries its
`full` sibling's rating. That over-drives the small end deliberately, because
the ladder's own asymmetry says under-driving is the dangerous direction.
Lowering one is a real judgement somebody still has to make.

## The by-product is bigger than the rating

THE SAME PASS WAS ASKED TO HUNT FOR MECHANICAL WORK, and found 62 candidates
with 35 marked certain. `spec/mechanical-steps.md` holds them, each with a file
and a line.

FOUR OF THEM CARRY A RECORDED INCIDENT ALREADY. A scoring floor no code
applies, against 22 of 44 cells that broke it. An editor that never seeds a
cell from its own node, producing four fields of retyping. A count the prose
demands that no field holds. A consistency sweep whose candidate set nobody
derives.
