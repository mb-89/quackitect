## Why it stands

Prove the suite would notice if a mechanism vanished. Deleting five working parts one at a time left every case passing on a run of over sixteen hundred, so a whole green board says only that nothing threw. Build the deletion pass as a tool, run it against the tree, and treat each survivor as a missing case rather than a curiosity.

## When it comes back

ready when somebody is willing to spend a run proving the suite catches what it claims to
