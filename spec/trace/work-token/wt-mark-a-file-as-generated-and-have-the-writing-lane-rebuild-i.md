## Why it stands

Mark a file as generated, and have the writing lane rebuild it the instant its origin changes. One script already knows where the text starts, where the twins belong, and how to turn one into the other, so the only missing part is what sets it going. Today an edit through the lane leaves the twins behind, nobody notices until the next opening, and the check then answers with an instruction naming a script for a person to run by hand. That hands the agent a job the system could do using knowledge the system already holds, and it fires long after whoever caused it has gone. It is the same class as a commit landing only half of a pair, and that one is the symptom while this is the machinery.
