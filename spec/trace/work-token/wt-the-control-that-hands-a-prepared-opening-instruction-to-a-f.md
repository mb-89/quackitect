## Why it stands

The control that hands a prepared opening instruction to a fresh session did nothing, and the owner typed it out by hand instead. The path has three legs: put the text on the clipboard, focus the window, send the keystroke. Two of them already name a cause when they fail. Neither spoke, so this failure is silent and looks exactly like the other two from outside. WHAT IS LOST IS A SESSION THAT STARTS THE SAME WAY TWICE, which is worth more than the few seconds of typing.

## When it comes back

ready when a reproduction says which of the three legs failed — until then nobody can answer the first question, which is whether the repair belongs in this repository at all
