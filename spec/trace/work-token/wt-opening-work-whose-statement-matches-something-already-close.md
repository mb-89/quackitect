## Why it stands

Opening work whose statement matches something already closed at that position succeeds, returns an empty id, and puts nothing anywhere. The minting code files a terminal match onto the settled list rather than the minted or matched list, so the caller reads back nothing and the surface shows nothing. IT SUCCEEDS, which is the whole problem — a refusal would at least say what happened. The failing expression is one line.

## When it comes back

ready when the retro has picked one of three: reopen the closed item in place, refuse and name it, or match only against items still open
