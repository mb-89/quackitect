## Why it stands

Being told to keep walking is worthless advice when every place that permits the needed verb lies behind you, because routing only ever draws paths onward. One session had to remove a single file to undo something it had just created, and no destination ahead of it allowed removal; only the front-desk hatch produced a way through. The engine already knows the blocked verb and already knows which places declare it, so the message can point at the closest one and can offer the hatch when nothing ahead qualifies.
