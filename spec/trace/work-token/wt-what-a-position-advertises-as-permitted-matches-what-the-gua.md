## Why it stands

What a position advertises as permitted matches what the guard actually allows. An agent reads the advertised set and trusts it, so a mismatch either blocks work that was offered or hides work that was available. Seen again on 2026-08-25: the advertised set was empty while seven verbs were in fact accepted.
