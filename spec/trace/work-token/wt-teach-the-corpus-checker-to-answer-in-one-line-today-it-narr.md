## Why it stands

Teach the corpus checker to answer in one line. Today it narrates every node it visits before saying anything useful, so the part a caller wants sits under a few hundred lines of chatter. There is no flag to suppress the chatter. Reaching the verdict therefore means redirecting to a file and slicing the end off it, which this system forbids as a matter of rule and permits only through a declared exception. Six of that exception's twenty-two uses in one round were this exact manoeuvre against this one program. Add a switch that prints the judgment and the problems alone, and the exception stops being needed for this at all.

ready when a round takes the corpus checker or the lane's output handling
