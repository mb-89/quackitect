## Why it stands

OWNER RULING. A sketch of a surface fully defines it. Nobody transcribes it elsewhere, and changing the sketch changes what is defined.

Three consequences.

It cannot live in a scratch area. Those get cleared, which would give the definition an expiry date.

Keep the editable file, not a flattened picture. A format that stores its scene inside the image both displays and reopens.

Never restate a sketch in words. That mints a second source which drifts, and the consistency check already hunts that shape.

This widens an existing law. State machines are drawn and edited as drawings, and a surface now works the same way.

WHAT IS OWED: a named home inside a record for these files, so a reader can find them. One is currently parked on a guess.
