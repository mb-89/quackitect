## Why it stands

A standing constraint says the system takes its own name from one file, and that nothing else it ships spells that name out. No check enforces this, and eight shipped files break it already. The sharpest case is the editor icon, where a system built under a different name still carries artwork titled with the original. Write the counting check the constraint demands, expect it to fail immediately, then clear each spelling it reports.
