## Why it stands

Parking an item against a phase this round will never reach is refused where it is written, not discovered later. The chosen rigor decides which phases exist, so the set of legal destinations is already known at the moment somebody names one. Today an item can be addressed to a phase the round dropped, and it simply never arrives.

## When it comes back

ready when a round runs at anything below the largest size, which is most of them
