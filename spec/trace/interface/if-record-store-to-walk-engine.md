The position derives from the record's files; nothing else remembers it.

## The tree joined this contract in i51

THE CROSSING IS NEW AND THE EXCHANGE IS NOT. The engine has always run a step's
leaving judgment against the record's tree. Nothing named the contract, because
the function that does it was only minted in i51.

IT IS HANDED OVER BEFORE THE JUDGMENT STARTS. A judgment that outlives the call
that started it cannot ask for its tree later, so it is given one and keeps it
until it settles.

FAILURE BEHAVIOUR: a tree that cannot be resolved refuses the handback rather
than starting a judgment with nowhere to run. The caller sees that refusal
inside its second, and no step is left deciding for ever.
