THE ANSWER COMES BEFORE THE WRITE, not after it. A module emitting widget
markup outside the one entry point is refused rather than reported.

THE SAME RULE ALSO RUNS IN THE SWEEP, over the tree rather than over one
write, because a break that did not arrive with this write still has to be
found. That is req-a-check-too-slow-for-the-write-moves-to-the-sweep, not a
second mechanism.
