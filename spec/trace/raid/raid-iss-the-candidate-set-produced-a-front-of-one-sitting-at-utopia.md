## What was observed

Three candidates were composed and a clean-context hand scored them against six
criteria. The baseline was scored too.

| candidate | the six scores in axis order |
| --- | --- |
| cand-the-narrow-guard | 3, 2, 3, 4, 3, 3 |
| cand-buy-the-sweep | 2, 1, 3, 3, 2, 1 |
| cand-the-handed-capability | 1, 1, 3, 2, 1, 3 |
| baseline | 0, 0, 3, 0, 0, 0 |

The narrow guard dominates all three others. Utopia is its own line exactly.

ONE CROSSING EXISTS in the whole set, between the two losers, on one axis.

## Why it is an issue rather than a result

A one-member front is a legal outcome. What makes this one a problem is the
combination.

- The winner is the shape the requirements were WRITTEN for.
- The winner already exists in this tree, governing a different rule.
- Two of the six criteria are close paraphrases of what that existing rule does
  well.

A comparison built from a register written around an incumbent will find the
incumbent. That is a validation-shaped question finding validation.

## What the numbers cannot settle

UTOPIA IS LOW. The best score reached anywhere is a single 4. One row cites a
named comparison; the other seventeen cite none.

So this is not a strong field with a clear winner. It is a weak field with one
member less weak than the others, and the arithmetic draws both the same way.

## What would close it

Either of two things.

- A fourth candidate composed by somebody who has not read the incumbent rule,
  scored on the same six axes. If it also loses everywhere, the front of one is
  honest.
- A criterion set derived without the register, from the demand alone, scored
  against the same three candidates.

## What must not close it

A second pass by the same hand over the same six axes. It would agree with
itself, and agreement is what is already in doubt.
