## PROBED, 2026-08-26 — there is no information to lose, because nobody ever put any in

## What was measured

EVERY MATRIX ROW WAS SEARCHED FOR A COMPLEXITY RATING. The shape is
`<column>_complexity: <judgement>/<reading>` on a row's frontmatter.

ZERO ROWS CARRY ONE. A search over the whole matrix returns nothing.

THE CORPUS SAYS THE SAME IN THREE PLACES. This record's own file: "NOT ONE
MATRIX CELL IS RATED." i38's sweep: "NO ROW WAS EDITED — none is rated, which is
the standing debt." And i38's demo run names the single exception it created by
hand and then removed.

## What that means for the collapse

THE TWO LADDERS ARE A SCHEMA NOBODY POPULATED. They exist in the loader, the
README teaches them, tests exercise them, and no real row uses them.

SO COLLAPSING THEM DESTROYS NO INFORMATION, because there is none to destroy.
The question "does one value carry what two carried" has no data behind it on
either side.

THAT IS A REAL ANSWER RATHER THAN A DODGE. A distinction nobody has ever drawn
in practice is not a distinction the system currently depends on.

## What the probe does NOT establish

WHETHER TWO LADDERS WOULD HAVE EARNED THEIR KEEP once populated. Nobody can
know, because nobody populated them. The collapse forecloses finding out, and
that is its honest cost.

WHETHER ONE AXIS IS ENOUGH FOR ROUTING. That is answered by using it, and the
entry's own original reason — only living with it settles it — was half right.
What it got wrong was implying nothing could be checked at all.

## Why the earlier exclusion was still a fault

THE PICK AT rank-unknowns LEFT THIS OUT saying no timeboxed probe settles it.
One did, in minutes, and it changed the answer from "unknown" to "no data
exists". The lesson is that "unprobeable" is itself a claim that wants checking.

## Probe

WRITE THE MAPPING AND READ WHERE IT TEARS. Take every step of the rigor
matrix. For each one, put its old reading rung and its old five-name rung
beside the single complexity value it is being given.

NAME EVERY STEP WHERE THE TWO OLD VALUES PULLED IN DIFFERENT DIRECTIONS. A
step light to read and hard to think about is the case that decides this, and
so is its reverse.

IT IS AUTHORING RATHER THAN MEASURING, and it can be done today. The matrix
stands, both old values stand on it, and nothing has to be built first.

## Why the kickoff gate owed this and did not open it

THE GATE NAMED THREE ASSUMPTIONS and deliberately logged none of them, because
the scope was still moving and an entry filed against a moving scope is an
entry about the wrong thing.

TWO OF THE THREE ARE NOW OPEN. The token count's legibility, and the storage
shape as standing dissent. This is the third.

## The two ladders being folded in

THE READING LADDER controlled how much a step demanded be read before it could
be worked.

THE FIVE-NAME RUNG — derive, transcribe, apply, author, frame — named what
kind of thinking a step asked for.

COMPLEXITY IS NEITHER OF THOSE. It is a routing key deciding which hand gets
the work, and the kickoff gate says so in as many words.

## Why it is graded plausible

THE TWO OLD AXES ARE NOT THE SAME QUESTION, so a step can be light to read and
hard to think about, or the reverse. A single value has to pick one, and the
mapping has never been written down. The gate itself listed that mapping as
missing.

## What falsifies it

ONE STEP WHOSE TWO OLD VALUES POINT OPPOSITE WAYS and whose single complexity
value gets the routing wrong in either direction.

## What is not at stake

AUTONOMY IS UNCHANGED. This entry is only about the difficulty side.
