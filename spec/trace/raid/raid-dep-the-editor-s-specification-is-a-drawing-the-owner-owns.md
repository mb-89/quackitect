## The ruling this rests on

A DRAWING OF A SURFACE IS THAT SURFACE'S SPECIFICATION. Nobody rewrites it into
prose, and if the drawing changes then the specification changed.

THE FILE IS design/worktokens.excalidraw.svg, beside this record. It stores its
own scene inside the picture, so the same file both renders and reopens for
editing.

## Why this is a dependency and not a risk

SOMEBODY ELSE OWNS IT. That is the tell. The design cannot resolve a silence in
the drawing by reasoning about it; it has to ask.

## Three silences already found

DOES AN ASSIGNED BUCKET GATE ITS STATE? The drawing says a bucket may be
assigned to a state. It was settled elsewhere that a bucket never gates. If a
record's own bucket holds its work, it must gate, or the record finishes with
work outstanding.

WHAT REACHES THE CHILDREN'S HALF OF A SUMMED COUNT? A machine showing its own
count beside its children's opens only its own. The rest is then a number
nobody can act on from where they stand.

WHAT HAPPENS WHEN AN ASSIGNED BUCKET IS DELETED? Its contents fall to the
backlog, which would quietly remove a record's scope.

## What closes it

EACH SILENCE ANSWERED, either in the drawing or as a ruling recorded beside it.
An answer given in conversation and written nowhere leaves the dependency open.
