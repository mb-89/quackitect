## What the risk is

THE SPLIT IS CORRECT AND IT HAS A SIDE EFFECT. Three files keep their door.
Everything else in the folder becomes readable.

BUT READABILITY IS NOT THE SAME AS BEING THE RIGHT SOURCE. A file with no door
today may grow one tomorrow, and an agent that learned to read it raw will keep
doing so.

## The concrete case already in the corpus

THE RETRO METHOD INSTRUCTS A RAW READ of a timings file, and a summary of the
same data. Whichever it reaches for, an agent is choosing between two sources
of one fact with no rule telling it which.

## Why it is expected rather than plausible

A RAW READ IS CHEAPER THAN LEARNING A VERB, and an agent optimises for the
call it already knows how to make. This one does not need bad luck.

## What bounds it

THE THREE FILES THAT MATTER KEEP THEIR DOOR. The call log, the notes and the
reading are the ones where paging and filtering carry real meaning, and none
of them is being opened.

SO THE DAMAGE IS CONFUSION RATHER THAN LOSS. Nothing is destroyed by a raw
read; somebody is misled by one.

## What would settle it

A WRITTEN REASON PER HIDDEN NAME, which this iteration already owes. The same
sentence that says why a file stays hidden can say what the door buys, and an
agent that reads the reason stops guessing.
