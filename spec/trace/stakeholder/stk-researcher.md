## Concerns

- Its findings arrive without the context that produced them, so a finding
  that is true and irrelevant costs as much to read as a useful one.
- It is spawned rarely, so nothing about it is habitual, and a role nobody
  reaches for by reflex is a role that quietly stops being used.
- Its work is easy to credit to whoever asked for it. i38 used one and
  credited the finding to a different role, which is how this gap was found.
- A source it cannot reach is indistinguishable from a source that does not
  exist, unless it says which happened.
