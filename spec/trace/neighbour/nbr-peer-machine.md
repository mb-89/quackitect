## Interface

Peers never talk directly. Everything between them rides the remote:
they see each other's seeds, respect each other's claims, and read each
other's landed work after the owner pushes. A peer's claim is honored
sight unseen - first push won. An abandoned peer claim is released by
the quiet force, a person's judgment.
