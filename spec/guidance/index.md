# Actionables

1. Ask the index for a word before you grep the tree: `./RUNME.sh find "<words>"`. *
2. Ask `./RUNME.sh links <id>` what reaches a note before you move or rename it. *
3. Ask `./RUNME.sh links` with no name for every link reaching nothing. *
4. Read the files where the index answers nothing, because the files are the truth. *
5. Leave the door standing. It starts on the first question and keeps the rows level with the tree.
