# Actionables

1. Run `./RUNME.sh work take` first where you start on `main`. It gives you a branch and its brief. *
2. Read the brief level zero hands you where you start on a `work/` branch already. *
3. Work the branch you hold and stop at its edge. The brief is the whole job. *
4. Commit and push each time you finish a thing. A box dies and takes its working tree with it. *
5. Write your result and your retro into `HANDOVER.md`, at the root, replacing the brief.
6. Run `./RUNME.sh work done` last. It sets the status and pushes.
7. Leave the merge to a person. A cloud box opens no pull request.
8. Say in your answer which commit you are on, and whether it matches origin. *
