# Motivation

Guidance is what the agent reads before it does anything.
It is expensive, because every rule costs attention that the other rules wanted.

So a note holds few rules, each one a thing a writer does.
A rule a program can hold belongs to that program and leaves this file.
This note says what shape a guidance note takes and why the shape holds.

# Actionables

1. A guidance note carries three chapters, in order: Motivation, Actionables, Discussion.
2. One rule per item, in the active voice and the present tense, as an instruction. *
3. A rule a program can check is a check, and it leaves this file for the thing that holds it. *
4. Hold a note to ten rules. A note wanting more is two notes.
5. Mark a rule needing argument with a star, and argue it in Discussion under its number.
6. Motivation says what goes wrong without the note, in ten sentences or fewer.
7. Discussion is the one chapter allowed the past tense, because it recounts what happened. *
8. Level zero hands over the Actionables chapter and no other, so write that chapter to stand alone.

# Discussion

## 2. One rule per item

A rule spanning a paragraph is several rules, and a reader holds none of them.
An item a reader can act on without re-reading is the size to aim for.
An instruction beats a prohibition, because a prohibition leaves the reader to guess the alternative.

## 3. A rule a program can check

An earlier line of this project measured its own guidance: 161 rules across 13 files, and about 90 of them mechanical.
Sixty-five sat in guidance while a program could have refused them.
Each of those spent the agent's attention and bought nothing, because the engine refused the breach anyway.

So a rule moves to the thing that holds it and leaves a link behind.
The voice rules went to a Vale style folder for this reason.

## 7. Tense

The surface takes the present tense, because it says what holds now.
A chapter recounting an incident is history and reads as history.
Discussion is where that belongs, so it is the chapter allowed the past.

A note wanting to recount an incident at length writes it down elsewhere and links to it.
