# Actionables

1. Run `./RUNME.sh retro effect <retro>` after collect, which counts the last retro's class patterns over this input. *
2. Read each class the verb names, and say whether its failure still occurs and whether its rate falls. *
3. Carry a class whose rate holds or grows into this retro's classify step, and name its fix as failing. *
4. Retire a class whose failure no longer occurs, and keep the fix that retired it.
5. Read the battery's report the verb writes beside the classes. It holds each part's time against the last retro's, and the slowest cases new, grown and gone. *
6. Turn a part or a case that grows into a finding for classify. Name a case that earns its time no more as one to cut.
7. Read each of the slowest cases, and say what it proves. Say what it reaches past a fake, and what smaller fixture proves the same. *
