# Actionables

1. Run `./RUNME.sh retro effect <retro>` after collect, which counts the last retro's class patterns over this input. *
2. Read each class the verb names, and say whether its failure still occurs and whether its rate falls. *
3. Carry a class whose rate holds or grows into this retro's classify step, and name its fix as failing. *
4. Retire a class whose failure no longer occurs, and keep the fix that retired it.
