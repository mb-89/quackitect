# Actionables

1. Ask of every bad output which rule, prompt or tool makes it, and what change stops that. *
2. Rank the log's refusals and failing calls by rule, and name what each one stands in for. *
3. Read a retry in both records: the log shows it, and the transcript says why. *
4. Read the agent's thinking for doubt, worry, a guess, and a plan it drops. *
5. Mark every place the owner corrects the agent, repeats an ask, or pushes back. *
6. Count the shell commands, and name the missing verb each group stands in for. *
7. Name a script a hand writes twice as a capability asking for a home. *
8. Compare the chapter's first and last hours for errors and thinking length, so a tiring worker shows. *
9. Rank by what repeats, because one shape three times is a property of the machinery. *
10. Name the cheapest change that stops a pattern: a check, a refusal, a gate, a prefill, then a sentence. *
11. Record what goes well too, and name the practice behind it. *
12. Read every failed review on its own, and name the shape of the mistake beneath it. *
13. Name a tool nobody calls, and a tool a hand calls and then corrects. *
