# Why

The owner decided this for the migration, and the decision is final. Every pair
of duplicate implementations met as golden files before its JavaScript copy
went. Go alone wrote frontmatter, after one commit that rewrote every ticket in
the Go writer's form. The prose checks moved to Go, with wink as the reference
until the owner accepted its differences. An agent reads this note before it
asks again.

## 1. What it measured

Several pairs already disagreed, as
[[spec/design_output/migration#the-duplications]] lists. Go quoted a value, and
JavaScript left it bare. Five parsers and three writers read and wrote
frontmatter.

## 2. Why golden files

A golden file named each difference, and the owner read each one at the merge.
A port that dropped a copy with no comparison hid the drift inside the survivor.

## 3. Why one rewrite commit

A single commit rewriting every ticket put the whole diff of the form in one
place. Later diffs then showed content alone, and a writer rewrote the lines it
changed.

## 4. What it gave up

Each pair cost its golden files, and the rewrite commit touched every ticket at
once. The prose checks kept wink until the owner accepted each difference, so
Node ran until then.

## 5. What would make it wrong

A difference where the JavaScript copy was right and the Go copy wrong, accepted
at the merge unread. The golden files then carried the fault forward, so the
owner's read was the step that held it.
