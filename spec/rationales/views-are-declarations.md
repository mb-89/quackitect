# Why

The owner decided this for the model, and the decision is final. A file declared
each view, and one renderer drew every declaration. An agent reads this note
before it asks again.

## 1. What it measured

The tree held the log and the work as views, and neither was a form.
`spec/views/work.base` already named the columns, flags, presets, filters and
sorts. The window counted the tickets in its own code, beside the sidebar, and
the numbers disagreed. A view reading a name drew the value the provider
gave, so it could not disagree.

## 2. What it gave up

A view could not compute, so a column needing a new value waited on a
provider. A renderer drew what the keys allowed, and a look the keys lacked cost
a key in [[spec/design_output/views]].

## 3. What would make it wrong

A view that needed logic no key expressed, such as a drawing of a route. Such a
view stood outside the renderer, the way the route drawing stayed in the
extension.
