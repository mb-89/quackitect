# Why

The owner decided this for the model, and the decision is final. Every crossing
of the boundary went through a door, one file each, holding its interface, the
real one and a fake. A check over the imports held the rule in the build. An
agent reads this note before it asks again.

## 1. What it bought

A test ran in memory with the fakes, so a case touched no disk and no network
and replayed the same on every box. A new adapter was one more file, and the
index and the modules stood as they were. The JavaScript doors had held the
same rule, per [[spec/design_output/doors]], and the Go code kept it.

## 2. What it gave up

A module could not reach the outside in one line, so a quick read of a file went
through `files/` or a door call. A fake cost code a person kept in step, and a
contract test per door paid for that.

## 3. What would make it wrong

A fake that answered where the real door failed, often enough that green tests
hid real faults. The contract tests existed to catch that, so a fake drifting
past them was a missing case and no reason to drop the fakes.
