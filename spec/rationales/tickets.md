# Why

A ticket is the one unit of work this tree hands an agent, and the agent met it
with no rule that named it. Sessions wrote briefs by hand, parked ideas in a
memory folder no clone sees, and edited the fields the verbs own. The guidance
note says what a ticket is and which verb touches it, so a session reaches for
the verb before the editor.

## 2. The engine hands the branch

A hand picking its own branch reaches for one another box already holds. The
pull reads which tickets stand free, so it takes a branch for a cloud box and
hands a desk the free tickets.

A hand naming a branch of its own works past that reading, and the push says so,
once the work stands.

## 3. The verbs own three fields

`state`, `step` and `steps` say where a ticket stands, and a hand that edits
them by hand writes a status the engine then reads as a fact. The pull writes
them, and the door refuses an agent's edit, so a ticket tells one story.

## 4. Evidence under its own leaf

Evidence written under another leaf reads as that step's answer where the engine
looks, so the record and the note say two things. A hand reading the ticket
later takes the record, and the stray field stands unread.

So each leaf carries its own, and the pull reads it there before it moves the
ticket on.

## 8. A doubt costs one line

A doubt a hand carries out of a session dies with the box. Parking it costs one
line, and the retro decides it later with the tree in front of it.

The alternative is a hand weighing every stray thought against the step it
stands on, which stops the step.

## 9. A note is private

A note is the smallest ticket, and most of them die at the retro. A private
ticket under `.se` costs nothing to write and stays off git, so a session parks
a thought without a commit and without a review.

## 10. The memory folder drains

The agent's memory folder stands on one box and travels with nothing. A rule
that lives there shapes one box alone. So the retro moves every such entry into
the tree, where a clone and a cloud box read it.

## 11. A group is a branch

A branch is the one thing git decides on. So the claim on a group is a push, and
two boxes reaching for one group meet one rejected push. The children ride the
branch, and the merge is the verdict over the sum.
