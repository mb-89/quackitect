# Why

A chapter reader asks what happened. An auditor asks whether the work held
the rules the project writes for it. The two read the same window from two
sides, and a rule broken in silence shows only to the second.

## 1. One checklist

The craft guidance fills the checklist, and each retro adds to it. So the
list grows with what the project learns, and every retro walks all of it.

## 2. The work, and the record

A rule about code reads in the code the window lands. A rule about conduct
reads in the record: the log and the transcripts. An auditor reads whichever
the item asks about.

## 3. Held, broken or untested

An item nobody could test says so, with the reason. A silent item reads as
held, and the next retro inherits a gap it cannot see.

## 5. A rule nobody follows

A guidance sentence nobody follows is no fix. The third version measured
whether its findings led to edits, and promoted the ignored rules to refusals
or cut them. An auditor names each one, so the retro decides between a check
and a cut.
