# Why

A group closed done, and its cloud box stayed on the branch. The box then wrote
the group's name into five free tickets, and the pull handed each one out as a
child. It worked them there for two hours past the close.

The desk read the branch as done and merged it. The five tickets rode in
unread, and the owner found them afterwards.

Nothing stopped the box. The pull read a closed group as any other, and the
group field took a write from any hand. So the pull now answers `done` on a
closed group, and the box goes back to trunk. For the rule, see
[[spec/design_output/pull#a-closed-group-hands-nothing]].
