# Evidence form / mint-cost-per-entry

## current_situation

Deriving what a position owes runs on every entry into every position, so a cost anywhere near the per-hop bound would be felt on every hop of every walk.

MINTING WAS RUN FOR REAL over all 137 method cards, reading each card and deriving an identity per marked step, with the cache warmed first so the figure is the steady state rather than a first touch.

MEDIAN 0.039 ms. WORST 0.570 ms, on the gate review card. All 137 together take 6.7 ms.

THE BUDGET IS 1000 ms, so the worst single mint is 0.06 percent of it. This was the sharper of the two open assumptions the architecture round carried, and it is not a close call.
