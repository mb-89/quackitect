## scope

WHAT THIS ROUND TAKES ON, and the kickoff gate's goals are the binding statement. This restates them as a boundary rather than as a list of promises.

THE UNIT. Every piece of work becomes a work token: one markdown file carrying frontmatter and prose together.

THE PLACES A TOKEN CAN BE. Buckets on a state. Input and output block the state; done is a filter over status rather than a place; pending holds work that does not block. A user's own bucket is born holding what was dropped on it and dies when it empties.

THE STATUS A TOKEN CAN HAVE. Open, in work, or one of several terminal kinds including rejected and skipped. Place and status are separate, and nobody holds a token.

THE EXIT RULE. A state may be left when every token in its input and output buckets has reached a terminal status or moved elsewhere.

WHERE TOKENS COME FROM. Reading requirements become input tokens, only where the evidence is not already proven. A method's marked headings become output tokens. Today's evidence fields become output tokens, one per field.

DEPENDENCIES. A token may depend on another token or on a state finishing, and readiness is derived from that edge rather than authored in prose wherever the edge exists.

THE PULL. It returns open tokens instead of instructions.

THE LADDERS. Four become two. Complexity becomes a routing key deciding which hand takes a token. Autonomy is unchanged.

THE SURFACE. Counts per bucket on every state, a zero bubble hidden, and clicking one opens the token editor. The editor's specification is the owner's drawing and is not transcribed anywhere.

THE SWEEP. The architecture analysis later in this round covers every place work is done, so nothing the change touches is missed.

ONE ADDITION MADE DURING THE MOTIVATION PHASE. Every build milestone gets a debt-reduction step with a small budget, seeded from the pool when the build steps are made.

## non_goals

Ten things a reader could reasonably expect here and will not find. Each says where it went.

THE WALK ITSELF IS NOT TOUCHED. Routing, edges, gates and how the pull computes position all stay exactly as they are. A change this size could plausibly move the machine, and it does not. Only what a state hands out changes.

REMOVING THE NARRATION SYSTEM IS IN SCOPE, and this line previously said the opposite. The record's own vision says it at line 44: the narration system is gone, the token's own open and done entries produce the graph the update ops build by hand today, and five refusal clauses that exist only to police narration are removed with it.

WHERE THE MISTAKE CAME FROM. i55 is named for narration and it is listed as an INPUT to this round, not as its owner. Reading an input as a destination put the work in the wrong place.

WHAT IT COST: the business case was split into a saving this round enables and a later round collects. That split is wrong and is corrected. The sixteen per cent is this round's own return.

ARCHIVED RECORDS ARE NOT CONVERTED. Finished records keep their evidence forms as they stand. Nothing is migrated backwards, and a reader of an old record reads it in the old shape.

HOW THE POOL IS STORED IS NOT REBUILT. The file-per-token shape stands. The argument against it is real and recorded as standing dissent in the register, and it is the owner's to rule.

NO CLOCK IS PUT ON ANYTHING THAT WAITS. Every surveyed workflow engine bounds an open-ended pause and this system bounds none. It is adjacent, it is named in the delta, and it is deliberately not taken here.

THE SPAWN POSITIONS ARE NOT REMOVED. Owner ruling: they go, and i64 is where they go, because that round already rebuilds how a worker is started.

DRIVING THE MACHINE BY HAND IS NOT BUILT HERE. A person walking the machine has no view of its own today. That is i58 and i23, and it stands as work tokens in the pool.

WHETHER A PRIVATE NOTE BECOMES A TOKEN IS NOT DECIDED. It is open and it is the owner's. Nothing is built either way, so the two stores stay as they are for now.

THE RETRO REOPENING ON NEW NOTES IS NOT FIXED. It is a defect in the retro's own mechanics rather than in how work is modelled, and it is captured as a note.

THE SEVEN FILTERING SURFACES ARE NOT FOLDED INTO ONE. Whether they are one mechanism or seven copies is worth finding out and is not a commitment. If the answer is seven, this round should fold rather than add an eighth, and that is a condition rather than a plan.
