# The candidate drawing

One compose state per line drawn on the chart at build_chart. Four lines were
drawn there. A FIFTH and a SIXTH were added on 2026-08-14 when a fatal must
arrived that none of the four answers: an agent changing the engine without
stepping out of their work, and without changing what any other agent runs.

The four disagree at the chart's first row, which is the only row whose
answers are mutually exclusive shapes rather than compatible components: does
the lane's root move at all.

- SPEAKING ROOT keeps the moving root the probe measured, makes it total, and
  makes every answer say which tree it used.
- FIXED ROOT stops it moving and addresses a record as a path underneath one
  permanent root.
- JUDGED PATH is the decided i1 answer drawn whole, so the issue that says it
  was never priced can finally be closed by comparison.
- OS ROOTED hands the question to the operating system and writes no
  resolution rule at all.
- LIVE ENGINE answers the row the other four do not: what happens to the
  running engine when its own code changes inside a record's walk.
- CORE AND SATELLITE answers the same row with a shape the owner named, and
  it is the only line that gives the machine-wide shared state an owner by
  design rather than by leftover.
MEMORY SERVED WAS DRAWN AND THEN FOLDED (owner ruling 2026-08-14). It was
core-and-satellite with one cell changed, so putting both on a front compared
a design against itself. Holding a record's work in memory turned out to be
adoptable by EVERY line, which makes it a refinement rather than a rival, and
it is recorded as one on its option node.

They are independent and all hang off start; the join waits for every one.

## What each state writes

It writes back into the candidate note its line already created, and mints
nothing:

- How it works - the whole architecture, and especially the seams between the
  chosen options.
- What it costs - rough feasibility checks, proportional and no more.
- What it leans on - what has to be true for it to work.

Nothing here is scored. Judging stays at evaluate-set, because an agent that
knows the score while it writes the description writes a description that
earns the score.
