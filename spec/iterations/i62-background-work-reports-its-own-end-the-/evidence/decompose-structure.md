# Evidence form / decompose-structure

## current_situation

The candidates phase was struck at this change size, so the structure inherits the requirements and the function structure directly.

No element is minted and no interface is minted. That is the tell the state asks for: wanting either would mean the architecture is moving and this is not a minor.

Three new functions allocate into two standing elements, and one standing interface carries one more flow.

## elements

- el-work-registry
- el-entrypoint

## allocation

THE MATRIX IS COMPUTED AND NOT WRITTEN HERE. What follows is only the argued spread.

TWO FUNCTIONS LAND ON el-work-registry BESIDE THE ONE IT ALREADY HAD. Keeping the account true and bounding a wait are both about an entry's own life, and the entry lives in that element. Splitting them out would put the decision about when an entry stops somewhere other than the thing that decides when it starts.

ONE FUNCTION LANDS ON el-entrypoint. Holding a workspace alone belongs to the start path, because the only moment the question can be asked is before anything else is done. It is not the registry's, even though the registry is what the answer protects.

THAT SPREAD IS THE ONE WORTH ARGUING. Settling entries a previous instance left behind is only safe because one instance holds the workspace, and those two facts now live in different elements. The dependency runs from the registry to the entrypoint and not the other way, which is why the check sits in the start path.

NO FUNCTION IS IMPLEMENTED IN MORE THAN ONE PLACE, so there is no other spread to argue.

ONE CROSSING GREW RATHER THAN A CELL OPENING. flow-wait-bound is produced where a wait is entered and consumed in the registry, which is the boundary if-walk-engine-to-work-registry already covers. It joins that interface's carries. The pair, the direction and the form are unchanged.

THE OTHER TWO NEW FLOWS CROSS NOTHING INSIDE THE SYSTEM. flow-existence-answer and flow-workspace-hold are both produced outside it, by the operating system, and consumed in one element each.
