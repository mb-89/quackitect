## prfaq

### PRESS RELEASE

### The folder you open is the whole thing

Quackitect no longer has a level above itself.

UNTIL NOW the repository held a wrapper: a folder called project that carried everything being built, and beside it the machine's own state, the built packages, the launcher and three documents. People opened the inner folder. The outer one existed and nobody worked in it.

FROM THIS RELEASE THERE IS ONE LEVEL. What you open is the project. Its state lives inside it, where it describes what it is next to rather than what it is above.

AND THE INSTALLER RUNS ONCE, which the entry document has promised since it was written. After that, opening the folder is the whole ritual. If something changed that a running window cannot pick up, it says so and offers a reload rather than going quiet.

WHAT THIS BUYS somebody using it: one fewer thing to know. There is no second location, no script to remember, and no question about which folder is the real one.

### HOSTILE FAQ

**Nobody complained about the folder layout. Why spend a major on it?**

Because the layout is not the point. The machine-state folder sits one level above the thing it holds state for, and the lane hides it wholesale, and that costs three measured things: 121 citations nobody can follow, a method step that instructs a read the lane forbids, and an agent that cannot read back a declaration its own header claims to maintain. The tidiness is a consequence, not the reason.

**You raised the size to major for moving files. Is that not ceremony?**

The column buys one thing: a sweep of the standing requirements the move touches, for continued truth. A change that relocates every path is exactly the kind that quietly makes an old demand untrue. If the sweep finds nothing, the column cost a form. If it finds something, the column is why anybody found it.

**What breaks while it is half-moved?**

Nothing may be half-moved. The caller count runs before the first edit, and nothing is renamed or deleted while things are moving. That is a scope item rather than an intention.

**A path will be missed. Then what?**

Then a caller finds an empty folder and reads it as a fresh start, which is the worst shape available because absence is a legal state here. That is why it is a register entry with a probe, and why the count comes first.

**What happens to somebody who already has this cloned?**

THIS ONE HAS NO CLEAN ANSWER and it folded. Their machine-state folder is ignored by git, so no commit can move it. They pull, the engine looks in the new place, finds nothing, and reads a long-driven tree as a fresh one. Every existing checkout hits this, by construction.

**Opening a folder now sets things up on its own. How is that different from something malicious?**

It is different at the edge and identical inside it. A folder that is not a project is untouched entirely. A folder that IS one was seeded by a deliberate act, and that act is the consent. The scan for this milestone found the editor's own silent bootstrap being used to load extensions without prompting, so the shape is known to be abusable and the line is drawn rather than assumed.

**The 121 citations still do not work after this. What did anyone actually get?**

Conceded, and the record's own claim on this was corrected at the kickoff. This delivers the precondition and not the repair. What anybody gets on the day is one level instead of two, an installer that runs once, and files that were unreadable becoming readable. The citations are the next record's.
