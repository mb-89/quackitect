# Evidence form / the-staleness-check

## current_situation

SIX CONSUMERS DERIVE FROM THE DECLARATION AND ONE CANNOT. The editor extension is a separate build with no run-time reach into the engine, so it holds a generated copy.

A COPY NOTHING COMPARES IS THE DRIFT THE DECLARATION EXISTS TO STOP. Until this chunk there was nothing to compare it.

## built

TWO CHECKS IN `enginestatedecl-check.ts`, and they answer different questions.

- `generatedCopyDrift(root)` reads the editor's constant back out and compares it to the declaration. A wrong value, a missing constant and a missing file are all drift, because a consumer that lost its copy has either gone back to a literal or stopped being a consumer.
- `strayLiterals(root)` lists every engine line that still spells the folder's name rather than deriving it.

ONLY THE FIRST FAILS. Preflight pushes drift onto its failure list, which is where a person sees it at boot. The strays are printed as a count and nothing else, because they are the move's work and the number falling run by run is what progress looks like.

WHY THE SPLIT IS NOT A SOFTENING. A check that failed on the strays today would fail on work this chunk's own sibling has not done yet, and a guard that blocks work the system cannot yet do is a trap rather than a guard. The drift half has zero tolerance from its first run.

THE PATTERN FILE EXCLUDES ITS OWN TWO. The declaration is where the name is supposed to be spelled out, and the check quotes it to build its pattern. Counting either would make the number lie by two forever.

MEASURED: preflight green, and the whole battery green apart from this record's own twenty-three reds, each naming a chunk that has not been built.

## follow_up

### What this makes possible

THE ROOT CHECK CAN NOW BE GENERATED. It runs a test built from the same answer, and that was only safe once a drifted copy could be caught. The chunk order had this dependency in it and the reason is now concrete rather than argued.

### The stray count is the move's progress bar

TEN FILES STILL SPELL THE NAME, in scripts and hooks rather than in consumers. Preflight prints the number every boot, so the move's progress is visible without anybody running a search.

THE COUNT MAY FALL AND SHOULD NOT RISE. It is not a ratchet with teeth yet, and it should become one the day the move reaches zero. Recorded here rather than built, because a ratchet set above zero invites somebody to fill the gap.
