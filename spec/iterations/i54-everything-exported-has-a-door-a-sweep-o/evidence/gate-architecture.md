## round_2_red_team

- STEELMAN, at its strongest => The decomposition is four elements where one would do, and three of the four are labelled `existing` because their call sites already stand. Read uncharitably, this milestone renamed parts of a file that already works, drew two interfaces between them, and produced a structure whose only genuinely new part is a predicate taking one more argument. A reviewer could reasonably ask what was decided that the code did not already decide.
- The answer to the steelman => The split by reach is not a rename. widgets.ts holds one rule fixed to one conversation; the neighbours walk found four. The choice between one parameterised rule and four copies of the shape is a real choice with a real cost difference, and the decomposition takes the first.
- The strongest attack on the element set => el-door-write-guard duplicates el-widget-guard's job. Both are write-time callers of a rule module, and allocation spread already counts fn-run-a-governed-walk.guard-a-write as implemented by two elements. Folding one into the other is a question the build will meet and this milestone did not answer.
- The strongest attack on the interfaces => Only two crossings were declared, both into el-door-sweep. Nothing crosses from el-door-rule to el-door-write-guard in the drawing, although the element bodies describe exactly that exchange. The flows the functions carry did not demand it, so the drawing is thinner than the prose.
- THE KILL CRITERION, named => This decomposition is wrong if the four conversations do not want one rule. A version door with 16 touching files and a disk door with 81 may want different strictness, different departure lists and different intervals.
- Looking for the kill criterion => opt-one-rule-per-conversation-rather-than-one-rule-for-every-reach was drawn as an option and rejected in the third decision on the grounds that four mechanisms cost more than one predicate and two lists. That is an argument about mechanism count and NOT an answer about strictness.
- What that means => the kill criterion is not disproven, it is deferred. The per-door counts differ by more than an order of magnitude and nothing in this record measured whether the same rule fits all four.
- The honest state of the two at-risk rulings => Both are real and neither is this milestone's doing. Five copies of a containment predicate with two disagreeing, and 34 of 35 lane verbs named in no requirement. The door regime neither caused nor closed either.
