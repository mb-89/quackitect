### What the two runs actually show

RUN ONE takes cand-buy-the-sweep as the datum. The narrow guard scores +1 on five axes and 0 on one, totalling +5. The handed capability totals -2.

RUN TWO takes the leader as the datum, which is the controlled-convergence step. Both rivals go negative: buy-the-sweep at -5, the handed capability at -4.

THE LEADER DID NOT CHANGE, so the result is stable.

### Why stability here is weaker evidence than it looks

PUGH CONVERGENCE EARNS ITS KEEP BY SWAPPING THE DATUM. The method's value is that a different reference point can promote a different candidate, which exposes a ranking that was an artefact of where you started.

HERE IT CANNOT. One candidate is at least equal on every axis, so no choice of datum can reorder anything. The second run was arithmetically bound to agree with the first before it was computed.

SO THE STABILITY IS REAL AND IT IS NOT INFORMATION. It reports that domination is transitive, which was already true.

THAT IS THE SAME DEFECT THE M4 GATE RECORDED, arriving a second time in a different shape. A row that cannot separate anything cannot separate anything at any datum.
