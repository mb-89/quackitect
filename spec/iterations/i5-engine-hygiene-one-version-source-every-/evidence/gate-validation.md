## follow_up

THE TYPECHECK IS NOT RUNNABLE FROM THE VALIDATION GATE. `se_run` is not among its legal tools and `se_test`'s battery does not include tsc, so a gate whose round_0 asks for types can only carry the number forward. Either the battery should run it or the gate should grant the tool. This is a note for the retro, not a defect of the delta.

THE GATE FORMS ASK FOR THE WHOLE STANDING SET, not the delta. This form named twenty-four must stories and nine value props to report on five requirements; nineteen answers are "not exercised". The scoping is described in the gate's own guidance and not implemented in its fields.
