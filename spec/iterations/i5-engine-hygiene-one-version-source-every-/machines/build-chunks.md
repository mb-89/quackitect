# The build plan

Five chunks. Two run free and three form a chain, and the chain is a fact
about one FILE rather than about the design.

## The lenses, and both are visible in the order

PARALLEL FLOW SHAPES THE FAN. The five changes share no design and no data.
Each answers one requirement, in one place, with its own test file already
written and already red. Nothing here is a deep chain pretending to be one.

RISK FIRST DECIDES WHAT COMES LAST. The paint is the only change that touches a
rule the whole panel rests on, and the only one whose test could not be written
against an existing export. It goes last, after the two smaller changes to the
same file have landed and their cases are green — so a red there is the paint's
own and not somebody else's.

## The one edge that matters, and it is not a design edge

THREE CHUNKS TOUCH `engine/render.ts`: the actor read, the palette path export,
and the paint decider. They are chained for that reason alone.

A DEPENDENCY EDGE HERE MEANS "do not edit this file at the same time", not
"needs the other's output". Said plainly because the drawing cannot tell the
two apart, and a later reader would take it for a design coupling that is not
there.

WHAT ACTUALLY FLOWS ACROSS EACH EDGE: nothing. That is the honest answer, and
the check the method asks for — per edge, what flows — is answered by naming
the file rather than a flow.

## What fans out and what does not

THE FIRST TWO CHUNKS ARE FREE. `the-version-flag` lands in `bin/se-mcp.ts` and
`an-empty-source-says-so` lands in `stateform.ts`. Neither shares a file with
anything else in the plan, so either could be built by a second builder with no
coordination at all.

ONE AGENT WALKS ALL FIVE HERE. The width is real and unused, which is worth
recording rather than hiding: the plan says what could have been parallel, and
the run says what was.

## What this plan deliberately does not contain

THE HEAVY TEST FILE'S SPLIT IS NOT A CHUNK. The measurement that decides
whether splitting it buys anything arrives at verification, which is after
every chunk here. Drawing it as a chunk would commit the build to an outcome
the evidence has not reached.

## Sizing

EVERY CHUNK IS ONE FILE AND A FEW LINES, except the paint, which is one file
and one new exported function. Each is resumable on its own: a chunk that
stops half-done leaves a red test naming exactly what it was doing.
