## built

FOUR FUNCTIONS AND ONE PUBLISHED VOCABULARY.

- `difficultyOf(step)` reads the pair off the step in hand. A step with none REFUSES rather than defaulting, and the message says how to fix it: rate the cell, or write the README line once every active cell is rated.
- `sizeUnit(steps)` takes the maximum PER FIGURE and keeps the spread. Taking it over a collapsed rung would lose the pair — a unit holding one heavy-reading step and one heavy-judgement step needs both figures high, and the collapsed answer would say only that it is hard.
- `rungFor(pair)` names a rung or returns the pair that matched none. It never falls back.
- `publish(pair)` sends the decision and the input it was made from, together.

THE RUNG VOCABULARY IS THE INTERFACE AND IT IS THE ONLY ONE: derive, transcribe, apply, author, frame. The names say what the WORK is, never which model does it. Everything published crosses a boundary we do not control, so these have to be stable in a way nothing else in this element does.

THE CORNER RULE IS THE HIGHER OF THE TWO POSITIONS, and the code carries the argument beside it: under-driving produces a plausible wrong answer that passes, over-driving only costs money.
