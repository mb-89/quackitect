### Re-signed after the sizing half arrived, 2026-08-20

WHAT THIS FORM SAID: only one of the two predecessors was built, so a named driver was a string a caller repeated back with nothing behind it.

BOTH ARE BUILT NOW. `the-answer-rides-the-pull` publishes `needs` carrying a rung and the pair it came from, so the value a walker sends back on `named_driver` is one the walk already holds.

THE JOIN IS STILL NOT CLOSED BY A CHECK, and that is the honest residue. Nothing compares the `named_driver` a caller sends against the `needs` the pull published for that same state. A walker could name any rung it liked and the record would carry it.

THAT IS THE SAME SHAPE AS THE MODEL COORDINATE and it takes the same answer: the value comes from the party being measured until it comes from the walk itself. The pull knows what it published, so a later iteration could stamp the named driver from the same place it stamps the state — and then the asymmetry stops being voluntary.

## built

TWO MORE ARGUMENTS RIDE EVERY LANE TOOL. `named_driver` carries the strength the step was told it needs; `weaker_reason` carries why a weaker hand took it anyway.

SENDING A NAMED DRIVER IS WHAT ARMS THE ASYMMETRY, and the schema says so. A record carrying one and no reason takes `weaker_reason: null` and `unreasoned: true`. Omitting the reason does not stop the call.

A REASON CARRIED WITHOUT A NAMED STRENGTH IS NOT ALLOWED TO SUPPRESS THE MARK. `whichHand` drops it from the stamp when no driver was named, because a sentence about nothing would otherwise make an unarmed record look reasoned. The field is still kept where a caller writes it directly; what is refused is letting it stand IN PLACE OF a named strength.

TWO CASES HOLD IT. One walks the served `tools/list` and asserts both keys on every tool — the same reach check the vocabulary chunk needed, for the same reason: a field nothing can set is a field that is always empty. The other holds the suppression case.

## follow_up

THE MARK IS THE WHOLE MECHANISM AND IT IS ASKED OF THE PARTY BEING JUDGED. `raid-risk-the-weaker-model-asymmetry-has-nothing-enforcing-it` stands at crippling and is not retired by this chunk. A walker that reads "this needs a stronger hand", takes the step itself and sends no `named_driver` at all leaves a record that is not even marked.

SO THE ARMING IS VOLUNTARY, AND THAT IS THE HONEST RESIDUE. What the build can do is make the reasoned and the unreasoned cases distinguishable once a driver IS named. What it cannot do is make a caller name one.

WHAT WOULD CLOSE IT is the value arriving from the walk rather than from the caller — the pull already knows what it published, so a later iteration could stamp the named driver from the same place it stamps the state. That is the same shape as taking the mark off the model coordinate, and it is outside this iteration's box for the same reason.

`the-answer-rides-the-pull` IS WHERE THE OTHER HALF LANDS. When the block publishes a rung on the pull, the named driver stops being a string a caller repeats back and becomes a value the walk already holds.
