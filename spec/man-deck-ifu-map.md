# Start And Walk
This IFU shows where the work loop lives.

<!-- ai:3 -->
- Start work with retro, triage, and planning.
- Walk one ready check at a time.
- Use grants only after the evidence exists.
- Ship only after handover.

Minutes: 1.0
Note: This slide is a route map. It does not replace the detailed method.
---
<!-- ai:3 -->
# Review And Evidence
The review lane is where the record becomes useful.

<!-- ai:3 -->
- Notes capture loose input.
- Readout explains the board.
- Report renders the full board.
- Retro turns wasted effort into method changes.

Minutes: 1.0
Note: Review is not ceremony. It is how work remains explainable later.
---
<!-- ai:3 -->
# Book And IFUs
The book is the stable reader surface.

<!-- ai:3 -->
- Chapters hold the trace.
- Guides serve repeated work.
- IFUs are slideshow guides.
- Decks are markdown sources rendered into the book.

Minutes: 1.0
Note: The markdown deck is the source of truth. The HTML deck is derived.

<!-- ai:3 -->
# Engine And Workspace
The engine keeps the workflow portable.

<!-- ai:3 -->
- One global binary can drive many workspaces.
- Vehicles can carry their own brand and method overlay.
- MCP is the preferred agent lane.
- The repo stores truth. Caches stay outside it.

Minutes: 1.0
Note: This slide is for operators who need to know where state and tools live.
