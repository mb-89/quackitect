# The write door

- The door shall refuse a write breaking a rule the paragraph schema holds.
- The door shall name the line, the rule and the phrase in its refusal.
- The door should hand the writer the better word where the rule knows one.
- The door must leave a fence and a code span alone.
- The door must read the path the repo root holds.

| the case | what the door does |
|---|---|
| a mechanical rule refuses a line | the door refuses the write |
| the judge refuses a span | the door refuses the write |
| every rule passes | the door hands the write on |
